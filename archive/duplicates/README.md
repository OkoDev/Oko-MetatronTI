# 🗄️ Архив дублей (Duplicates Archive)

> «Не просто выбрасывать, а складывать в локализованный архив — мы проделали работу
> для их создания, они могут быть однажды полезны. А пока пусть отдохнут.» — юзер, 11.06.2026

Сюда переезжает код дублей при их устранении (см. `docs/DUPLICATES_REGISTRY.md`).
**Не удаляем безвозвратно** — выведенный из работы расчёт сохраняем здесь: работа над ним
была реальной, контекст ценен, и однажды может вернуться (другой домен, другая калибровка).

## Политика
1. Перед заменой дубля на эталон — **извлечь старый код сюда** файлом `D-NN_<что>.py`
2. В шапке файла: ID дубля, дата, откуда извлечён, почему выведен, чем заменён, когда может пригодиться
3. Код **закомментирован / не импортируется** (спит), но читаем
4. Ссылка из реестра (`docs/DUPLICATES_REGISTRY.md`) на архивный файл

## Принцип
Это материализация бережного отношения к проделанной работе: ничего ценного не теряем,
но и не тащим в активный код (чтобы не плодить дрейф). Архив = «отдыхающие», не «мёртвые».
