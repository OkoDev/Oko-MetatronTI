## Старт каждой сессии (обязательно)
1. `DISCUSSION.md` — живой диалог агентов, найти вопросы к роли DS.
2. `TASKS.md` — задачи, статусы, **раздел координации ролей**.
3. `.claude/CLAUDE.md` + `memory/MEMORY.md` — правила, баги, паттерны.

## Coding Style
- **Thinking и документация — на русском.**
- **Grep before claim:** имена методов/полей/констант — только после grep/Read, не по памяти.
- Числа — только из `config.yaml`/кода, не «типичные» значения.
- Стиль кода — как в окружающем файле (отступы, нейминг, плотность комментариев).

## 🔴 Координация двух агентов (Claude + DeepSeek)
Над репо работают ДВА агента параллельно. Разделение **по риску**:

| Зона | Агент |
|---|---|
| Торговая логика, Куб, критичный код: `core/trading/` (register_trade, gates, sl_tp), `core/signals/`, `core/smc/`, `bot/` | **Claude** |
| Рутина: `scripts/` (аналитика), тесты, `docs/`, research, рефакторинг низкого риска | **DeepSeek (DS)** |

**Правила (нарушение = конфликт git / сломанный бот):**
1. **НЕ коммить чужие файлы.** Перед коммитом — `git status`, коммить ТОЛЬКО свои.
2. **НЕ трогать один файл одновременно.** Если файл уже изменён (M) — это чужая работа, не перетирать.
3. **Критичный код (`core/trading/`, signals, gates) — НЕ трогать без согласования.** Цена ошибки = «бот не стартовал».
4. Перед правкой `register_trade`/INSERT — runtime-проверка (не только синтаксис): прогнать `scripts/`-тест на копии боевой БД.
5. Свою работу фиксировать в `DISCUSSION.md` под ролью **DS** (как DEV/ARCH/TRADER).
