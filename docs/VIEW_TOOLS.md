## 1. 🌊 ВОЛНОВОЙ РАЗБОР — главный инструмент «посмотреть»

Рисует три этажа (1D нога · 1h счёт волн и зона · 15m микроструктура) + текстовый разбор
и сценарии с целями. Возвращает PNG, который можно открыть и увидеть.

```bash
# запрос разбора (sym без /USDT; ltf: 3m | 5m | 15m)
curl -s -X POST http://127.0.0.1:8010/api/waves/analyze \
     -H "Content-Type: application/json" -d '{"sym":"BTC","ltf":"15m"}'
# → {"ok":true, "png":"BTC_20261006_1209.png", "card":{...}, "state":{...}}

# картинка лежит здесь (открывать инструментом Read — он показывает изображение):
#   data/wave_analyst/<png>
# либо по HTTP:
curl -s -o /tmp/w.png http://127.0.0.1:8010/waves/analyst/BTC_20261006_1209.png
```

**Что читать в ответе:** `card.side` · `card.light` (wait/go) · `card.targets` (цели с %) ·
`card.invalid` (где счёт отменяется) · `state.scen` (сценарии) · `state.zone_lo/hi` (зона) ·
`state.count_px` (точки счёта 0-1-2).

| ручка | метод | что даёт |
|---|---|---|
| `/api/waves/analyze` | **POST** `{sym, ltf}` | разбор + PNG (самое важное) |
| `/waves/analyst/{name}.png` | GET | забрать картинку |
| `/waves/chart/{name}` | GET | HTML-график волн |
| `/waves` | GET | страница волн |
| `/api/waves` | GET `?syms=&tf=` | волны пачкой |
| `/api/waves/similar` | GET/POST | похожие ситуации в истории |
| `/api/waves/journal` · `/api/waves/review` | GET / POST | журнал и разборы |

## 5. 📈 TradingView MCP

Инструменты `mcp__tradingview__*` есть, но **TradingView Desktop не найден** по стандартным
путям Windows (проверено 06.10: `AppData\Local\TradingView`, `Program Files`, `Program Files (x86)`).
Чтобы пользоваться — запустить вручную с отладкой:

```
"<путь>\TradingView.exe" --remote-debugging-port=9222
```

Тогда доступны: `chart_set_symbol` · `chart_set_timeframe` · `capture_screenshot` ·
`draw_shape` · `data_get_ohlcv` · `pine_*` (работа с Pine) · `replay_*` (реплей).
⚠️ TV MCP однажды **перезаписал наш OkoTrend** — к Pine-скриптам осторожно.
