## 1. SMC-структура (фундамент — глазами пользователя)

| Паттерн | Статус | Функция / заметка |
|---|---|---|
| **ZigZag «Waves»** (dev=3, depth=11) | ✅ | `zigzag_atr` — основа структуры, точнее swings(50) |
| **Структурные точки HH/HL/LH/LL** | ✅ | `_zz_typed` + классификация по пред. экстремуму |
| **Слом структуры BOS/CHoCH** | ✅ | `find_setups_zz` — пробой последнего zz-экстремума; CHoCH=против тренда, BOS=по |
| **OTE / Fib на импульсе слома** | ✅ | `build_ote` [0,0.5,0.62,0.705,0.79,1.0]; зона 0.705–0.79; импульс = тот, что СЛОМАЛ структуру |
| **Order Block (+ mitigation)** | ✅ | `detect_order_blocks`, `active_order_blocks` (breaker не используется) |
| **Premium / Discount / Equilibrium** | ✅ | `premium_discount` — упрощённое фибо-деление |
| **EQH / EQL** (равные хаи/лоу) | ☐ | LuxAlgo: pivot(3) + max<min+atr*0.1. Следующий слой |
| **FVG** (имбаланс) | ☐ | LuxAlgo: src_l>src_h[2]; конфлюенция к OTE = «+»/«++» |
| **Liquidity sweep** (снятие стопов) | ☐ | свип экстремума + возврат; лучший LONG-сигнал в БД |
| **FVG overlap reversal** | 🔬 | bull-FVG **перекрывает** bear-FVG (зоны пересекаются) = сильный знак разворота вверх. **Bear часто уже mitigated** — именно bull-импульс его перекрыл/закрыл (снял сопротивление) → искать НЕ только активные bear, а bull(активный) × bear(любой), где `bull.ts > bear.ts` и `bl≤rh and rl≤bh`. Подтверждение: зона перекрытия УДЕРЖАЛАСЬ на откате (цена не закрыла вниз). Примеры: AVAX 15m (8.181–8.191), SOL 15m 03.06 (74.26–74.69, отскок). Зеркально: bear перекрыл bull = разворот вниз. **Полезно как сигнал входа** (правило пользователя 03.06).

**🔑 Правило входа (эталон):** слом значимой структуры → импульс «от низа до верха» (что вызвал слом)
→ OTE его импульса → ретест **зоны 0.5–0.79** → вход, стоп за 1.0. Конфлюенция OB/FVG в OTE = «+».
bull-CHoCH → LONG (OTE near low); bear-CHoCH → SHORT (OTE near high). Объём на 1m НЕ критерий.
**Зона входа = 0.5–0.79** (уточнение 02.06); 0.705/0.79 — наиболее вероятные точки отскока внутри.

**🌊 МУЛЬТИ-МАСШТАБ импульсов (Эллиотт, уточнение 02.06):** фибо строится НЕ только на локальном
сломе, но и на ВСЁМ волновом импульсе старшего масштаба. Пример GRT 02.06: коррекция ABC →
полноценный **5-волновой импульс вниз** (1-3-5 вниз, 2-4 откаты) c(16:18 0.02395)→волна5(19:33 0.02284).
Большая фибо на нём → откат вверх дошёл **ровно до 0.79** (0.02371 @21:37) → SHORT по тренду
старшего импульса. Локальная фибо (CHoCH) и большая волновая (5 волн) работают ОБЕ, на разных ТФ.
→ связь [[Elliott-Wave]]; будущее: детект 5-волновой структуры (3 импульсных слома 1-3-5).

## Как наполняем
1. Пользователь описывает паттерн (как размечает, условия, вход/стоп, на каком ТФ).
2. Формализую правила → проверяю на данных (GRT/XLM 1m, визуальная сверка через `chart_verify`).
3. После подтверждения — код-детектор + статус ✅ + ссылка на функцию.
4. Связь с Кубом Метатрона: каждый паттерн — вход для сферы сигналов / конфлюенции.
