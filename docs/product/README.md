## 🔴 Закон этого склада (перенесён из всей сессии 13–14.10)
**Ни одного числа на витрину/в оффер, которое не держится.** Проверено дорого:
- `Patterns 72% +2.8R n=184` — мок из `oko-dashboard/lib/oko-data.ts`, не замер. На лендинг нельзя.
- `косты 57% убытка` — приписывает проекту чужую торговлю (NEAR вне пути бота). Нельзя.
- `equity curve` — реальная уходит в −7650, не растущая. Как витрину не показываем.
- `380k похожих часов` — числа нет, метод реален.
- `adaptive weights` как эдж — аудит: «взвешивать нечего».

**Можно (проверено кодом 13–14.10):** ширина падения PF 1.62→4.22 p=0.00026 (`structure_terminal.py:144`),
71 признак (combinator ARCH-118), форвард-табло net% (`_scoreboard`), состояние монеты, отсеянные с причинами.
