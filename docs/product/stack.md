# 🏗️ Стек и архитектура продукта — решение 15.10.2026

> Решение принято Егором 15.10.2026. Контекст: metatronti.com живой (лендинг + /moment демо),
> следующий шаг — многопользовательский продукт с тарифами.

## Текущее состояние (3 фронтенда — хаос)

| Порт | Стек | Экранов | Язык | Продуктовая ценность |
|---|---|---|---|---|
| **:8010** | aiohttp + Jinja2 | ~12 | жаргон владельца | максимум фич, но legacy-стек |
| **:3000** | Next.js / React | ~4 | жаргон + моки | правильный стек, полуготовый |
| **:8000** | aiohttp API | — | JSON | бэкенд для :3000 |
| **/moment** | чистый HTML | 1 | человеческий | целевой дизайн, но статика |

## Решение: Next.js + FastAPI + Redis

```
metatronti.com          →  Cloudflare Pages (лендинг, статика)
app.<домен>             →  Next.js (React, прод-фронт) — план; поддомены текущего туннеля — в auto-memory, не в git
api.<домен>             →  FastAPI (Python API, auth, данные)
:8010                   →  кабина владельца (остаётся как есть)
```

### Фронтенд: Next.js (oko-dashboard → перестройка)
- Компонентность — каждая вкладка = компонент, переиспользуется
- Auth — NextAuth/Clerk, middleware гейтит вкладки по тарифу
- Дизайн — из /moment (золото #D9A441, IBM Plex) + glossary.md
- Деплой — Vercel или Cloudflare Pages+Functions
- Экосистема — shadcn/ui, Recharts, TanStack Query

### Бэкенд: FastAPI (замена :8000 aiohttp)
- Автодокументация OpenAPI + валидация Pydantic
- JWT auth, rate limiting, CORS
- Async — не хуже aiohttp по скорости
- Эндпоинты: /api/agenda, /api/pairs, /api/screener, /api/waves, /api/kpi, /api/coin/:symbol

### Кэш: Redis (между ботом и API)
- Бот пишет → Redis хранит → API читает и раздаёт
- Pub/sub для WebSocket real-time обновлений
- На старте можно in-memory dict, Redis — когда >50 пользователей

### Перевод: glossary.json
- Единый источник: docs/product/glossary.md → glossary.json
- Используется в: Next.js фронт, FastAPI ответы, лендинг, /moment
- Контракт: любой термин для НЕ-владельца берётся отсюда

### Языки (решение Егора 17.10)
- **Английский — только в новом проде** (Next.js app.*, /moment, лендинг): там i18n на ключах `ru`/`en`.
- **:8010 остаётся на русском**: текст переведён прямо в коде, i18n в legacy не строим (кабина уйдёт).
- Технические термины трейдинга одинаковы в обоих языках (ATR, WT, OB, CHoCH, BOS, DEMO/LIVE, алерты,
  ЯДРО/CORE, Куб/Cube) — переводится только человеческий текст (объяснения, причины, вердикты).
- glossary.json — мост: к парам добавить `en`, когда начнётся Next.js.

## Масштаб данных (уточнено Егором)
- Монет: **475+** в кэше (500+ с учётом роста)
- Признаков: **435** MTF в матрице (пивоты 216, SMC 66, дивергенции 24, WT 18, ATR 12 + старшие ТФ)
- В шине реального времени: 71 (на лендинге)
- Данные у всех пользователей ОДНИ — это рынок. Compute один раз, serve N раз.

## Нагрузка
20 одновременных пользователей × fetch раз в 15с = ~1.3 req/sec. FastAPI отдаёт ~5000 req/sec.
Запас 3000x. Боттлнек — не стек, а данные. Кэш решает.
