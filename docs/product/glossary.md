# 🗣️ Словарь Жаргон → Человеческий (продуктовый, многопользовательский)

> 🔴 Канон для кода — [glossary.json](glossary.json). Этот файл — его человеческая версия с пояснениями.
> Утверждён Егором **16.10.2026** (черновик 14.10).
>
> **Принцип:** убираем ВНУТРЕННИЙ новояз проекта («дрейф вселенной», «ширина падения», «нога», «чистая эра») —
> его не поймёт ни новичок, ни трейдер. Общепринятую трейдерскую терминологию (кластер, импульс, Ордер Блок,
> имбаланс, дивергенция) оставляем — это язык аудитории. Один язык для :8010, /moment и лендинга.
>
> **Как применяем:** только к видимому тексту. Ключи логики (`p.state`, `d.phase`, value фильтров), колонки БД
> и источники данных (`oko_sm_watch._W` — там «полка», «FVG» это ключи весов скоринга) не трогаем. Новый термин
> на экране → сначала пара сюда и в json, потом на экран. Числа — точные.
