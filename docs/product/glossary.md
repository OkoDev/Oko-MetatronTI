# 🗣️ Словарь Жаргон → Человеческий (продуктовый, многопользовательский)

> 🔴 Это НЕ личный `словарь Егора` (тот был для одного владельца и в многопользе мешает). Это
> **канонический перевод** внутреннего жаргона на язык, понятный любому. Один источник правды для
> /moment, лендинга и будущего перевода терминала. Решено 14.10.2026.
>
> Правило: любой термин, который видит НЕ-владелец, берётся отсюда. Новый жаргон на экране → сначала
> пара сюда, потом на экран. Числа — ТОЧНЫЕ (мы честный замер делаем, округление подрывает доверие).

## Рынок и режим
| Жаргон | Человеческий |
|---|---|
| Режим не подтверждён ни одним прибором | Ни один прибор не говорит «да» |
| Ширина падения | Падают разом |
| порог 15% | обвал — от 15% |
| X из N ликвидных за 24ч | X монет из N |
| **Дрейф вселенной** 30д | **Рынок за 30 дней** · 🤫 «Дрейф вселенной» — наш внутренний флавор, публично только «Рынок за N дней» |
| производная +9.0 < +10 | публично убрать (или «ускорение ещё слабое») |
| Фаза phase_watch · UNCLEAR | Фаза рынка · пока неясно |
| как режим не мерилась | точным прибором не измеряли |
| шорт вне режима · рано для шорта | для шорта не время |

## Идея / сделка
| Жаргон | Человеческий |
|---|---|
| ТЕРЯЮ ПРИ x15 | РИСК ПРИ ×15 |
| на 1$ риска — 6.2 | на $1 риска — $6.2 цели |
| карта (похожие часы) | похожие случаи |
| осциллятор 4h вниз N баров | импульс 4ч вниз |
| кластер | совпадения |
| косты | издержки |
| одиночный сигнал | без подтверждения |
| цель ближе стопа | цель ближе стопа (ok) |

## Бот / движок
| Жаргон | Человеческий |
|---|---|
| открытый риск волн | риск в открытых сделках |
| impulse_fib | импульс |
| choch | слом |
| радар | радар (ok) |
| увёл в тень · вне доказанной зоны | убрал — настройка себя не доказала |

## Лендинг / метрики (для не-эксперта)
| Жаргон | Человеческий |
|---|---|
| net% | чистый результат после издержек |
| p-value | насколько это не случайность |
| PF (profit factor) | во сколько раз прибыль больше убытка |
| R / R-multiple | во сколько раз цель больше риска |
| SMC | структура рынка (или оставить SMC для своей ЦА) |
| WT / WaveTrend | индикатор перепроданности (или оставить) |

## Что НЕ переводим
Названия монет (BTC/ETH), цены, проценты, $ — как есть. Числа всегда точные. Для ЦА «трейдер с методом»
(лендинг) часть терминов (SMC, R) можно оставить — они её язык; для холодного/массового (/moment) — переводим всё.
