## 🔑 ГЛАВНЫЕ КОНЦЕПЦИИ SMC

| Концепция | Суть в 1 фразе |
|-----------|----------------|
| **BOS** | Пробитие последнего лоя/хая на объёме = смена тренда |
| **BMS** | Подтверждение BOS: 2+ свечи за линией |
| **POB/POP** | Зона проторговки ПЕРЕД сломом — главная POI |
| **Order Block** | Свеча, где крупный игрок набрал позицию перед импульсом |
| **SC (Sponsored Candle)** | OB, собравший ликвидность хвостом = сильнее обычного |
| **FVG / Imbalance** | Ценовой разрыв — магнит для цены. Фикс на 0.5 или 1.0 |
| **Breaker Block** | Пробитый OB, ставший зеркальным уровнем |
| **Supply / Demand** | Последнее движение перед импульсом |
| **Wick (Вик)** | Длинная тень — зона ликвидности. Вход от 0.5 тени |

## 📈 ORDER FLOW — 5 ПРАВИЛ

1. ❌ **Не торгуй против CumDelta** (падает → не лонгуй)
2. 🔍 **Absorption на экстремумах** = набор/раздача
3. 💎 **Delta Divergence + RSI Divergence** = 90% разворота
4. 🟢 **Delta после sweep** = лучший вход (зелёная → лонг)
5. ⚠️ **Объём ≠ Delta** (объём большой, Delta ≈ 0 = нерешительность)
