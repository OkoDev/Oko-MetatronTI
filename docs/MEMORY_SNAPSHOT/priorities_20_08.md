## 🔴 УРОВЕНЬ 1 — ГОТОВО К ВНЕДРЕНИЮ, БЛОКИРУЕТ ДЕНЬГИ

**1. Заменить источник в боте на импульсную механику.**
Сейчас крутится `choch_wavec`: OOS 1.07, за сутки НОЛЬ сделок (103 из 120 сетапов
протухают за 12-барное окно). Импульсная механика: **OOS×OOS 1.53, WR 56.2%**,
все 5 лет в плюсе, портфельно **+8.4%/мес**. Готовый рецепт → [[backlog_impulse_session_19_08]].

**2. Стоп 2.5·ATR вместо стопа за origin.**
Не про доходность, про выживание: при плече 10 стоп 8.5% стоит ЗА ликвидацией —
**123 ликвидации из 503 сделок**. Стоп 4.4% даёт двойной запас: **12 вместо 123**,
PF 1.63 против 1.56, по годам ровнее (минимум +2.9%/мес против +0.6%).
🔴 Плечо 20 не использовать ни с каким стопом — 370 ликвидаций из 828.

**3. Цель по стороне: LONG −1.0 · SHORT −1.618.**
Шорту дальняя цель даёт **OOS 1.66 против 1.49**, положительный безтоп10%.
Лонгу дальняя цель ВРЕДИТ (OOS 0.90 против 0.95). Одна строка кода.

**4. Ступенчатый размер по скору вместо бинарного отбора.**
На OOS **+11.1%/мес против +6.7%**. Кэп позиций режет 94% сигналов — фильтр не отнимает
частоту, а выбирает, чем занять слоты. Скор монотонен по квинтилям (0.95→1.25).

## 🟡 УРОВЕНЬ 2 — ПОЧИНЕНО, НО НЕ ПЕРЕМЕРЕНО

**5. Перемерить `ote_nested` и `arch104` на починенной конфлюэнции.**
`ote_retest_setups` считал конфлюэнцию по ВСЕЙ истории: сетап на баре 100 получал
усиление от FVG с бара 500. Раздув **+85%**, задето **90% сетапов** (434 из 482).
Починено 19.08, но прошлые результаты этих стратегий содержали подсматривание —
их выводы недействительны до перемера.

**6. Breaker — детектор РЕАЛИЗОВАН и ВНЕСЁН В ПРИЗНАКИ 20.08 (команда Егора).**
`OrderBlock.is_breaker` существовал с самого начала, но НИКОГДА не выставлялся —
детектора не было, только поле. Теперь: `is_breaker=(mit != -1)`, плюс функции
`active_breakers(obs, at_bar)` и `breaker_side(ob)` в `core/smc/smc_engine.py`.
Проверено: **70% OB становятся breaker** (38 из 54 на 3 монетах).
✅ В наборе признаков: `bull_breaker`/`bear_breaker` из `etl_order_blocks` →
колонки `*_{tf}` в `compute_flags`, сторона в `scan_loop`, вес 5 в `registry`.
Доля True 0.6–2.4% баров, причинность чистая (0 расхождений из 2000).
🔑 В замере конфлюэнции breaker — **лучший одиночный фактор по OOS (1.80)**,
но считался УПРОЩЁННО. Перемер на настоящем детекторе: `scripts/measure_breaker_filter.py`.
