# 🔴🔴 НАЛОГ НА ИСПОЛНЕНИЕ УДВАИВАЕТ КОСТЫ (14.08.2026)

Проверка бэклога [[backlog_vst_spread_poisons_forward]] по требованию Егора
(«сравнить фактические avgPrice»). Замерено ДВУМЯ независимыми способами.

## 1. Спред стаканов: VST против боевого (49 пар × 3 раунда)

`scripts/vst_spread_systematic_check.py`

| | LIVE | VST | отношение |
|---|---|---|---|
| медиана спреда | **0.0888%** | **0.2992%** | **3.3×** |

VST шире в **97% замеров**, ≥3× в 56%. Стабильно по раундам (3.2× / 3.7× / 3.2×) —
это система, а не снимок. Фантомная надбавка **+0.2104% за круг**.

🔑 **Инверсия по ликвидности:** Q4 ликвид **6.2×** (LIVE 0.027% против VST 0.264%),
Q1 неликвид только 2.1×. Чем качественнее инструмент, тем сильнее демо-стакан искажает —
мы наказывали себя именно там, где в бою издержек почти нет.
Худшие: `1000PEPE` +3.47% за круг (72×), `ARB` +2.72% (26×), `HYPE` 27×, `XAUT` 26×.
Цены при этом СОВПАДАЮТ (отклонение mid 0.0148%) — VST врёт только о стоимости исполнения.

## 2. Фактические исполнения: 5796 реальных ордеров

`scripts/vst_actual_fill_slippage.py` — поля `entry_price` (сигнал) против
`actual_entry_price` (факт), знак по направлению сделки.

```
медиана налога на вход:  +0.2183%      за круг: +0.4365%
хуже сигнала: 85.2%       p90: +1.453%
```

**РЕАЛЬНЫЕ КОСТЫ = 0.35% комиссии + 0.44% исполнения ≈ 0.79% за круг.**
Все замеры эджа велись по ставке 0.35% — заниженной в **2.25 раза**.

**Доля РИСКА, съедаемая исполнением (главная таблица):**

| стоп | медиана налога | доля риска |
|---|---|---|
| 0–1% | +0.210% | **42.0%** |
| 1–2% | +0.214% | 14.3% |
| 2–4% | +0.297% | 9.9% |
| 4–8% | +0.802% | 13.4% |
| 8%+ | +0.947% | **6.8%** |

Абсолютный налог почти постоянен, а доля риска падает в 6 раз с ростом стопа.
Это третье независимое подтверждение закона размера — теперь со стороны ИСПОЛНЕНИЯ,
а не комиссии. Боевой стоп бота был **0.61%** → исполнение съедало ~40% риска.

**VST против SIM:** медиана идентична (+0.218% у обоих), но VST бьёт ХВОСТАМИ —
среднее +0.75% против +0.31%, p90 **+1.94%** против +0.63%.

## ⚠️ Ловушка данных, которую пришлось обойти

В 12% ордеров `actual_entry_price` буквально РАВЕН `entry_price` — фактическая цена
не записывалась, поле скопировано. Доля скачет по месяцам: апрель 27.6% · май 15.3% ·
июнь 1.1% · июль 12.5% · **август 59.2%**. Из-за этого «нулевой налог августа»
оказался артефактом, а общая медиана была занижена (+0.179% против честных +0.218%).
**Правило: перед выводом проверять, не является ли поле копией другого.**

По месяцам (только реальные): апрель +0.041% · май +0.080% · **июнь +0.589%** ·
июль +0.229% · август −0.647% (n=78, вероятно лимитные).

## Следствия

1. **VST годится для проверки МЕХАНИКИ, но не ЭКОНОМИКИ.** Гейт REAL-MONEY
   ([[forward_machine_sphere11]]) на нём построить нельзя — 20–30 чистых net+
   недостижимы при фантомном налоге.
2. **Все выводы «эдж не переживает косты» надо перемерить по 0.79%** —
   [[live_root_cause_costs_eat_tight_stops]], [[crosssection_dead_at_our_costs]],
   [[arch104_remeasured_causal_fvg]] (там брутто было +0.060% при ставке 0.35%).
3. **Лимитный вход снимает проблему в корне** — спред не платится вовсе
   (скилл `bingx-maker-entry`). Август с −0.647% косвенно это подтверждает.
4. Механика [[atr_flip_plus_fvg_regime_edge]] на 4h имела стоп 7.79% → налог ~10%
   риска. Требует пересчёта по 0.79%: при TTL 8 суток она давала +0.34%/сд
   и может уйти в минус; при TTL 24–64 суток (+1.23% / +1.55%) — выживает.
