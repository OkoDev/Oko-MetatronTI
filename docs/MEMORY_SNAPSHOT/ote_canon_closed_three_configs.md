# 🔴 OTE ЗАКРЫТ ОКОНЧАТЕЛЬНО: ТРИ КОНФИГУРАЦИИ, НИ ОДНА НЕ БЬЁТ СЛУЧАЙНЫЙ ВХОД (05.09.2026)

Егор: «ты ведь понимаешь по структуре и мультиструктуре, где импульс, где слом и где искать
OTE по теории? У нас нет 2-3 недель». Собран канон целиком и проверен с контролем.

## Что именно построено (`scripts/ote_canon_run.py`)

1. **Нога — из ЭТАЛОНА**: `oko_sm_engine.run_structure(swing_len=50, internal_len=5,
   record_legs=True).leg_history[t]` = {origin, extreme, trend}, ровно как размечает Егор
   (origin = HL/Weak Low, extreme = Strong High). Нога с 1h, взята с ЗАКРЫТОГО бара (shift+ffill).
2. **Зона** 0.618-0.786 отката от extreme к origin ЭТОЙ ноги.
3. **Триггер** — слом ВНУТРЕННЕЙ структуры (internal len=5) на 15m в сторону ноги.
4. **Стоп** — в двух вариантах масштаба (см. ниже). **Цель** — extreme ноги / фибо −0.618 / 1R / 2R.

## Результат: сигнал НЕ отличается от случайного входа

| конфигурация | цель | сигнал | контроль |
|---|---|---|---|
| зона + триггер, стоп за origin (len=50) | extreme | −0.447% | **−0.232%** (сигнал ХУЖЕ) |
| | фибо −0.618 | −0.390% | −0.344% |
| | 1R | −0.497% | −0.423% |

13 196 сигналов, 12 монет ядра, 2023-2026, косты 0.35%, счёт в % цены.
По годам: 2023 −0.31% · 2024 −0.66% · 2025 −0.37% · 2026 −0.09%.

🔑 **Масштаб стопа поймал Егор**: «триггер сломом микроструктуры len=5, а стоп за структуру
len=50?» — это была моя ошибка, тот же класс, что стоил RR 7:1 → 0.33 в июне. Исправлено:
при микро-стопе распределение приняло правильную форму (медиана −1.58% при среднем −0.40% =
редкие большие выигрыши), но СУММА всё равно не в плюсе.

## Три конфигурации подряд — направление закрыто

1. Зона без триггера, 10.08 → PF 0.87 ([[ote_zone_no_edge_even_on_correct_leg]]);
2. Зона + триггер + макро-стоп → хуже контроля;
3. Зона + триггер + микро-стоп → равно контролю.

⇒ **OTE как механика входа эджа не даёт** — ни на правильной ноге, ни с правильным
триггером, ни в согласованном масштабе. Не переоткрывать.
