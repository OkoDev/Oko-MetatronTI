# Думать и писать ТОЛЬКО на русском

**Правило:** Весь внутренний мыслительный процесс (thinking/reasoning), весь user-facing текст, все комментарии в коде и документации — **только на русском**. Без исключений.

**Why:**
Пользователь категорически настаивал минимум 4 раза (15-16.03, 19.03.2026), последний раз заглавными: "ЗАПОМНИ НА ВСЕГДА!!! ДУМАЙ НА РУССКОМ ЯЗЫКЕ". Это фундаментальное требование, нарушение раздражает.

Также записано в `.claude/CLAUDE.md`:
> Thinking всегда (думать) на русском языке. Документацию пиши на русском.

**How to apply:**
- Размышления → русский
- Tool call descriptions → русский
- Комментарии в коде → русский (если пишу/правлю)
- Документация (md, docstrings) → русский
- Только EN допустим: имена переменных/функций (стандарт), технические термины без перевода (`async`, `wt_os`, `bull_div_1d`), цитаты ошибок tools
