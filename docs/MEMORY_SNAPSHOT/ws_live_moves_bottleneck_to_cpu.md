# 🟢 WS В БОЮ: СЕТЬ РЕШЕНА, УЗКОЕ МЕСТО ПЕРЕЕХАЛО В CPU (02.09.2026)

Проба №2 по указанию Егора («WS проверить»). Первая, 03:23–04:16, была
неубедительной: 2 цикла, и в те же минуты latency биржи выросла втрое.
Сейчас впервые была ЧИСТАЯ база — прокси дали медиану 318 с при стабильных
15/30/40, выбросы latency ушли в ноль ([[scan_bottleneck_is_the_channel]]).

## Результат на разбивке времени пары

| | до WS | после WS |
|---|---|---|
| `total` на пару | 19.8 с | **16.9 с** (−15%) |
| **`ohlcv` — сеть** | **8.0 с** | **3.2 с** — в 2.5 раза |
| доля сети в total | 41% | **20%** |
| обработка (total − ohlcv) | 11.8 с | 13.7 с |

Запросы через прокси: ≈200–250/мин до → **≈55/мин** после.

## 🔑 Главный вывод

**WS свою часть отработал, дальше мешает не сеть.** После него 80% времени пары —
обработка. Следующий рычаг уже измерен в этот же день: SMC-детекторы съедают
**151 с CPU за цикл**, из них 125 с в `sub_cube` (573 пары × 4 ТФ), корень —
поэлементный pandas в `_detect_breaks`, который в 42 раза медленнее эталона
([[smc_set_b_40x_slower]]). Оценка выигрыша от векторизации: ~70 из 151 с.

Порядок рычагов, каждый со своим замером:
1. **прокси** — сняли накопительный троттлинг: цикл 832 → 318 с
2. **WS** — снял сетевую задержку: ohlcv 8.0 → 3.2 с
3. **дальше CPU** — векторизация `_detect_breaks` (не сделано)

## Качество данных WS (за чем следить при откате)

`merge per TF` за 10 минут: `5m: append 1550, replace 53969` ·
`3m: append 2295, replace 51325, stale 1`. Один stale на ~110 тысяч записей,
и он не растёт. Очередь reader'а q≈0–11, rate 139–195/с.

🔴 Критерии отката (`use_ws: false`): hit по ТФ < 70% · рост stale ·
очередь reader'а копится (в shadow доходила до 6366) · расхождение цен с REST.

🪤 Не спутать: лавина `force REST refresh (stale-guard)` по 33–39 записей каждые
~3 минуты — это ПЛАНОВАЯ проверка открытых позиций в `trade_simulator`,
она идёт одинаково до и после WS и к качеству WS-данных отношения не имеет.

Конфиг: `market_ws.enabled: true · use_ws: true · timeframes: [3m, 5m]`.
15m оставлен на REST — его TTL 1800 с длиннее цикла, hit и так 81%.
