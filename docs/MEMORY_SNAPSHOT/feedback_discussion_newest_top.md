В `DISCUSSION.md` новые записи добавляются **СВЕРХУ** — сразу после шапки (строка-правило «> Хронологический лог. Новые сообщения — сверху.»), НЕ в конец файла. Юзер дважды поправил 13.06: сначала текущую запись, потом нашёл ещё две мои записи 13.06 в самом низу (среди 04.06).

**Why:** файл читается сверху вниз как лента — свежее первым. Запись в конец = теряется среди старых, другие агенты/юзер не видят новое.

**How to apply:** при добавлении в DISCUSSION.md — Edit вставляет блок ПОСЛЕ шапки (`---` после строки «Текущий: с ...»), ПЕРЕД первой существующей записью `### [дата]`. Формат записи: `### [ДД.ММ.ГГГГ HH:MM UTC] Автор → Адресат ЭМОДЗИ — Заголовок` ... тело ... `— Автор, ДД.ММ.ГГГГ`, затем `\n\n---\n\n`. Порядок по убыванию даты/времени. Тот же принцип у `memory/current_state.md` (новые сверху). Связано: [[feedback_tasks_vs_discussion]].
