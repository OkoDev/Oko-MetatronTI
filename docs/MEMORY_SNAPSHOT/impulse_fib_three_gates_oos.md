# 🟢🟢🟢 ИМПУЛЬС + ФИБО 0.382 + ТРИ ГЕЙТА (19.08.2026)

Развитие [[impulse_detector_is_the_root_egor]]. Гипотезы принёс РОЙ (11/12 ответили,
7 семейств) по мандату Егора «проверяй всё, подключай рой, найди LONG и SHORT».

## Механика
```
импульс ПО ОПРЕДЕЛЕНИЮ: ход >=3 ATR, контр-откат <=35%, длина <=60 баров
  → лимит на откате 0.382 от импульса (0.382 сильнее канона 0.618-0.786!)
  → стоп за origin импульса · цель = длина импульса ×1.0 · держим 96 баров
ТРИ ГЕЙТА (произведение сильнее суммы):
  · объём импульса 1.0-1.5× среднего за 120 баров  (>1.5 ЯД: PF 0.72)
  · импульс ПО тренду (цена vs EMA200 1h)
  · растущая волатильность: ATR(14)/SMA(ATR,100) > 1.1
```

## 🔴 ADVERSE SELECTION ВЫЧТЕН (главное подозрение роя)
Две независимые семьи назвали артефактом №1: «лимитка исполняется чаще, когда уровень
пробивают насквозь (убыток), и НЕ исполняется, когда он отрабатывает идеально».
**Проверено:** идеальный фил (касание+разворот) — 426 сделок из 5629, PF **1.90**;
пробитые насквозь — PF **1.03**. То есть базовый эдж и правда сидел в неисполнимых.
🔑 **НО связка выживает и на консервативном исполнении**: все числа ниже посчитаны
ТОЛЬКО по лимиткам, пробитым глубже 0.15% — то есть исполнимым гарантированно.

## Вклад гейтов (на консервативном филе)
база 1.03 → +объём 1.20 → +тренд 1.05 → +режим 1.35 → **ВСЕ ТРИ 1.95**.
Произведение сильно лучше каждого по отдельности — сходится с [[stacked_gates_joint_robustness_p7]].

## 🔑 ОБЕ СТОРОНЫ ЖИВЫЕ — впервые
**LONG 1.31 · SHORT 1.22** (на консервативном филе). В отличие от
[[choch_pullback_waveC_oos_passed]], где лонг был мёртв (0.76). Егор: «рынок может
развернуться, мы должны быть готовы» — здесь готовы обе стороны.

## 🔑 ЧАСТОТА — 36 сделок/мес на 250 парах
Против 7/мес у CHoCH-ядра. Это ответ на «3.6 и даже 10 сделок в месяц — ничто».

## Что НЕ подтвердилось
- **Режимный гейт не объясняет деградацию 2025-26**: медиана режима по годам почти
  неизменна (0.94-0.98), хотя сам гейт работает (PF 1.43 при режиме >1.1).
- **Ужесточение чистоты импульса ВРЕДИТ**: откат ≤0.25 даёт 0.88 против 1.01 при ≤0.35.
  🔑 Связь не «чем чище тем лучше», а **чистота диктует ГЛУБИНУ входа**: чистый импульс
  не даёт глубокого отката → его надо брать на 0.236, рваный — на 0.382.
- **|vdr| (перекос инициаторов) НЕ работает**: 1.12 / 1.11 / 1.04 — обратный слабый градиент.
- Объём >1.5× среднего — ЯД (PF 0.72), не «чем больше тем лучше».
