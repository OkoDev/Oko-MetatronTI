# 🔴 ФАНДИНГ — НЕ КОРЕНЬ АСИММЕТРИИ (21.08.2026)

Гипотеза роя (`sambanova`, единственная про фандинг): «лонги платят за удержание,
шорты получают — на 15m это накапливает издержки и убивает лонг».
Единственная версия, объяснявшая асимметрию МЕХАНИЧЕСКИ. Мы фандинг не учитывали НИКОГДА.

Данные: `ohlcv_cache.db` → `funding_rates`, 1 557 170 записей, 450 символов, 2022-2026.
Метод: для каждой сделки суммируем фактические ставки за окно удержания
(384 бара 15m = 96 часов ≈ 12 периодов по 8ч). Long платит сумму, short получает.
Покрытие: 20 624 сделки из 22 210 (93%).

## РЕЗУЛЬТАТ: НАПРАВЛЕНИЕ ВЕРНОЕ, ВЕЛИЧИНА МИЗЕРНАЯ
| сторона | медиана за 4 дня | среднее | доля ПЛАТЯЩИХ | худшие 10% |
|---|---|---|---|---|
| long | **+0.092%** (платит) | +0.023% | **76.4%** | +0.231% |
| short | **−0.072%** (получает) | +0.004% | 23.6% | +0.174% |

```
разрыв short−long БЕЗ фандинга: +0.700 п.п.
разрыв short−long С фандингом:  +0.718 п.п.
фандинг объясняет:              +0.018 п.п. = 2.6% разрыва
```
Сдвиг PF: long 0.96 → 0.95, short 1.31 → 1.31. **Практически ничего.**

🔑 **Асимметрия long/short НЕ в фандинге.** Гипотеза закрыта.

## ЧТО ВСЁ-ТАКИ ПОЛЕЗНО
1. **Измерена реальная величина издержки**, которую мы не учитывали: для long
   +0.023% в среднем, +0.231% в худших 10%. На фоне костов 0.35% это 7-66% добавки.
   Для длинных горизонтов (1d+) станет заметно — учитывать при замерах на старших ТФ.
2. Подтверждено: **76.6% ставок положительные** (толпа структурно в лонге), но
   СРЕДНЯЯ ставка отрицательная (−0.0036%) из-за редких выбросов до −3% при проливах.
   → судить о фандинге по средней НЕЛЬЗЯ, только по факту удержания.

## ЧТО ОСТАЁТСЯ НЕОБЪЯСНЁННЫМ
Разрыв +0.700 п.п. между сторонами на 15m. Живые версии (рой + мои):
- каскадность падений против фрагментированности роста (микроструктура);
- горизонт: цель −1.618 недостижима для long, максимум кривой на −1.0;
- токсичность филла: глубокие пробои чаще у лонгов (не резал по стороне);
- **разворотные против продолжающих импульсов** — проверяется, для long не мерилось.
