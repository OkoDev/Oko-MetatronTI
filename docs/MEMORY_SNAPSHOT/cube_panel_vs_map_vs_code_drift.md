## 🔴 Префикс `S` означает ДВЕ разные сущности

Первая версия аудитора выдала ложный конфликт «S14 = FUNDING_EXTREME» — парсер читал
сводную таблицу ДЕТЕКТОРОВ. То есть в проекте `S14` это и **сфера** (Execution), и
**сигнал** (FUNDING_EXTREME). На этом спотыкается не только скрипт.
