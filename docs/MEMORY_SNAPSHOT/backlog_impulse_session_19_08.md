## 🟢 ГОТОВО К ВНЕДРЕНИЮ (проверено OOS, в боте НЕТ)

### 1. Импульсная механика — главный результат сессии
```
импульс: ход >=3 ATR, контр-откат <=35%, <=60 баров, ТФ 1h
вход:    лимит на откате 0.382 · стоп: за начало импульса
цель:    LONG −1.0 · SHORT −1.618 (фибо-шкала от экстремума)
гейты:   объём импульса 1.0-1.5x · по тренду EMA200 · ATR/SMA100 > 1.1
фильтр:  LONG pivot_bounce_down_R1_1D · SHORT pivot_above_S1_1D
выход:   ФИКСИРОВАННЫЙ (БУ и трейл забирают до 25% дохода)
```
**OOS×OOS: PF 1.53, WR 56.2%, n=201.** Все 5 лет в плюсе (1.65/3.74/1.80/1.42/1.62).
Портфельно (кэп 8, риск 2%): **+8.4%/мес** три гейта · +6.3% с пивотом ·
**+8.6%** три гейта + ступени размера. На OOS×OOS ступени дают **+11.1%**.
Детали: [[impulse_fib_three_gates_oos]], [[impulse_wr_pivot_filters]].

### 2. Ступенчатый размер позиции по скору (гибкая система)
Непрерывный скор (объём·режим·тренд·пивот) монотонен по квинтилям: PF 0.95/0.89/0.92/1.04/**1.25**.
Размер 0.5x/1x/1.5x/2x вместо бинарного отбора: на OOS **+11.1%/мес против +6.7%**.
🔑 Кэп позиций режет 94% сигналов — фильтр не отнимает частоту, а ВЫБИРАЕТ, чем занять слоты.

### 3. Замена источника в боте
Сейчас крутится `choch_wavec` (OOS 1.07, 7 сд/мес, за сутки НОЛЬ сделок — 103 из 120
сетапов протухают за 12-барное окно). Импульсная механика лучше по всем параметрам.

## ⏳ НЕ ПРОВЕРЕНО (открытые вопросы)

- **Сокращение стопа** (прогон был запущен, результата нет): варианты за фибо 0.618/0.786,
  за экстремум отката, 1.5/2.5·ATR. Ожидание из [[stop_tightening_by_structure_dead]] —
  WR упадёт сильнее, чем выиграет риск.
- **Плечо и вместимость**: меньший стоп ТРЕБУЕТ больше маржи (позиция = риск/стоп),
  поэтому вместимость растёт только через плечо. Не посчитано, где ликвидация
  становится ближе стопа.
- **Обучаемая модель**: причина AUC 0.18-0.28 найдена — часть признаков ИНВЕРТИРУЕТСЯ
  по режиму. Стабильны: объём, волатильность. Инвертируются: тренд EMA200, пивоты
  (в нейтральном 2024 лифт −1.03 и −0.32). Учить можно только на стабильных,
  либо добавив режим в признаки.
- Усилители матрицы на 250+ монетах (проверены на 241) · связка двух независимых путей
  (гейты + волновая пропорция) · механика на 5m · `wl_breach` и `rangefade4h` зоны стопа.
