# 🔴🔴 ЗАКОН: СВЕРЯТЬ ЦЕНУ БД С ЦЕНОЙ КЭША ПЕРЕД ЗАМЕРОМ (05.09.2026)

Поймал Егор вопросом «STRAX +12 709%, WAVES +346% — невозможно?». Проверка показала:
не памп и не ре-деноминация, а **битые данные в `ohlcv_cache`**.

## Что в кэше

| символ | плоских свечей (o=h=l=c) | уникальных цен |
|---|---|---|
| **RAY/USDT** | **100.0%** | **1** (одна цена на всю историю) |
| STRAX/USDT | 85.1% | 5 973 |
| WAVES/USDT | 60.4% | 17 540 |
| XCN/USDT | 55.2% | 2 400 |
| SLP/USDT | 42.2% | 10 244 |
| CTK/USDT | 29.6% | 9 088 |

Всего по 15m: 479 315 плоских баров из 35 468 410 = **1.35%**. Символов с почти
константной ценой — 1 из 496.

## Что это делает с замерами

Сверка `entry_price` из `simulated_trades` с `close` бара кэша на 4 000 сделках:

| | доля |
|---|---|
| цена совпадает (<5%) | 84% |
| 🔴 **расхождение >5%** | **3%** |
| нет в кэше / вне диапазона | 12% |

3% несопоставимых сделок дали выброс **+12 709%** (STRAX: в БД вход 0.0110, в кэше 1.4174 —
в 128 раз), который поднял среднее по `oko_ote` до +52.8% при медиане −1.5%.

## ПРАВИЛО

**Перед любым замером на боевых сделках:**
```python
if abs(float(C[p]) - entry_price) / entry_price * 100.0 > 5.0:
    continue        # данные несопоставимы — это НЕ движение рынка
```
И **докладывать МЕДИАНУ вместе со средним**: медиана переживает такие выбросы, среднее — нет.
Расхождение среднего и медианы в разы = сигнал битых данных, а не находка.

## Почему это важнее, чем кажется

Мой вывод «oko_ote даёт +3.2%» держался частично на этих выбросах: после санитайзера
осталось +1.126% (медиана +0.962%) против контроля −0.325%. Находка выжила, но
вдвое слабее. Без сверки я бы доложил втрое завышенное число.

Это третья ошибка того же рода за один день: [[stop_kills_before_move_arrives]]
(`max_R_possible` без чтения определения), контроль не в том временном окне
([[tsl_be_close_before_move_okoote]]) и вот эта. Общий корень — **доверие к данным
без проверки самих данных**.

До этого — исключать их из замеров либо полагаться на санитайзер.
