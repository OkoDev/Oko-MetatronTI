**🔴 РЕТРАКЦИЯ 07.08: это был CONFOUND, тревога снята.** Я заявил «глобальный min_rr гонит систему
в убыток» — неверно. Гейт `min_rr=2.0` САМ отбрасывает RR<2, поэтому ведро RR<2 заполнено
пер-сорсовыми исключениями (`oko_ote: 0.1`, `radar: 0.5`, `ote_nested: 0.9`, `rangefade*: 0.95`),
а RR≥2 — всеми остальными. Сравнивались НЕ уровни RR, а РАЗНЫЕ ИСТОЧНИКИ.
Проверка ВНУТРИ источника:
| источник | RR<1 | RR 1-2 | RR 2-3 | RR≥3 |
|---|---|---|---|---|
| ote_nested (n9438) | 0.90 (n31) | **1.40** | **1.53** | **1.34** |
| oko_ote (n1587) | **2.54** | 2.03 | — | **0.32** |
У `ote_nested` градиента НЕТ (RR 2-3 даже лучший) — высокий RR не вредит. У `oko_ote` градиент
драматический. **Эффект зависит от ИСТОЧНИКА, а не от RR.** Глобальный гейт менять НЕ нужно.
Урок (третий раз за сессию): при разрезе по признаку проверять, не разделяет ли он на самом деле
РАЗНЫЕ ПОПУЛЯЦИИ. Родня: [[golden_keys_matrix_verdict]] (ATRChange), [[cluster_gate_market_wide_flush]].

## Прочее из этого прогона
- **Исполнение измерить НЕЛЬЗЯ**: `entry_price_lag_pct` у всех 2887 записей внутри ±0.05% —
  поле не ловит реальный филл (как `slip_pct` = все нули). Единственное живое: `entry_lag_seconds`
  разделяет монотонно (<30с −0.050% · 30-120с −0.336% · 2-10мин −0.405%) — быстрее регистрация лучше.
- **SHORT + кластер зеркало НЕ спасает**: SHORT всё PF 0.72 → кластер≥2 PF 0.94. Шорт мёртв окончательно.
- **MTF-конфлюэнция на настоящем SMC** (`scripts/golden_mtf_confluence.py`, впервые в проекте):
  структура 1h UP → **PF 8.09** (n72) против базы 2.06; структура 4h UP ВРЕДИТ (PF 1.53, безтоп10% −10);
  близость к недельному пивоту слегка вредит. Конфлюэнция как СКОР работает (скор1 PF 3.44 vs скор0 1.79).
  OB/FVG померить не удалось: при флеше цена уже пробила ближние зоны → почти нет совпадений.
- **🔑 SMC v2 с ГЛУБОКИМ окном** (`scripts/test_smc_deep.py`, 1h 600 баров / 4h 400): результат
  ИНВЕРТИРУЕТ классическое SMC. Наличие непробитой бычьей зоны спроса НИЖЕ цены **ВРЕДИТ**:
  зона 1h есть → PF **0.58** (МЕД −1.019%, 4/17 монет) · зона 4h есть → PF **0.68**
  · **ЗОН НЕТ → PF 2.51, МЕД +2.636%, безтоп10% +351, 15/18 монет** 🟢🟢.
  Механизм: есть зона снизу = флешу есть куда падать, движение НЕ закончено. Нет зоны = цена
  в «чистом воздухе», структура исчерпана → отскок. Для фейда покупать надо там, где зоны НЕТ.
  Четвёртая инверсия сессии: WPP помогает тренду/вредит фейду · кластер помогает фейду/вредит
  импульсу · дивергенция ключ 1h/яд 4h · SMC-зона снизу вредит фейду.

разница объяснима: big-flush эдж ТЕКУЩЕГО режима, и отскок после крупного флеша идёт дальше 1R.
**НЕ ВНЕДРЕНО** — требует частичного TP + трейла; инфра есть у radar_armed (tp_shares[40,30,30]
+ runner_pivot_trail/runner_tail/runner_swing_floor, config 190-204). Рекомендация: k=3.0 (робастность).

**❌ ДИВЕРГЕНЦИЯ и BIG-FLUSH ВЗАИМОИСКЛЮЧАЮЩИ** — настоящий `DivergenceDetector` проекта дал
**0 обнаружений на 670 сигналов**. Не баг: regular bullish требует, чтобы текущий WT был ВЫШЕ
предыдущего дна при более низкой цене, а big-flush срабатывает когда WT делает НОВЫЙ экстремум.
Дивергенция = всегда второе дно = ожидание. **6-е подтверждение «подтверждение = опоздание».**
**❓ EQH/EQL — выборки нет**: 4 случая из 670. Равные лои ниже цены при флеше почти не встречаются —
флеш их уже пробил (та же логика, что с SMC-зонами). Вердикта нет.
