**ЗАКОН (Егор 01.07.2026). Узкое место trend-following на линии — механизм исполнения стопа.**

## Суть
**Стоп, поставленный НА линию тренда (Supertrend trendup/trenddown, MA, trend-line), исполняется
биржей по КАСАНИЮ (intrabar touch), а не по закрытию свечи за линией.**
- Симуляция проверяла «свеча закрылась за линией» (`close` пересёк) → находила edge.
- Биржа: цена интрабар коснулась линии → стоп-ордер сработал → выход. Но свеча **НЕ закрылась**
  за линией = это был **свит ликвидности**, после которого цена **продолжила** в нужном направлении.
- Итог: вышли в убыток на движении, которое пошло В НАШУ сторону. Реальный edge ≠ симулированный.

## Почему симуляция врала (механика)
```
close-выход (sim):    выход только если bar.close за линией  → редко, ловит реальный разворот
touch-выход (биржа):  выход если bar.low/high коснулся линии → часто, ловит свиты (фитили)
Линия Supertrend цена ТЕСТИРУЕТ постоянно (фитилями) → touch-стоп выбивает на каждом тесте.
```
Подтверждено бэктестом сессии: atr_change Слой 0/1 на 4h с ИДЕАЛЬНЫМ close-выходом (held до обратного
флипа по close) → median −1.9%, sum%net минус. Даже идеальная close-симуляция не дала edge → на бирже
(touch) было ещё хуже. Edge был мнимый (R + close-sim). См. [[principle_measure_pct_not_r_LAW]].

## Правило применения
1. **НЕ ставить стоп НА линию, которую цена тестирует фитилями** (Supertrend, MA). Выход по линии —
   только по подтверждённому close-за-линией (требует ждать закрытия бара, не стоп-ордер на бирже).
2. Бэктест выхода-по-линии мерить ОБА способа: close-cross (оптимист) и intrabar-touch (реализм).
   Расхождение = размер иллюзии. Доверять touch-числу.
3. Стоп ставить за СТРУКТУРУ (swing-экстремум/пивот-уровень) с буфером, не за индикатор-линию —
   структурный уровень цена не тестирует так же часто. См. [[ote_production_drift_root]] (широкий SL за структуру).
4. Альтернатива trend-trailing: выход по обратному флипу через ОТЛОЖЕННОЕ закрытие (по close бара),
   а не стоп-ордером — но тогда нет защиты внутри бара (компромисс).

**Why:** trend-following edge живёт в редких больших трендах; touch-стоп на линии выбивает из них
свитами до разворота. Это вторая (после R-иллюзии) причина мнимых edge. **How to apply:** любую
стратегию с выходом «за линию» валидировать на intrabar-touch, стоп — за структуру не за индикатор.
