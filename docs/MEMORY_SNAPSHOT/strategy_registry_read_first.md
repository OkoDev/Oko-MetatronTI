1. **Вход на РЕТЕСТЕ, не на сломе:** `ote_retest_setups(provisional=True)` —
   слом CHoCH → OTE → первый бар отката в зону. `provisional` дорисовывает ногу live.
2. **Сторона — разворот у экстремума большого 4h-импульса** (`structure_trend`):
   SHORT у вершины восходящего · LONG у дна нисходящего. Mean-reversion ПРОТИВ HTF.
3. **Цели — OTE большого импульса** (0.5/0.62/0.705), стоп локальный тугой.

⚠️ Недостающее звено — **толпа/funding/OI у экстремума**, в OHLCV его нет
(отсюда `require_crowd: true`). Историчка выжата до WR 55 / безубыток.

алерты живут в method-shadow». Это РЕШЕНИЕ, не забытый флаг.
