# Принцип конфлюенции — ядро проекта

**Факт:** Когда N независимых механизмов указывают на один ценовой уровень — это реальный рыночный магнит. Не совпадение.

**Why:** Каждый источник = разные участники рынка с разной логикой (institution, retail, algorithm). Когда все они "согласились" на одной цене — там стоят ордера.

**How to apply:** Любая новая задача должна спрашивать: "Где добавляем конфлюенцию?" Не "добавим ещё один индикатор", а "добавим ещё одну сферу Куба которая подтверждает то же самое".

## Где уже работает (data-driven)

**Вход (ARCH-104):** `bull_div_1d + bull_fvg_4h + wt_os_4h` → WR=100%, avgR=+1.89 (n=29). Три сферы сказали "да" одновременно.

**Confirmations registry:** 25 типов с весами = gravity scoring для сигналов входа.

**TPSelector (ARCH-113):** gravity cluster тест, 16,877 дней × 20 пар:
- `psycho alone` @ dist=1.15%: reach=**94.4%**
- `pdh|psycho` @ dist=2.33%: reach=**72.9%**, n=1173
- `bear_fvg_4h|pdh|psycho|std_r1` @ dist=1.86%: reach=**63.5%**

**Combinator:** паттерны с 4-5 конфлюентных флагов → avgR=1.4-1.6, WR=80-86%.

## Ключевой инсайт из тестирования TP уровней (25.05.2026)

```
dist<2%:   reach 75-94% (зона максимального притяжения)
dist 2-4%: reach 50-65% (допустимо при конфлюенции 3+ источников)
dist >4%:  reach <50%   (только при gravity>=6)
```

**Парадокс близости:** при одинаковой дистанции больше источников НЕ гарантирует выше reach. Близость к entry важнее числа источников.

**Оптимальный scoring:** `score = gravity / dist_pct^1.5`
- Ближний слабый кластер выигрывает у дальнего сильного
- gravity=6 @ dist=2% → score=2.12 > gravity=10 @ dist=6% → score=0.68
