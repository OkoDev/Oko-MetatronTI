## История бага (как нашли — dev на грани)

**XLM 1h live 04.06** (пользователь поймал визуально, дорисовал красным):
zigzag_atr(depth=11, dev_mult=3.0) поставил вершину на **0.2674 (бар53)**, а
истинный higher-high был **0.2742 (бар66)** — выше на +2.54%.

## Trace (точная причина)
```
H 0.2674 (бар53) → НОВЫЙ свинг ✅
L 0.2425 (бар60) → НОВЫЙ свинг ✅  (dev 10.27% > thr 9.92%)
H 0.2742 (бар66) → dev=11.56% vs thr=11.89% → ОТБРОШЕН ❌ не хватило 0.33%!
L продлён → 0.215 (бар103)
```
`pivot_at` РАБОТАЕТ (0.2742 распознан как pivot @бар71). Косяк в dev-пороге:
движение от предыдущего low (0.2425→0.2742)=11.56% < thr(ATR×3)=11.89%.

## Корень
dev_mult=3.0 → порог ~12% на волатильном 1h. Реальный +2.5% higher-high «невидим».
На грани 0.33% потеряли истинную вершину → **импульс 0.221→0.2674 вместо 0.221→0.2742
→ OTE-зона смещена вниз.**

## Влияние
OTE строится на импульсе слома (find_setups_zz). Неверная вершина = смещённая OTE-зона
= вход/SL/TP по неверным фибо-уровням. Критично для движка генерации.
