## Корень = PRODUCTION DRIFT, НЕ look-ahead
- **Walk-forward аудит зоны** (60 симв): HTF-зона выжила 1566/3311 = 47% (look-ahead есть, завышал
  КОЛИЧЕСТВО вдвое). НО выжившие честные держат tp1 +0.375R WR **70%** — качество ок.
- **Разрыв бэктест/SIM WR68-70% → VST WR14-30%** = исполнение, не зона. Совпадает с
  [[ote_production_drift_root]] «прод WR16%». Три killer'а: slippage входа (цена уехала) +
  свеча-курок + тугой SL за свечу (выбивает проколом, [[stop_on_line_is_liquidity_sweep]]).
- **R vs %**: бэктест +0.375R звучит ок, но VST в % net = −0.5..−0.86%. R обманул ([[principle_measure_pct_not_r_LAW]]).

## ✅ ФИКСЫ ВЫХОДА (01.07) — BE-counterfactual доказал корень
**BE counterfactual** (пересим 122 BE-закрытых ote_nested на СВЕЖИХ ccxt-барах, держать до TP/original_sl):
- **69% дошли бы до TP**, 21% выбило бы original_sl, 12% висят.
- факт BE avg −0.121%/sum −14.8% → **БЕЗ BE avg +0.345%/sum +42.1% (+0.466%/сделка!)**.
- **BE душит прибыль** — избыточен (есть original_sl широкий + CHoCH-перенос). Егор был прав.
- oko_ote counterfactual n=9 (ничтожно) намекал обратное — НЕАКТУАЛЬНО: oko_ote ВЫКЛЮЧЕНА (Егор 01.07),
  ote_nested = единственная активная VST-стратегия → BE-отключение затрагивает только её (чисто).

**Применённые фиксы (config, обратимо):**
1. `max_entry_slippage_pct` 0.5→0.3 (гейт свежести, режет 54% обходящих slippage-сделок).
2. `use_breakeven: false` + `use_be_after_tp1: false` — BE отключён (душил, +0.466%/сделка потеря).
Защита выхода теперь = original_sl (широкий) + CHoCH-перенос (choch_sl_moved) + TSL (после +1R).
**⚠️ Нужен РЕСТАРТ бота** чтобы config подхватился. Мониторить VST-%-net с оживления после рестарта.

**TSL counterfactual (149 status=TSL сделок):** 70% дошли бы до TP, 27% выбило original_sl. факт TSL
avg −0.234% → БЕЗ TSL avg −0.154% (улучшение лишь +0.08%/сделка, vs BE +0.466%). **TSL режет СЛАБЕЕ
BE и убирать НЕЛЬЗЯ** — без него минус (широкий original_sl ловит 27% откатов с +1R на большой убыток).
TSL и режет (преждевременно), и защищает. Корень = широкий SL + далёкий TP (R:R 5-21), TSL костыль.
**TSL не убирать — настроить (позже активация/шире трейл) + пересмотр R:R (частичный TP ближе).**
Баг: `tsl_activated=0` у ВСЕХ 149 TSL-сделок (классификация сломана как BE→loss, [[be_exit_classification_findings]]).

**Why:** живая торговля = финальный арбитр; вход/зона работают (WR80%), корень был ВЫХОД (BE обрезал
69% на взлёте). **How:** судить live по VST-%-net с оживления (не SIM/БД/R); BE-выходы честно = non-loss;
counterfactual выхода — на свежих ccxt-барах (cache отстаёт). [[be_exit_classification_findings]] · [[ote_nested_edge_diagnosis]].
