**ФУНДАМЕНТАЛЬНЫЙ ПРИНЦИП: MTF-философия едина для ВСЕХ вложенностей и сигналов** (юзер 09.06).

HTF-приоритет — НЕ свойство FVG ([[fvg_htf_priority_midline]] был частным случаем), а **универсальный закон** для каждого сигнала/зоны/детектора в боте:

| Сигнал/зона | Иерархия весов (старший = сильнее) |
|---|---|
| **FVG** | 1D > 4h > 1h > 15m > 5m |
| **Order Block** | старший OB = сильнее опора |
| **CHoCH/BOS** | слом старшего ТФ важнее младшего |
| **OTE** | 4h-OTE > 1h-OTE (вход в 4h-зоне = риск ×10, [[ote_nested_mtf_strategy]]) |
| **Пивоты** | W > D > 4h |
| **EQH/EQL ликвидность** | старший пул = сильнее магнит |
| **Волны Эллиотта** | вложенность 1D→4h→1h→15m (фрактал, [[user_wave_runner_strategy]]) |
| **ЛЮБОЙ детектор** | вес ∝ ТФ |

**Правило:** старший ТФ = ОПОРА (держит зону, на midline 0.5 разворот), младший ТФ = ВХОД/ТРИГГЕР (можно протык фитилём, ≠ инвалидация). Анализ сверху вниз → вход снизу → цель/опора сверху. Это [[user_wave_runner_strategy]] (MTF-каскад $50→$7000) + ядро [[project_confluence_principle]] (Куб = конфлюэнция 11 сфер × MTF-иерархия).

**Why:** юзер 09.06 после FVG-подтверждения (15m держал 0.5, 5m протык): «MTF-философия едина для всех таких вложенностей и сигналов». Возводит частное наблюдение в общий закон. Это снимает эмоцию (его цель «оцифровать себя») — система判ит по иерархии ТФ, не по чувству.

**How to apply:**
- **Магниты/TPSelector ([[arch_two_smc_detector_sets]]):** вес КАЖДОГО магнита (OB/FVG/EQL/Fib/pivot) ∝ ТФ источника. Унифицировать: общий множитель веса по ТФ.
- **WAVE-WATCH:** сила алерта = Σ(сигналов) × вес ТФ. «HTF-зона + LTF-триггер» = сильнейший (опора+вход). Чистый LTF без HTF-конфлюэнции = слабый.
- **Гейты ([[ARCH-129-FLOW]] чистота потоков):** один общий механизм MTF-веса для всех детекторов, НЕ per-сигнал хардкод. Централизованно (= просьба юзера «централизованно хранить гейты»).
- **Куб:** это ребро между ВСЕМИ сферами — каждая сфера выдаёт сигнал со своим ТФ-весом в общий Bus.
