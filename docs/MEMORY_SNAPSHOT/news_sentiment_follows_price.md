Новостная сфера (`scripts/news_sphere.py` → `news_items` в `oko_feed/external_data.db`)
даёт часовой ряд тона. Замер 30.09.2026 на окне **08.07–15.09.2026** (1513 часов,
23 697 классифицированных новостей, BTC +21.8% за окно):

**Ряд следует за ценой, опережения нет.**
- corr уровня тона с ПРОШЛОЙ доходностью растёт с горизонтом: +0.09 (6ч) → **+0.235 (24ч)**,
  ВНЕ контрольной полосы циклического сдвига.
- corr с БУДУЩЕЙ ≈ 0 на всех лагах 1/2/3/6/12/24ч — внутри полосы, шум.
- Прямое доказательство: перед «бычьим часом» прошлая 24ч доходность **+0.82%** против
  базы +0.127%. Бычьи новости выходят ПОСЛЕ роста.

**Срезы (протокол [[feedback_verdict_protocol_egor]]):**
- Важность НЕ выделяет: `importance>=8` не лучше фона (Δ к базе +0.008 на 6ч, −0.109 на 24ч).
- Кластер НЕ помогает: кластер ≥4 однонаправленных — бычьи часы хуже базы.
- Подпериоды (июль +1.3% · август +24.9% · сентябрь −3.8%): знак Δ держится, величина нет.
- Альты (ETH/SOL/XRP): n бычьих часов 28/17/5 → [[law_sample_representativeness]], НЕ мерено.

**Проверенный артефакт:** «бычьи новости → цена хуже» (Δ −0.218%, на самой границе
перестановки [−0.215;+0.203]) после matched control на прошлую 24ч доходность падает до
**−0.094%** — то есть это в основном возврат после роста, а не новость. Ниже костов.

**Что НЕ закрыто:** тон как предиктор ВОЛАТИЛЬНОСТИ (размера хода), а не стороны —
сходится с [[stop_zone_survived_blind_test]]; календарь `upcoming_high_impact` (известен
ЗАРАНЕЕ, физически не может следовать за ценой) — единственный элемент сферы с
потенциалом опережения; всплеск ЧИСЛА новостей вместо тона.
