## Оговорка
Обе проверки живут в одной макро-эпохе (альты лили три года). Это утверждение о РЕЖИМЕ,
не о законе. При развороте альтов полярность может инвертироваться — поэтому по решению
Егора в новый shadow (`scripts/ote_cell_shadow.py`, pm2 `ote-cell`) пишутся **ОБЕ стороны**:
«шорт и лонг в клетку», чтобы при смене режима были данные, а не сожаления.
