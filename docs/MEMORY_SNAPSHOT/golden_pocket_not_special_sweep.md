# 📐 ЗОЛОТОЙ КАРМАН НЕ ОСОБЕННЫЙ — развёртка фильтров (11.08.2026)

## Зачем
Егор: «подгонка — нехорошо, нужно перепроверить». Развёртка детектора режима дала лишь
ЧАСТИЧНОЕ плато. Остались ТРИ оси, подобранные руками: границы зоны, порог стопа, порог кластера.
В каждую ось намеренно включён вариант **«фильтр выключен»** — иначе меряешь, какое значение
лучше, вместо вопроса «нужен ли параметр вообще».

Тонкость: границы зоны определяют, СУЩЕСТВУЕТ ли сигнал → постфактум не применить.
Решение: сбор по широкой зоне 0.45-0.95 с записью фактического уровня отката и PnL для
КАЖДОГО бара в зоне (до 8 на импульс) → любая узкая зона = подмножество с ПРАВИЛЬНЫМ
первым касанием. `scripts/test_cell_filters_sweep.py`.

## 🔑 ГЛАВНОЕ: уровень не работает, работает ГЛУБИНА отката
Каноническая зона ICT **проигрывает всем**, включая контрольный вариант «зоны фактически нет».
Плюс режет выборку впятеро (n=72 против 433) — узкая полоса пропускается между часовыми
закрытиями. Вывод: **«золотой карман» не несёт информации сверх «откат достаточно глубокий»**.

⚠️ Это переоценивает прошлые вердикты: ВСЕ наши проверки OTE
([[ote_zone_no_edge_even_on_correct_leg]], [[ote_impulse_assembly_choch_bos]]) гонялись по
КАНОНИЧЕСКОЙ зоне — то есть по самому слабому варианту. Мы мерили худший случай и делали
вывод о методе целиком. (Прямого сравнения нет: там не было ни режима, ни кластера.)
