# ❌ РЕТРАКЦИЯ «прорыва +1.78%» ожидающего лимита (23.07)

## Что было заявлено (22-23.07) и СНЯТО
Зона-свип ожидающего лимита на глубоком крае OTE-зоны показал «fill 29%, WR71, +1.72…1.78%/фил».
**ФЕЙК.** Канонический fib-свип Егора («нужны 0.618/0.705/0.786 реальной fib») вскрыл баг:

## Механика фейка (класс: перевёрнутая геометрия SL)
**83% сетапов (3459/4168) имеют хранимый SL МЕЛЬЧЕ fib 0.79** (тугой стоп у реакционной свечи,
ВНУТРИ зоны). Лимит на глубоком крае филился НИЖЕ собственного стопа → walk-forward мгновенно
«выбивал SL» по цене ВЫШЕ входа → формула net=(exit−lim)/lim бронировала ЛОСЬ как ПРОФИТ.
WR71 = доля перевёрнутых. Урок в копилку к [[oko_suite_trend_wt_validated]] (3 класса look-ahead):
**класс 4 — вход глубже стопа = профит из воздуха. В любом лимит-бэктесте проверять lim vs SL.**

## Что осталось ПРАВДОЙ после ретракции
- Реактивный лимит (reaction-close) = adverse selection, обречён ([[ote_entry_reaction_close_measurement_bias]]) — это стоит.
- Медиана отката = 0.70 зоны (≈fib 0.70); глубина отката РЕАЛЬНА, вопрос — работает ли вход там.
- Тугой хранимый SL НЕСОВМЕСТИМ с глубоким входом (с ним WR 5-6% — тест несовместимой пары, не метода).

## ✅ Честный тест (23.07): ВЕРДИКТ — НЕВЕРНО ДЕТЕКТИМ OTE (нога не та)
Вход на канонич. fib + **СТОП ЗА СТРУКТУРУ** (за fib1.0, буфер) + tp1, n=1076 топ-50:
| fib | fill% | WR | net/фил |
|---|---|---|---|
| 0.618 | 76 | 20 | −3.68 |
| 0.705 | 53 | 33 | −1.95 |
| 0.786 | 30 | **55** | **−1.07** |
ВСЁ в минусе. WR растёт с глубиной (механика отката верная!), но net отрицателен везде.
**Методом исключения** (реактивный=adverse selection ❌, глубокий+тугой SL=несовместимы ❌,
канонич.+структурный SL=минус ❌): **проблема НЕ во входе — ДЕТЕКТОР БЕРЁТ НЕ ТУ НОГУ**
(мельче разметки Егора; walk-forward WR38 подозрение → доказано перебором). Фрейм Егора
подтверждён. Чинить ВЫБОР ЗНАЧИМОГО ИМПУЛЬСА от метода Егора: [[method_egor_two_scale_entry]]
(len5/len50), ote_matrix/structure_trend значимые ноги, ТЗ `docs/OTE_METHOD_ENTRY_V2.md`.

**Why:** не дать фейку пережить сессию; Егор дважды снял мои артефакты (ожидающие vs реактивные;
канонические fib). **How to apply:** в лимит-бэктестах ВСЕГДА валидировать вход vs SL; тугой SL
только для реакционного входа, глубокий вход = структурный SL. Связано: [[stop_on_line_is_liquidity_sweep]],
[[method_egor_two_scale_entry]], [[ote_sim_edge_illusory_entry_slip]].

## 🏁 ФИНАЛ ДУГИ (23.07): полная конвергентная матрица — красная вся
ВопросЕгора «все ли данные сошлись в единой точке?» закрыт полностью: ноги 1:1 + fib-свип +
структурный SL + ТОЧНЫЕ пивоты OKO (S1/R1×2.003 — сдвиг за свип в самой формуле!) + FVG + полки
+ вложенные сетки + WT/медиана/стрелки + дивергенции + W-S2/R2. Лобовое правило красное во ВСЕХ
срезах (4.5г, топ-50). Лучшее: кластер≥2+WT<-30 = **−0.93%** (градиент схождения ЕСТЬ, знак нет).
- **Дивергенция = ловушка выживших**: WR17 −4.7% (глаз помнит R+ на удержанных днах, съеденные — нет).
- **W-S2 при глубоком откате тренд-ноги = нога мертва в 90%** (WR10) — зеркало atr_S2-шорта.
**4-е подтверждение: эдж Егора = ОТБОР+ТАЙМИНГ+СОПРОВОЖДЕНИЕ, не статический уровень.**
