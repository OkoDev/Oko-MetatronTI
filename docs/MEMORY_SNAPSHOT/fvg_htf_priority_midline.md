1. **HTF имеет БОЛЬШИЙ ВЕС:** 15m-FVG > 5m-FVG. Цена коснулась **midline 0.5** 15m-FVG → развернулась вверх (опора держит). 5m-FVG перекрыли НЕ полностью, но сходили глубоко (LTF можно протыкать фитилём, HTF держит зону).

Поэтому midline на чарте (добавлен 09.06 в chart_builder HTF-FVG overlay) — рабочий сигнал, не украшение.
3. **Глубина теста = сила зоны:** held@0.5 (HTF, сильная) → reaction@deep (LTF, можно протык) → full mitigation (зона мертва).
