## Что это за признаки (оба из правок Егора)

**Свежесть состояния** — сколько баров подряд держится текущее состояние `wt1 > wt2`
(или `<`). Правка: «кросс действует ДО ОБРАТНОГО кросса» → мерить СОСТОЯНИЕ и его
длительность, а не «давность последнего кросса» (та метрика смешивала: после обратного
кросса состояние другое, а счётчик продолжал считать). Работает СВЕЖЕЕ (0-5 баров),
вызревшее (6-15) убивает: PF 0.66 / OOS 0.91.

**Медиана SMA(50) по wt1** — правка «с длиной можно поиграться». Эталонная EMA(200)
из Pine вырождена: делит выборку 2/98, признака нет. SMA(50) делит 23-26%.
Сетка каналов WT (7/14 · 10/21 · 14/28) разницы не дала — 2.05/1.98/1.98, шум.
Менять каналы не нужно, менять медиану — принципиально.
