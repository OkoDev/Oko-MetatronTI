# 🟢🟢🟢 BIG-FLUSH: эдж в РАЗМЕРЕ сетапа, а не в таймфрейме (30.07.2026)

## Как нашли
Егор: «частота наверняка живёт на меньших ТФ». Я до этого объявил **15m мёртвым** (медиана −0.21..−0.29%,
минус в оба года) — это была **ошибка усреднения**. Гипотеза о причине: на 15m стоп 0.3-0.5% против
костов 0.15% = косты съедают 30-50% цели. Значит умирал не ТФ, а РАЗМЕР сетапа.
Разрез по дистанции стопа вскрыл монотонную структуру (`scripts/golden_ltf_costaware.py`).

## 15m, ядро ATRTrend↑ + WT<−60 → LONG TP1R, по дистанции стопа
| стоп | медиана net% | вердикт |
|---|---|---|
| <0.5% | −0.450% | 🔴 |
| 0.5-1% | −0.692% | 🔴 |
| 1-2% | −0.558% | 🔴 |
| 2-4% | −0.295% | 🔴 |
| **>4%** | **+0.877%** WR57%, безтоп10%+110, монет+23/32 | **1.90 сд/мес → +1.67%/мес, оба года плюс** 🟢🟢 |

## Валидация (`scripts/golden_bigflush.py`) — ПЕРЕВОРАЧИВАЕТ survivorship-проблему
15m стоп>4%: ВСЕ n2225 МЕД+0.925% безтоп10%+283 монет+30/40 → +1.77%/мес
- **ЛИКВИДНАЯ половина ЛУЧШЕ: МЕД+1.194% WR61% → +2.18%/мес** (у 4h-ядра было НАОБОРОТ:
  ликвид слабый и 2025 отрицательный — см. [[golden_keys_matrix_verdict]])
- неликвидная: МЕД+0.683%, безтоп10% −32 🟡
- по годам: 2024 −0.010% 🔴 / **2025 +2.768% / 2026 +2.754% WR83% монет+39/39** 🟢🟢
5m стоп>4%: ликвидная половина плюсовая у **16/16 монет**, 2025 +1.05 / 2026 +1.24

## Стресс (`scripts/golden_bigflush_stress.py`) — ПРОЙДЕН по всем осям
- **Косты 0.15/0.25/0.35%** (флеш = широкий спред!): 15m стоп>4% держит до 0.35% →
  МЕД+0.994%, **+1.81%/мес**, безтоп10%+132, 16/20 монет 🟢🟢
- **Порог МОНОТОНЕН, не «нож»**: 3% слабый (🟡 безтоп10% отрицателен) → 4% / 5% / 6% все 🟢🟢
  с близким %/мес (2.18 / 2.14 / 1.87) и растущей медианой (1.19 → 1.67 → 1.95)
- 5m стоп>5% при костах 0.35%: МЕД+2.240%, +2.05%/мес, безтоп10%+818 🟢🟢

## Почему это лучший кандидат проекта
1. **Ликвидная половина сильнее** → survivorship не объясняет эдж, и это РЕАЛЬНО торгуемо
2. **2025 И 2026 сильные** (эдж текущего режима, а не прошлого как гибрид-раннер)
3. Частота вдвое выше 4h-ядра (1.83 против 0.94 сд/мес на монету)
4. Устойчив к костам ×2.3 и к порогу
5. Охват: 16/20 ликвидных монет, в 2026 — 39/39

## КАВЕАТЫ (честно)
- **2024 в нуле/минусе** → НЕ всепогодный, это эдж волатильного/чоп-режима. Как сменится режим —
  перепроверять (связано с предохранителем гибрида по доминации).
- Срез 2026 = 5 месяцев (кэш до 2026-05-31), n=203 на 15m.
- Sim входит по закрытию 15m-бара; в реальном флеше проскальзывание может превысить смоделированное.
  Митигация: `entry_order_type: LIMIT`. Живой VST — единственный настоящий судья.

## Урок метода
**Не усредняй по неоднородному.** «15m мёртв» было правдой в среднем и ложью по существу — внутри
жил сильный подкласс. Правило: перед вердиктом «ТФ/сетап мёртв» — разрезать по РАЗМЕРУ движения
относительно костов. Косты — не константа вычитания, а ДОЛЯ цели.
