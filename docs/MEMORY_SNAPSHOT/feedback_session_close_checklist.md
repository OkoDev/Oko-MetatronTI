## Чек-лист закрытия сессии (выполнять по порядку)

### 1. Код и бот
- Если были изменения в Python-коде — проверить логи бота и БД (нет ли ошибок, работает ли фикс)
- Если рестарт ещё не выполнен — напомнить; если выполнен — подтвердить в production (логи/БД)

### 2. Git
- `git status` — проверить незакоммиченные изменения
- Если есть правки кода — предложить коммит с кратким описанием

### 3. Документация
- `TASKS.md` — закрыть завершённые задачи (не оставлять 🔴/🔄 на закрытых)
- `memory/current_state.md` — обновить: что сделано, что изменилось, next tasks
- `whats-next.md` — handoff для следующей сессии (что сделано, что осталось, на чём остановились)
- `START.md` — обновить дату + актуальный статус + приоритеты

### 4. DISCUSSION.md
- Проверить открытые вопросы к текущей роли — ответить перед уходом если есть

### 5. Финал
- TTS: "Сессия закрыта. [краткий итог]."

**Why:** 29.05.2026 — сессия закрылась без проверки рестарта и git. Пункты 1-4 регулярно упускаются. CLAUDE.md описывает правила но не собирает их в один actionable список.

**How to apply:** когда пользователь говорит "закрываем сессию" / "спасибо за работу" / "до свидания" — пройти этот чек-лист сверху вниз перед финальным TTS.
