## Ключевой принцип

"Мы не угадываем рынок! Мы торгуем то что он нам показывает!"

### Что это значит для кода:

1. **WT кросс = обязательное подтверждение**, не бонус
   - Просто нахождение WT в зоне OS/OB — недостаточно для сигнала
   - Нужен реальный кросс (wt1 пересекает wt2) в зоне → подтверждение разворота
   - Без кросса на entry TF → сигнал НЕ генерируется (`return None`)

2. **Смена тренда + кросс в зонах** — вот что важно
   - LONG: WT кросс UP в зоне OS + тренд разворачивается
   - SHORT: WT кросс DOWN в зоне OB + тренд подтверждает

3. **Не добавлять "предсказательную" логику**
   - Никаких fallback-ов "ну раз alignment хороший, войдём без кросса"
   - Рынок должен ПОКАЗАТЬ разворот, прежде чем мы войдём

4. **TSL = основной стоп**, не ATR и не проценты
   - "В первую очередь мы учимся не терять деньги"
   - TSL-линия (trendup/trenddown) = структурный стоп, привязан к рынку
   - Плотный TSL = маленький убыток = правильно
   - НЕ расширять стоп до ATR 1-2% если TSL плотный
   - ATR/volatility = только fallback когда TSL недоступен

5. **Confluence тоже без угадываний**
   - WT_CROSS обязателен и для Confluence (уже реализовано)
   - Без кросса → score хоть 100 → сигнал не выдаётся
