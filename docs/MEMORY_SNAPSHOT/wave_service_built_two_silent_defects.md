# ✅ WaveService СДЕЛАН — и вскрыл два молчаливых отказа (29.08.2026)

`core/intelligence/wave_service.py`, 10 тестов. Реализована НАПИСАННАЯ спецификация
`docs/CUBE_SUBCUBES.md` §Sub-куб 2, а не новая выдумка. Задача висела с 08.06 в
11 недельных дайджестах с пометкой «готово» ([[cube_panel_vs_map_vs_code_drift]]).

## Сверх спеки — требование Егора про память

- `history(sym)` — 64 последних снимка разметки, а не только текущий;
- **факт ПЕРЕСЧЁТА счёта** как событие + счётчик `wave_recounts`. По канону слом счёта
  означает, что прошлая разметка была неверной. Раньше его не видел никто, потому что
  каждый прогон считал с нуля.
  Слом = падение номера волны больше чем на 1 за такт ИЛИ переход `wave5_final → wave3_mid`
  «через голову».

## 🔴 ДЕФЕКТ 1: поля шины не существовали

`PairContextBus.update()` молча роняет неизвестные ключи в `logger.debug`. Полей
`elliott_*` / `wave_*` в `PairState` не было — сервис «работал» бы, а в шину не попадало
бы **ничего**. Заведены до подключения (+13 строк, только добавления).

🔑 Правило на будущее: **перед публикацией новой сферы в шину — проверить, что поля есть.**
Отсутствие поля не даёт ошибки, только debug-строку.

## 🔴 ДЕФЕКТ 2: спецификация опиралась на несуществующее поле

`_detect_phase` по спеке берёт `htf_price_dir` из `prev_ctx`. Грep по всему проекту:
**единственное упоминание — в самом сервисе**. Поля нет ни в `PairState`, ни в коде.
По спецификации фаза **всегда** возвращала бы `undefined` — тот же класс, что панель Куба,
рисующая несуществующие сферы.

Лечение: сервис считает направление САМ по определению из `ENCYCLOPEDIA` («направление HTF
последних 5 баров: up/down/flat»), порог **0.5 ATR за окно**, а не фиксированный процент
(процент не переносится между инструментами, [[twins_15m_stabilized_by_measure]]).

| | до лечения | после (20 монет) |
|---|---|---|
| `wave3_mid` | 0 | **9** |
| `impulse_start` | 0 | **7** |
| `undefined` | **100%** | 4 (20%, где рынок реально плоский) |

## Причинность

`find_swing_highs(series, period)` подтверждает пивот через `period` баров с каждой стороны,
поэтому хвост ряда НЕ окончателен. Снимок несёт `unconfirmed_bars` и не выдаёт хвост за факт
([[detector_lag_is_a_parameter_not_statistics]]).

## 🔴 НЕ подключено к `scan_loop` — намеренно

Бот в момент работы торговал (11 открытых позиций `ote_nested` + 8 `impulse_fib`). Правка
живого цикла ночью без присмотра рискует управлением позициями. Сервис проверен на реальных
данных отдельно; точка подключения и порядок ввода (SHADOW → накопить → потом решать про
гейт) записаны в `TASKS.md` ARCH-132.
