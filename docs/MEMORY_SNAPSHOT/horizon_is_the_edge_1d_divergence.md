## Тот же тест на младших ТФ — минус везде

1h: лучшая схема «только стоп до выбива» PF 0.91 (−0.300%); брутто контроля ≈ **ровно ноль**
(−0.355% при костах 0.35%) → дивергенция не убыточна, она просто не даёт преимущества.
4h: лучшая PF 0.94 (−0.188%). Монотонность 1h → 4h → 1d держится.

⚠️ Ошибка реализации, которую пришлось чинить по ходу: сначала входил НА дивергенции,
и выход по смене тренда срабатывал через 1–2 бара (дивергенция идёт ПРОТИВ тренда).
Правильно по Егору: дивергенция = КОНТЕКСТ, вход = первая смена ATRTrend в нужную
сторону в окне ожидания.

## Чему НЕ верить
- n=1011 всего на 1d, по типам 74–197 — мало. Проверка на 150 монетах запущена.
- Безтоп10% отрицательный везде (−3478), медиана −4.4% → **хвостовая стратегия**:
  40% сделок платят за 60%. Для трендследования это норма, но требует другого
  риск-менеджмента и психологической готовности к длинным сериям минусов.
- Охват 57% монет — не подавляющий.
- 1d агрегирован из 1h (в кэше нет отдельной дневной таблицы).

## Следствия для проекта
1. **Не строить новый комбинатор.** 14 789 паттернов уже намайнено; причинно из 153
   проверенных плюсовых 5 — уровень случайного перебора. Больше признаков → больше
   ложных находок ([[arch104_remeasured_causal_fvg]]).
2. Нести накопленный инструментарий (SMC, конфлюэнция, режим) НА 1d, где база нулевая
   и сигнал добавляется, а не отыгрывает косты.
3. 300+ пар — ресурс для КРОСС-СЕКЦИИ (сравнение монет между собой), а не для частоты.
   При недельной ребалансировке косты размазываются на дни, а не на часы — не проверялось.
4. Отбор ВСЕЛЕННОЙ может стоить больше отбора сигнала: охват стабильно 50–83%.
