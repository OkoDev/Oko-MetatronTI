# 🧱 СТРУКТУРНЫЙ ГЕЙТ «ТОЛЬКО ПОСЛЕ BOS» — в бою на bigflush15 (11.08.2026)

## ✅ ПЕРЕМЕРЕН 13.08.2026 — ПОДТВЕРЖДЁН на 15m, ИНВЕРТИРОВАН на 4h

Единственная из ПЯТИ перепроверенных находок, которая устояла
(остальные см. [[law_recorded_pf_needs_remeasure]]). `scripts/bos_gate_revision.py`,
движок проекта `run_structure`, полная база фейда, причинно (BOS по бару подтверждения):

| срез (LONG) | **15m — где гейт В БОЮ** | 4h |
|---|---|---|
| база без гейта | 1.27 (n=1667) | 1.39 (n=2542) |
| **len5 ≥1 BOS** | **1.49** (n=868), p=**0.011** ✅ | **1.09** (n=1045) ❌ |
| len5 НЕТ BOS | 1.10 | 1.63 |
| len50 ≥1 BOS | **0.48** (n=234) ❌ | **2.32** (n=584), безтоп10% +897 ✅ |

**Запись «шкала len5 критична, swing50 вредит» ВЕРНА — но только для 15m.**
На 4h всё зеркально: помогает len50, вредит len5. **Гейт ТФ-специфичен:
шкала структуры должна соответствовать таймфрейму сигнала.**
Масштаб чуть скромнее заявленного (1.27→1.49 против 1.53→1.79) — разница от полной базы
против bigflush-базы, но знак и значимость держатся.

По годам на 15m (len5≥1 против базы года): 2024 **1.19** против 1.07 · 2025 1.43 против 1.45 ·
2026 **2.77** против 1.71. Связка со вторым законом: `len5≥1 + стоп 8–12%` → PF **4.26** (n=134).

🟢 **Вывод для боя: гейт настроен ПРАВИЛЬНО, менять не надо.** Если когда-нибудь
переносить на 4h — переключать шкалу на len50.

## Откуда взялся
Из мысли Егора «импульс надо складывать через CHoCH и BOS» ([[ote_impulse_assembly_choch_bos]]).
На OTE это дало починку разметки, но упёрлось в безубыток. Зато САМО ПРАВИЛО оказалось
не про фибо, а про любой структурный вход — и легло на живое ядро.

## 🔑 ГЛАВНОЕ: гейт отделяет ХРУПКУЮ половину, а не просто поднимает среднее
База БЕЗ гейта **проваливает тест хрупкости** (безтоп10% −277%), с гейтом проходит с запасом
(+634%). Балласт — ровно сетапы без BOS: PF 1.05, плюс лишь на 56 монетах из 100. Мы их
торговали деньгами.
- **ШКАЛА КРИТИЧНА**: len5 работает (1.79), swing50 ВРЕДИТ (0.91). Флеш ломает ВНУТРЕННЮЮ
  структуру, не старшую.
- **8-е подтверждение «подтверждение = опоздание»**: бычий CHoCH перед входом PF 0.78.
- Механизм: фейдить надо дислокацию, которая реально вывихнула рынок. Согласуется с
  [[autocorr_regime_key_fade]] (фейд платит в импульсном) и [[cluster_gate_market_wide_flush]].

## Что внедрено (11.08)
`bot/loops/rangefade_loop.py` → `_bos_down_count(kl, bars=20)` (движок `oko_sm_engine`).
- **ГЕЙТ**: `config.yaml` → `trading.rangefade.bigflush_min_bos: 1`
- **САЙЗИНГ ×1.5** при ≥2 BOS (альтернатива бусту по фондированию, потолок `risk_mult_cap`).
  В гейт ≥2 НЕ ставим: частота падает вшестеро (0.17 против 0.96 сд/монету/мес), по %/мес
  выигрывает более частый ≥1 BOS (+1.25%/мес против +0.42%).
- Фича `rf_bos_dn` пишется в сделку.
