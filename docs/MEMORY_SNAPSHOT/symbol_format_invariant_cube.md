18.09.2026. Найдено по наводке Егора «проверь сделки! похоже они только в симуляции» — и оказалось шире, чем waves_long.

**Цепочка одного символа.** `bot/loops/market_data_loop.py` (Сфера 19, в бою с 01.09) публиковал OI/фандинг как
`f"{sym}/USDT"`. Шина (`PairContextBus`) ключи не нормализовала → на монету появлялась вторая запись рядом
с `GUN/USDT:USDT`. Дальше по цепочке:
1. `all_symbols()` отдаёт обе → `impulse_fib`, `impulse_fib_15m`, `choch_wavec` берут «голую» пару (26 VST-сделок);
2. `AccountRouter` (sticky symbol→account) считает её НОВОЙ и назначает least-loaded — часто второй аккаунт;
3. `account_id` в БД берётся из роутинга В МОМЕНТ регистрации, а запись роутинга создаётся ПОЗЖЕ при открытии
   → в БД аккаунт 1, позиция на аккаунте 2;
4. детектор сирот (`orphan_autoclose: live`) на аккаунте 2 не находит позицию в БД → **закрывает по рынку через
   минуту после входа**. В логе: `[D-070] ORPHAN SKY/USDT:USDT LONG … → [autoclose][live] ЗАКРЫТ market`;
5. `tsl_updater` не находит SL/TP («нет SL orderId и qty=0 — ORPHAN»).
Пострадали: всё семейство waves_long первой ночи (вход и выход по одной цене), у impulse_fib_15m — INJ, ARB,
MMT (−5.05%), STRK висел OPEN. Лимитные заявки impulse_fib в основном отменялись и не пострадали.

**Второе следствие:** данные Сферы 19 лежали под `GUN/USDT`, а `arch104_signal_adapter` и `risk_intelligence`
читали `funding_pct_8h` по каноническому ключу → 0.0. Гейты по фандингу 17 дней работали вхолостую.

**Фикс (коммиты `e6f29d1`, `b633d8f`):** `PairContextBus.canon()` приводит любой формат любой биржи
(GUN-USDT, GUNUSDT, GUNUSDT.P, BINGX:GUNUSDT.P, GUN/USDT, GUN_USDT, регистр) к `BASE/USDT:USDT`; первое
приведение каждого символа — WARNING, чтобы источник чинили, а не жили за счёт заплатки. Источник исправлен.
Егор: «все данные такого типа входящие в куб должны быть нормализованы… для нас это не должно быть проблемой».

**Урок:** «сделки не доходят до биржи» на дашборде означало ровно обратное — биржа исполняла, а бот сам убивал.
Диагноз по дашборду ≠ диагноз по бирже: смотреть filled-ордера и позиции НА КАЖДОМ аккаунте.
