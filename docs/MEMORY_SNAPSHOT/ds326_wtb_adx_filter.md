DS-326 (18.06.2026, 45 пар, RR=3, история до 19.05): искали фильтр для дивергентного WT-B входа (mean-reversion, вход на 15m).

**Единственный работающий фильтр = `ADX < 25`** (период 14, на срезе 60 баров 1h). Выводит стратегию из безубытка в плюс:
- ltf_all (без фильтра): avgR −0.039, WR 34.5%, Sharpe −0.028, n=1628
- ltf_adx<25: avgR **+0.204**, WR **47.1%**, Sharpe **+0.142**, n=68

**Порог 25 — не подгонка:** скан показал edge только при <25; зона ADX 25–30 убыточна (<30 → avgR −0.068). Совпало с классической границей ADX «тренд/флэт». Смысл: WT-B divergence работает в СЛАБОМ тренде, в сильном — выносит против тренда.

**Что НЕ работает (отбросить):** EMA50/200-trend ВРЕДИТ (−0.180, хуже безфильтрового); CHoCH 4h слегка вредит (−0.087); n_down 0-2 не фильтрует (80% проходят). Комбо не добавляют поверх ADX (ADX+TREND n=6 пусто; ADX+ND02 ≈ чистый ADX).

**Гигиена/оговорки:** medR=−1.0 у ВСЕХ (RR=3, прибыль на хвосте раннеров — медиана варианты не различает, смотреть avgR+WR+Sharpe). n=68 умеренный → нужен out-of-sample. Edge чувствителен к комиссии/проскальзыванию (`simulate_trade` не учитывает). Lookahead исключён (фильтры читают только `df1h[:bar_idx]`).

**РЫЧАГИ EDGE (`scripts/ds326_edge_levers.py`, на ADX<25 n=68):**
- **TSL КРИТИЧЕН, НЕ вреден!** RR3 TSL on +0.204 → TSL off **+0.000** (WR 47→25%). Для контртренд-mean-reversion трейл = ЯДРО edge (движение ограничено, +3R редко достигается). 🔴 КОНТРАСТ [[tsl_no_trail_insight]] — там тренд/раннеры. **Эффект TSL зависит от ТИПА стратегии.**
- **SHORT >> LONG:** SHORT +0.258 (n=45) vs LONG +0.097 (n=23). Edge преимущественно шортовый.
- **div_strength 5-12 = sweet spot:** 5-8 +0.339, 8-12 +0.330; экстрим 12-20 **−0.064 (вредит!)**; слабые 3-5 +0.108. Сильная дивергенция = неразворачивающийся импульс.
- **RR 2.0-2.5 оптимум** (Sharpe макс RR2.0); высокий RR без TSL опасен (RR4 off −0.265).
- **КОМБО SHORT+div5-12+TSL RR2.5 = +0.370 (Sh +0.241, n=25)** vs baseline +0.217. Путь +0.204→+0.370 (~×2).
- **🔴 БОЕВОЙ hybrid TSL ХУЖЕ простого crude для wt_b** (интегрирован `compute_hybrid_tsl` в бэктест, реконструкция пути BE@0.5R→hybrid@0.8R default-профиль): RR3 ALL hybrid **+0.062** vs crude **+0.204** vs off 0.000; COMBO RR2.5 hybrid +0.245 vs crude +0.370 vs **off +0.540**. Причина: hybrid gear «дать дышать» рассчитан на ТРЕНДЫ/раннеры, а wt_b=контртренд (короткое движение, дыхание отдаёт прибыль) + глобальный BE@0.5R рубит в ~0R. Профиль wt_b в TSL_PROFILES = default (НЕ mean-rev).
- **Нюанс TSL по силе сигнала:** слабые (вся выборка) → TSL обязателен (off=0); СИЛЬНЫЕ (SHORT+div5-12) → TSL-off ЛУЧШИЙ (+0.540, дать дойти до TP). Один универсальный TSL это не ловит.
- **ACTIONABLE прод:** (1) tight-профиль для wt_b в `TSL_PROFILES` (зеркало ote_nested: тянуть туго, не дышать); (2) для качественных wt_b (div5-12) — TSL поздно/off + ниже `breakeven_activation_r`. Оговорка: sim_hybrid не 1:1 (cascade/min_move опущены), n combo=25.
