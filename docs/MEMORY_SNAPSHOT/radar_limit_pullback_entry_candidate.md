# 🟢 РАДАРУ НУЖНА ГЕОМЕТРИЯ ВХОДА, А НЕ ФИЛЬТР (22-24.08.2026)

Вопрос Егора: «что дать радару, чтобы он прозрел». Ответ оказался: не признак, а
точку входа. Фильтра в наличном арсенале НЕТ — 417 флагов матрицы + свои признаки +
дрейф вселенной прошли тест перестановкой как шум
([[radar_exit_is_fine_entry_is_broken]]). Осталась конструкция.

## Метод
Реальные сигналы радара (время, символ, сторона, стоп/цель из БД) переиграны по кэшу
15m: baseline — вход по цене сигнала (как сейчас), варианты — лимит на откате k%
с СОХРАНЁННОЙ геометрией (стоп и цель на том же расстоянии в % от входа).
Косты 0.35%, окно фила 8 баров, удержание 96. Обе ветки считаются одной процедурой.

## Результат: кривая МОНОТОННА в обеих независимых половинах
| откат | OOS по МОНЕТАМ (n=116→30) | OOS по ВРЕМЕНИ (n=145→50) |
|---|---|---|
| 0.0 (как сейчас) | **+0.48** | **−0.25** |
| 1.0 | +0.51 | −0.13 |
| 1.5 | +1.26 | +0.07 |
| 2.0 | +2.26 | +0.07 |
| **3.0** | **+2.58** | **+1.02** |

Слепой выбор по монетам: IS взял 3.0% → OOS **+2.58%/сд**. По времени IS промахнулся
(взял 1.0% на малой выборке), но направление то же: глубже откат — лучше результат.

🔑 Сходится с законом, доказанным на impulse_fib: **лимит на откате бьёт вход по рынку**.
Радар входит В МОМЕНТ всплеска, то есть по худшей цене паники/эйфории.

## 🔴 Цена и оговорки
- **Охват 26-34%**: при откате 3% семь сигналов из десяти не исполнятся. Частота падает
  втрое — для механики, дающей больше всех сделок, это принципиальная смена профиля.
- **Окно только ИЮЛЬ** — см. ниже про кэш. Один месяц, один режим.
- n=30 на OOS-монетах — мало; вердикт предварителен.
- НЕ проверено: достижимость лимита в бою (спред/глубина стакана), сторона, тип радара
  на OOS отдельно, поведение в бычьем режиме.

## 🔴 ПОБОЧНАЯ НАХОДКА: КЭШ ОТСТАЛ НА ТРИ НЕДЕЛИ
Последний бар в `ohlcv_cache.db`: **15m 2026-07-31 23:45**, 1h и 4h — то же 31.07.
Из-за этого все августовские сигналы молча выпали из замера (переигралось 224 из 330),
и слепой тест по времени IS(июль)→OOS(август) стал невозможен. Любой замер сейчас
незаметно сужается до июля. Докачать перед следующим исследованием.

## Формат вердикта
**Проверено:** монотонность кривой отката · два независимых слепых разбиения
(по монетам и по времени) · baseline той же процедурой · косты · чистота данных
(`ledger_mismatch` исключены) · тип радара, сторона, месяц в предыдущих прогонах.
**НЕ проверено:** август и другие режимы (кэш) · исполнимость лимита в бою ·
разрез по типу радара на OOS · размер стопа в связке с откатом.
**Вердикт предварителен до:** докачки кэша и повтора на окне 2+ месяца.
