# RANGEFADE — первый эдж, переживший прокурора (30.07.2026)

Егор дал мандат «найди золотую стратегию». Систематический причинный поиск (`scripts/golden_search2.py`,
8 семейств на 60-90 монетах 2024-26 с OOS-сплитом). 7 из 8 — минус или выброс (пробой/пивот-отскок/
объёмный всплеск/континуация — все арбитражены, медиана минус). **Выжил ОДИН:**

**rangefade_L:** `1h ATRTrend ВВЕРХ + WT(10,21) 1h < -60` (глубокий откат в аптренде) → **LONG, TP 1R,
SL = 3-барный 1h лоу ×0.997.**

**Стресс (`scripts/golden_stress.py`) — прошёл ВСЁ:**
- косты 0.10→0.25%: медиана +0.71→**+0.56%** (не костами держится)
- параметры WT{-50/-60/-70}×TP{0.8/1.0/1.5}: гладкий монотонный градиент, глубже WT = выше медиана
  (WT-70 TP0.8 мед+1.38%) — **не нож**
- per-coin: **74 из 90 (82%)** плюс-медиана — не 3 счастливчика
- **⚠️ КАВЕТАТ режим-зависим:** 2025 мед+1.34% / 2026 +1.10% / **2024 -0.46%** (в бычьем-трендовом
  2024 глубокие откаты не отскакивали; работает в боковом/choppy). НЕ всепогодный.

**Почему это НЕ мираж (в отличие от предыдущих):**
- фейд-радар (25.07) = выброс (медиана−, топ-3 несли) → [[detectors_two_poison_atr_wt]]
- H3 мин-рев (30.07, golden_search v1) = HTF look-ahead (merge_asof хватал формирующийся 4h);
  causal-фикс убил (мед+6%→−0.5%). rangefade использует 1h ATRTrend (свой ТФ, causal) — чисто.

**Решающий тест — ЖИВОЕ исполнение** (вся сессия: эдж умирает на филлах, SIM врёт):
`bot/loops/rangefade_loop.py` (gated trading.rangefade.enabled) — триггер из шины (wt_snap 1h:
wt1/atr_trend), SL из свежих 1h klines, router source=rangefade (exchange_enabled=true, VST, cap8,
risk1%, LIMIT). Табло (:8010 _TRACK) + forward machine судят LIVE. **Гейт: 20-30 VST net+ → реальные
деньги.** Если backtest +0.66% переживёт живое исполнение — первая доказанная авто-стратегия проекта.

Конфиг: `trading.rangefade` (wt_threshold -60, tp_r 1.0). Связано: [[principle_measure_pct_not_r_LAW]],

## 🎯 ПРИНЦИП-ЯКОРЬ Егора (30.07): что есть «золото»
> «Не ищем миллион на одной сделке — ищем СТАБИЛЬНЫЙ + на ПОВТОРЕНИИ ПРОСТОГО.»
Профиль искомого эджа: высокий WR + ПЛЮС-МЕДИАНА + много сделок + простое правило + быстрый TP.
НЕ fat-tail/лоттерея (тренд, ATR-TSL ride-the-runner = «миллион на одной» = ОТКЛОНИТЬ).
Метрика-цель: max(n × плюс-медиана × WR), НЕ max(сумма на выбросах). Валидирует median-first
прокурор. rangefade/rangefade4h = ровно этот профиль. Трендследование отвергнуто верно (лоттерея).
