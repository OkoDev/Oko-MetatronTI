Егор 20.09.2026: «мини-реальный счёт пока не могу дать, возможно позже». VST исполняет по ценам, которых нет
([[vst_phantom_fills_demo_matching]]), поэтому мера форварда — не VST-pnl, а переигрывание каждой заявки бота
(`simulated_trades` VST, включая CANCELLED-лимиты и OPEN) на публичных 5m klines BingX: лимит по `entry_price`, окно фила =
TTL источника (реестр `source_registry`: impulse/choch 12 ч, ote_nested 4 ч, остальные 30 мин), стоп до фила = нет сделки,
после фила стоп/цель по касанию (стоп приоритетнее), выход по времени через HOLD источника по close, косты 0.10.
TSL/BE/гибрид НЕ моделируются — это мера ГЕОМЕТРИИ сигнала на реальных ценах. Скрипт **`scripts/vst_real_resolve.py`** (с 27.09 в репо; был только в scratchpad),
отчёты `G:/oko_lab/out/vst_real_resolve_{14,33}d.txt`, данные `vst_real_resolve.pkl`.
