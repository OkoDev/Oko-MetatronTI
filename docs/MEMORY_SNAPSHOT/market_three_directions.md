Правило: у рынка **ТРИ состояния**, не два:
- **↑ вверх** — bull / +1
- **↓ вниз** — bear / −1
- **→ вбок (range/боковик)** — neutral / **0** ← часто забывают, сводя к бинарному

**Why:** «вправо» — это консолидация / накопление / распределение / equilibrium. Когда цена
не идёт ни вверх ни вниз, она идёт вбок — это полноценное третье состояние, а не «отсутствие».
Большинство времени рынок именно в range. Бинарный bull/bear теряет это → ML/майнинг видят
неполную картину. Пользователь 03.06: «рынок! у него три направления вверх вниз и вправо».

**How to apply:**
1. Канон направления (features_json/снимок) = **троичный** `dir ∈ {+1, 0, −1}` + `dir_label ∈ {bull, range, bear}`.
   НЕ бинарный bull/bear.
2. Направленные СОБЫТИЯ (FVG/OB/слом/OTE) сами по себе bull/bear (событие имеет вектор),
   НО рыночный **РЕЖИМ/контекст** = троичный (bull/bear/**range**). range = equilibrium,
   нет слома структуры, HH/HL/LH/LL смешаны, wt_sideways, цена у середины Premium/Discount.
3. Источники range в проекте: ARCH-124 RANGE-классификатор (`memory/arch124_regime_audit.md`),
   Premium/Discount **equilibrium** (`smc_engine.premium_discount`), wt_sideways.
4. Накопление (range перед ростом) vs распределение (range перед падением) — под-типы боковика.

Связь: [[arch124-regime-audit]] (RANGE мислейбл), [[oko-sm-pine-ob-fvg]] (Premium/Discount eq),
DS-314 (унификация направлений — добавить третий стейт). Куб: режим рынка = контекст для всех сфер.

## 🔴 ВЫВОД 03.06: regime-КЛАССИФИКАТОР ОТБРОШЕН (решение ARCH)
Принцип ↑↓→ ВЕРЕН, но **классификатор режима НЕ нужен** как ключ. Любой regime врёт/дёргается
(ARCH-124 доказал, 03.06 подтвердили визуально: ZigZag-regime держит bull на коррекциях; даже
Range Filter+Detector+debounce рабочий, но боковик стратегически не нужен). **Стратегия: торгуем
ДВИЖЕНИЯ** (волна Эллиотт + зона входа OTE/FVG/OB + TP-цели), боковик = промежуток, не сетап.
**Направление = ПРЯМЫЕ признаки** (ATR-trend atr_up/down + структура HH/HL), не классификатор.
regime_* удалён из combinator/bridge (коммит ba1336d, 75→71 признак). [[arch128-step2-features]].
