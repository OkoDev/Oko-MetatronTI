# 🔔 КЛАСТЕР-ГЕЙТ: торгуем залив, а не беду одной монеты (31.07.2026)

Егор: «у нас ведь есть все признаки и детекторы» — толчок проверить кросс-секцию НЕ по сырой
доходности (она мертва, [[crosssection_dead_at_our_costs]]), а по нашим сигналам.
`scripts/golden_cs_features.py`, BIG-FLUSH 15m, ликвидная половина, косты 0.25%.

## Структурный факт
Сигналы приходят КЛАСТЕРАМИ: 260 временных меток, из них 125 одиночных и 135 кластеров (до 20 монет
одновременно). **88% всех сигналов — внутри кластеров.** Это рыночный залив, а не независимые события.

## Результат 🟢🟢
| | n | WR | медиана | PF | безтоп10% |
|---|---|---|---|---|---|
| **одиночный сигнал** | 125 | 48% | **−0.218%** | **0.67** | −142 🔴 |
| **кластер (≥2 одновременно)** | 934 | 61% | **+1.232%** | **2.24** | +390 🟢🟢 |
| база (всё вместе) | 1059 | 60% | +1.094% | 1.95 | +227 |

**Механизм:** монета, залившаяся ОДНА — это её собственная беда (новость, реальный слом, делистинг),
падение продолжается. Монета, залившаяся ВМЕСТЕ с рынком — механический корреляционный слив
(ликвидации, риск-офф), она не «сломана» и отскакивает вместе со всеми.

**Первый фильтр за две сессии, который НЕ убивает частоту:** теряем 12% сделок (125/1059),
медиана +1.094→+1.232%, PF 1.95→2.24, безтоп10% +227→+390, и СУММАРНАЯ прибыль выше
при меньшем числе сделок (934×1.444 = 1349 против 1059×1.197 = 1268).

## 🔴 РЕТРАКЦИЯ внутри этого же теста
Сначала я прочитал результат как «самая экстремальная монета в кластере хуже остальных» (ранг-1
по глубине WT / размеру стопа / funding везде проигрывал). **Это был confound**: база сравнения
включала убыточные одиночные сигналы. Контроль показал: исключение ранга-1 даёт Δ медианы
**−0.007%** — пользы НЕТ. Ранжирование внутри кластера не работает; работает САМ ФАКТ кластера.
Урок: при сравнении подгрупп всегда проверять, не спрятана ли разница в третьей группе.

## Оценка советчиков (оба ошиблись по существу)
- **DS**: «топ-4 даёт эксцесс +1.2% против +0.3% у порогового отбора» — измерено, неверно.
- **Рой**: «монета с WT −90 откатывает вероятнее, чем с −61» — ЦЕНТРАЛЬНАЯ посылка, измерена,
  неверна (ранг-1 по WT: PF 1.84 против 2.32 у остальных). Плюс ошибка в счёте костов:
  «50 позиций × 0.25% = 12.5% просадки портфеля» — комиссия берётся с КАЖДОЙ позиции, не с портфеля.
Оба предложили Top-K; правильный ответ оказался — не отбирать лучших, а **требовать кластер**.
