# Следование тренду: WPP + WT>0< — компоненты работают, триггер нет (30.07.2026)

Егор: «проверь следование по тренду! 4H выше/ниже WPP даёт направление, каждая 1h/15m ATRChange
по направлению = вход, выход по TSL» + позже «не забывай про WT >0<».

## 🔴 Мой первый прогон был НЕВАЛИДЕН (2 нарушенных факта проекта)
`scripts/golden_trendfollow.py` дал всё красное — по МОЕЙ вине:
1. **Стоп поставил на ЛИНИЮ ATRTrend** — прямо там, где цена её пересекает при флипе → мгновенные
   выбивания (WR31-35%). Нарушен ЗАКОН [[stop_on_line_is_liquidity_sweep]]: стоп за СТРУКТУРУ.
2. **TSL работал с первого бара**, а в боте активируется ПОСЛЕ +1R.
Урок: перед тестом чужой стратегии сверить реализацию с задокументированными законами и с тем,
как это РЕАЛЬНО работает в боте. Иначе опровергаешь свою ошибку, а не гипотезу.

## ✅ WPP КАК НАПРАВЛЕНИЕ — ПОДТВЕРЖДЁН (`scripts/golden_tf_pocket.py`)
4h флип ATRTrend + SL swing12 в коридоре 2-6% + TP1R, 60 монет, контролируемый разрез:
| | медиана | PF | монет+ | годы |
|---|---|---|---|---|
| **по WPP** | **+2.954%** | **1.06** | **40/60** | +3.32/+2.73/+2.86 |
| против WPP | −2.561% | 0.91 | 25/60 | 🔴 |
| без гейта | +2.460% | 0.98 | 32/60 | 🔴 |
**Δ по/против = 5.5% медианы**, и без гейта система безубыточна → именно WPP делает её неотрицательной.
Согласуется с единственным многолетним выжившим (`atr_change` S2: флип 4h + cl<WPP, +0.471%/сд).

## ✅ WT >0< КАК ГЕЙТ СОСТОЯНИЯ — РАБОТАЕТ (`scripts/golden_wt_zero.py`)
Флип + WPP + **гейт WT>0 (лонг) / WT<0 (шорт)**, TP1R: n6384 WR53% МЕД+2.119% **PF1.05**
монет+**41/60** (против 33/60 без гейта), **плюс во все три года** (+2.15/+1.99/+2.32), 3.67 сд/мес.
Гейт чинит 2024 (+2.15 против −2.32 у «WT против»). Нулевая линия WT — не декор, а рабочий фильтр.
Как ТРИГГЕР кросс нуля не сильнее флипа: WR51%, PF 0.99.

## 🔴 ПОЧЕМУ ВСЁ РАВНО НЕ В БОЙ
- **Триггер слаб: WR 51-53%** при симметричной выплате 1R = монета, проигрывающая костам.
  Ни флип ATRTrend, ни кросс нуля WT не поднимают WR выше 53%.
- **Тест на хрупкость провален всюду**: безтоп10% отрицателен (−2871 у лучшего варианта) —
  сумма держится на десятке лучших сделок. PF 1.05 = шум.
- Сравнение с фейдом: big-flush LONG даёт **PF 1.83-2.04 и безтоп10% ПОЛОЖИТЕЛЬНЫЙ (+261..+585)**.
  Разница качественная, не количественная.

## 📐 TSL против TP1R — устойчивый компромисс (воспроизведён 3 раза)
TSL после +1R везде даёт **выше PF и сумму** (PF 1.10-1.20, сумма +1516..+1767%), но **медиана
отрицательная** — большинство сделок отдаёт назад свой +1R. TP1R даёт плюсовую медиану и меньшую сумму.
Механика Егора верна (раннеры бегут), но профиль = лотерея, которую он сам отвергает.
Цели 1.5R/2R медиану убивают (WR 53→44→38) — очередное подтверждение «TP1 чемпион, RR≥3 опровергнут».

## 🔑 ПРАВИЛО: один уровень — два противоположных режима
WPP-гейт **помогает следованию тренду** и **ВРЕДИТ фейду**: у big-flush LONG «по WPP» PF1.05,
а «против WPP» PF **1.93** (`scripts/golden_wpp_bigflush.py`, n1958, безтоп10%+409). Механика:
крупный флеш проваливает цену ниже недельного пивота = максимальная дислокация = сильнейший отскок.
→ Направленный фильтр нужен трендовым системам и противопоказан возвратным.
