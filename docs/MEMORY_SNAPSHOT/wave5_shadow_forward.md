(`scripts/pm2_wave5_shadow.config.js`, `pm2 save`); данные — `data/wave5_shadow/{state.json,
shadow_signals.csv, charts/, pm2_out.log}`. Два цикла: полная разметка после закрытия 4h-бара (UTC +3 мин),
watch каждые 15 мин (вход/исход/фибо-прогноз по активным). Вселенная BingX swap оборот ≥2M (358 монет).
Егор: «сверка разметки — цель, ждать недели нелогично; входы на 15m → цикл 15m; по разметке — прогноз по
фибо» → в CSV `w5_reached` (какие цели пятой достигнуты: w5_618/w5_eq1/w5_chan/w5_1618) и `corr_reached`
(corr_382/500/618/w4) — разметка подтверждается/ломается за часы. Блок «волны» в `/filter` :8010 (1h/4h); слой «Волны» на `/monitor` (`/api/waves`, drawWv, коммит 4949d8c 14.09).
Старая scratchpad-версия ниже — история.

Скрипт (история): `scratchpad\wave5_shadow.py` — импортировал детектор из `wave5_sm.py` той же папки.

**Что делает за запуск (~5 мин, 146 монет):** BingX swap через ccxt без ключей → 4h 1000 баров + 15m 16 суток →
только ЗАКРЫТЫЕ бары → на последнем 4h-баре `impulses_on_bar` (масштаб 15/4) → поля: фрактал, depth5,
чередование тип/форма, ns, канонический счёт (alt_*), дневная структура из 4h-ресемпла (10-дн свинги),
дневной WT, линия 2-4 (пробита/нет, когда), первый кросс WT на 15m, экстремум пятой на 15m →
состояние `shadow_state.json`: detected → entered (кросс или line24) → closed (цель/стоп/240 ч) →
`shadow_signals.csv` (колонка `egor` — ручная оценка: верно / степень / четвёртая не там / удлинение) →
`charts_shadow/<SYM>_<date>.png` (draw_trade с df=живые бары — иначе рассинхрон индексов с кэшем).

**Самопроверка `--asof`**: NEAR 2026-01-14T04:00 → шорт, фрактал ✓, канал 0.48, кросс 13.01 20:30 (= бэктест);
TURBO 2025-06-06T20:00 → ядро полное (канал 0.62, чередование ✓✓, WT1D −57). Для asof LTF/4h берётся из

**Ограничения BingX**: 15m ≈ 30 дней истории, 5m < 60, 1h/4h — глубоко. `[skip]` печатается громко.
Первый живой прогон: 1 сетап (CYBER лонг, фрактал ✗ → не ядро). Ожидаемая частота базы ~136/год/150 монет.

**Регламент**: запуск после закрытия 4h-бара (00:05/04:05/… UTC): `python wave5_shadow.py --pairs 150 --draw`.
Автозапуск (планировщик Windows) — только по слову Егора. Через 30-40 сетапов — доля верных разметок по типам
