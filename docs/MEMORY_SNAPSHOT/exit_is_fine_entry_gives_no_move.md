# 🔑 ВЫХОД РАБОТАЕТ, ВХОД НЕ ДАЁТ ХОДА (12.08.2026)

Проверка перед тем, как браться за п.5 очереди «выход по режиму» (предписание с июня).
Метод подсказал DS: выжать `captured_R_pct` и `max_R_possible` БЕЗ переигрывания.
55 816 закрытых сделок.

## Выход эффективен — гипотеза «выходим рано» ОПРОВЕРГНУТА
`captured_R_pct` = доля захваченного MFE (`r_multiple / max_R_possible × 100`):
| статус | n | медиана captured_R |
|---|---|---|
| TP | 4741 | **89.6%** |
| TSL | 13981 | **73.5%** |
| SL | 23426 | 0.0% |
| EXPIRED | 1580 | 4.5% |

Когда рынок даёт ход — мы забираем 74–90% его. **Рычага в выходе почти нет.**

## 🔴 ВХОД НЕ ДАЁТ ХОДА — вот где течёт
Распределение `max_R_possible` (MFE в R), n=54 448:
```
p10 −0.156   p25 +0.071   p50 +0.367   p75 +0.908   p90 +2.015   p95 +3.013   p99 +6.628
доля MFE ≥ 1.0R  — 22.8%   ← цель TP1R достижима лишь у каждой пятой
доля MFE < 0.35R — 48.9%   ← половина сделок почти не идёт в нашу сторону
```
p10 отрицателен: у каждой десятой сделки цена вообще НЕ шла в нашу сторону ни разу.
При стопе −1R и цели +1R, когда медиана хода +0.367R, система убыточна **структурно** —
никакая работа с выходом этого не компенсирует.

## Связка со всей картиной сессии
Всё сходится в одну цепь:
1. Живой вход не требует разворота WT ([[live_entry_differs_from_backtest_wt_rising]]) —
   бот входит, ПОКА WT под порогом, то есть в падение;
2. → цена после входа продолжает идти против: медиана MFE +0.367R, 48.9% <0.35R;
3. → TP1R недостижим у 77% сделок;
4. → живой поток убыточен (VST WR 26.5%, медиана −0.47%, сумма −9277%);
5. при этом выход и гейты работают верно ([[drops_counterfactual_gates_clean]]).

**Приоритет меняется: п.5 «выход по режиму» НЕ является денежным рычагом.
Рычаг — момент входа.**

## Оговорка
`max_R_possible` считается от `original_sl` с `clamp_r_smart`, MFE берётся по
экстремуму цены за время удержания — то есть зависит от TTL и правил выхода
(закрыли раньше → MFE меньше). Для TP/TSL это смещение мало (позиция жила до цели),
для SL — велико (закрылись быстро). Вывод «вход не даёт хода» опирается на
p50/p25 по ВСЕЙ выборке, где SL-сделки составляют 42% → **часть низкого MFE
объясняется ранним стопом, а не отсутствием движения**. Чистая проверка —
переигрывание пути из кэша OHLCV без стопа (дизайн DS, не выполнено).
