# 🔴🔴 ВЕТО ПО ФАНДИНГУ НЕ РАБОТАЕТ — ДВА НЕЗАВИСИМЫХ ДЕФЕКТА (01.09.2026, ARCH-129.1)

## Дефект 1: вето не получает данных вообще

`core/intelligence/risk_intelligence.py:141-144` проверяет
`inputs.funding_pct_8h` против `max_funding_pct: 0.03`.
Единственное место в БОЕВОМ пути, где `RiskInputs` собирается, —
`bot/loops/arch104_observer_loop.py:285-294`:

```python
context = {                       # «минимальный — TODO: расширить из bot state»
    "funding_pct_8h": 0.0,        # 🔴 КОНСТАНТА
    ...
}
```

**Порог не может быть превышен никогда.** Конфиг утверждает, что вето есть;
поведение — что его нет. Класс [[bug_gate_lives_in_two_places]].

## Дефект 2: единицы разошлись — порог мягче в 100 раз

Проверено по данным 01.09.2026, а не по названиям полей:

| источник | что отдаёт | пример |
|---|---|---|
| `ohlcv_cache.db.funding_rates.rate` | **ДОЛЮ** | BTC ≈ 0.00007 (= 0.007%), медиана рынка 0.00005, экстремум −0.03 (= −3%) |
| `DataCollector.get_funding_rate` | **ДОЛЮ** (ccxt `fundingRate`) | докстрока: «напр. -0.0008» |
| `risk_intelligence.max_funding_pct` | ждёт **ПРОЦЕНТЫ** | комментарий в коде: «# % за 8h» |

Подставить долю туда, где ждут процент, — это порог 0.03 вместо 0.0003.
Замер на 215 982 расчётах за 90 дней (445 пар):

| трактовка | сколько расчётов отсекается |
|---|---|
| доля против порога 0.03 (как было бы) | **528 = 0.24%** |
| проценты против порога 0.03%/8ч (как задумано) | **29 002 = 13.43%** |

То есть даже почини первый дефект — вето осталось бы почти немым.

## Что сделано

`core/context/market_data_sphere.py` (Сфера 19) конвертирует ЯВНО:
на вход доля (`as_fraction=True`, как у обоих источников), наружу `pct_8h` —
всегда проценты за 8 часов. Интервалы приводятся: в таблице сосуществуют
1ч (61 235), 2ч (493), 4ч (974 575), 8ч (520 867) — константы 8 быть не может.
Проверка: BTC 0.00007/8ч → +0.0070% · HYPE −0.000064/4ч → −0.0128%. Тесты 17/17.

## 🔴 Отрицательный результат: «серия» как гейт НЕ ГОДИТСЯ

Идея ARCH-129.5 была: ловить не УРОВЕНЬ, а СЕРИЮ (разбор HYPE 30.08 — сквиз
предупреждал последовательностью, а не экстремумом). Реализовано и измерено:

| порог серии | доля расчётов |
|---|---|
| \|серия\| ≥ 3 | **76.4%** |
| \|серия\| ≥ 20 | **43.1%** |

Фандинг устойчив по знаку — серия это норма, а не событие. **Как самостоятельный
гейт бесполезна.** Возможная ценность — в связке (серия × низкий перцентиль,
или РАЗВОРОТ длинной серии), но это не мерилось.

🔴 Случай HYPE 30.08 проверить на кэше НЕЛЬЗЯ: `funding_rates` заканчивается
2026-06-30, отставание около двух месяцев.
