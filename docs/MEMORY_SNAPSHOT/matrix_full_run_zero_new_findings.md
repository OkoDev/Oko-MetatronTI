## 🔴 НЕ проверено

- **КЛАСТЕР не посчитан вовсе** — механика не вернула `entry_ts` (добавлено ПОСЛЕ прогона);
- ликвидность — прокси по амплитуде импульса, а не оборот в долларах;
- 🟡 расхождение с прошлым замером: тогда «половина эджа в НЕЛИКВИДНОЙ половине»
  (2.88 против 2.02), здесь наоборот (1.28 против 0.85) — прокси разные, сверить;
- отбор ПОВЕРХ боевого дрейф-гейта не делался (пункт 1.1 плана) — база здесь широкая
  и почти нулевая, признак поверх неё найти труднее;
- n_perm=20 даёт шаг P около 0.05 — P=0.15 груба;
- 1h не прогонялся, только 15m.

## Способы, которыми результат может быть артефактом

1. **Ранжирование меняет исход.** Булевая ветка сортирует кандидатов по WR, числовая —
   по PF. `mkt_drift_slope` попал в топ-12 по WR и пережил OOS, но по PF в топ-12 не
   вошёл вовсе. То есть список, уходящий на OOS, зависит от метрики сортировки.
2. Булевая часть прогона шла со СТАРЫМ абсолютным порогом (правка легла после старта).
   ✅ Перепроверено на сохранённом parquet: 87 → 68 кандидатов, топ-12 и выживший те же.
3. База сама почти нулевая (PF 1.01) — критерий «лучше базы ×1.15» на слабой базе
   пропускает больше шума, чем на сильной.

## Гипотезы

1. **Искать не признак, а УСЛОВНУЮ матрицу.** В быке short даёт 3.13, в медведе 0.69 —
   возможно, в разных режимах работают РАЗНЫЕ признаки, и глобальный отбор их взаимно
   гасит. Прогнать отбор ОТДЕЛЬНО внутри каждого режима.
2. **Отбор поверх боевого гейта** (пункт 1.1): база станет сильной, и превышение над
   ней будет значить больше, чем превышение над нулевой.
