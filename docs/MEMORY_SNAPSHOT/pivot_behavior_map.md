**Измерение поведения недельных classic pivots (Егор 01.07: «как работают пивоты, где закономерности?»).
461 символ, 4h, 2022-2026, 47984 недель. Уровни из прошлой недели, без lookahead. Data-driven, НЕ гипотеза.**

## Reach rate (% недель коснулись уровня)
```
R1 39% · R2 19% · R3 10%   |   S1 43% · S2 17% · S3 6%
```
Первый уровень ~40% недель, второй ~18%, третий редко. S1>R1 (медвежий перекос данных: 60% недель
закрылись НИЖЕ P).

## 🔑 Bounce vs Break (коснувшись уровня — разворот к внутр. [bounce] или пробой к внешн. [break])
```
R1: bounce 50% / break 50%   НЕЙТРАЛЕН
R2: bounce 62% / break 38%   ← ДЕРЖИТ, сильный разворот
S1: bounce 46% / break 54%   НЕЙТРАЛЕН
S2: bounce 69% / break 31%   ← СИЛЬНО ДЕРЖИТ, сильный разворот
```
**Закон: вторые уровни R2/S2 = сильные точки разворота; первые R1/S1 = нейтральны (нужен режим).**

## Режимная асимметрия (BULL/BEAR по наклону недельного P) — логична
```
BULL:  S1 bounce 57% (откат выкупают)   R1 break 57% (сопротивление пробивают вверх, тренд)
BEAR:  R1 bounce 56% (отскок продают)   S1 break 62% (поддержку ломают вниз, падение)
```
Первые уровни торговать ТОЛЬКО по режиму: BULL→long от S1, BEAR→short от R1. Против режима = пробой.

## Что объясняет
1. **S2-чемпион (Слой 7):** S2 bounce 69% → цена доходит и разворачивается → **S2 = идеальная TP для short**.
   Механизм подтверждён, не совпадение. Симметрично R2 = TP для long.
2. **Провал level-bounce (Слой 10):** торговал S1/S3 (нейтральные/ломаются в BEAR) вперемешку по режимам
   + тугой стоп за уровень = свит. Торговал не те уровни. [[atr_change_pivot_short_thin_edge]].
3. **Торгуемая гипотеза ИЗ данных:** short на отбой от R2 (цель P/R1), long на отбой от S2 (цель P/S1)
   + первые уровни по режиму. Волна Эллиотта = фильтр ФАЗЫ поверх (5-я волна у R2 / C у S2 усиливают bounce).

**Скрипт** `scripts/pivot_behavior_study.py`. **Why:** развернулись от навязывания гипотез к измерению —
нашли реальные закономерности. **How to apply:** строить стратегию на R2/S2-развороте + режимных первых
уровнях, НЕ на S1/S3-bounce. Стоп НЕ тугой за уровень (свит) — за структуру/шире. Мерить в % net.

## 🔴 Слой 11 — R2/S2-отбой ПОДТВЕРЖДЁН как сигнал, но НЕ монетизируется стопом
Short R2→R1: **WR 65%, median +2.68%** (карта верна, R2 держит!). НО mean +0.007 (~0). Стоп-свип
показал вилку без выхода:
```
stop за R3 (широкий): WR 65% mean +0.01 — большие убытки съедают профиты
stop 1.5% (тугой):    WR 23% mean −0.32 — СВИТ выбивает до движения к R1
stop 2/2.5/3%:        WR 28-37% mean −0.36
```
**У R2-отбоя нет хорошего стопа:** тугой свитится (WR рушится 65→23%), широкий даёт большие убытки.
Long S2→S1 ещё хуже (mean −0.58, 2022 −3.65). **3-е подтверждение свит-барьера** (stop-on-line/level/fix).

## Слой 12 — структурный swing-стоп ТОЖЕ свитится (все 3 стопа испробованы, барьер окончателен)
Стоп=swing-high/low K5/10/20 + выход на уровнях (R1/ladder R1+P): Sh_R2 mean −0.15..−0.21 WR 42-45%
(ХУЖЕ R3-стопа 65%!). Причина: **вход У экстремума → swing-структура = сам R2-прокол = свит-зона**
(даже K20 swing≈R2-прокол, он высший). Итог по ВСЕМ стопам R2-отбоя: R3(далеко)=WR65%/mean0/большие
убытки · фикс%(тугой)=WR23%свит · структурный=WR45%свит. **R2/S2-отбой НЕ монетизируется никаким
стопом — вход у уровня-экстремума делает защиту либо свит-зоной либо дорогой. Структурное свойство,
не недобор параметра.** Скрипты `_layer11_r2s2.py` `_layer12_structexit.py`.

## 🎯🎯 МЕТА-ВЫВОД сессии (сэкономит итерации)
Все pivot/level/atr_change направленные подходы: находим РЕАЛЬНЫЕ стат-закономерности (R2 bounce 62%,
WR 65%, зеркальная режимность, S2-цель) — но **НИ ОДНА не конвертируется в устойчивый % net после
реалистичного исполнения** (свит тугих стопов / costs / режимная концентрация). Барьер системный:
волатильность крипты у уровней выбивает защиту. **Монетизируемого direction-pivot edge в лоб НЕТ.**
Оставшиеся неисчерпанные идеи: (1) выход БЕЗ стоп-лосса (time/opposite-signal exit, раз стоп свитится);
(2) волна как фильтр фазы (только завершённый импульс у R2/S2); (3) вернуться к ЖИВОМУ ote_nested
(mean-reversion работает). Мерить всё в % net ([[principle_measure_pct_not_r_LAW]]).
