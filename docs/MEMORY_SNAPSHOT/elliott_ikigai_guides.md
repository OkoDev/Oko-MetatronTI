## ДВИЖЕНИЕ (5-волновой импульс)
ПРАВИЛА (всегда): волна2 НЕ за начало в1; волна3 НЕ самая короткая (1,3,5); волна4 НЕ на территории в1. Нарушено → не импульс.
ФИБО: **в2=0.618 в1** (←НАШ OTE-вход!); в4=0.382 в3; **в3=1.618 в1** (цель!); в5≈100% в1 ИЛИ 0.618 в3.
НОРМЫ: чередование (в2 острая→в4 боковая); растяжение в3/в5 (если в3 растянута→в5 ограничена); диагонали (начальная=в1/волнаA, конечная=в5/волнаC).

## КОРРЕКЦИИ (против тренда, 3-волновки)
- **Зигзаг A-B-C**: B не за основание A, **C выходит за конец A**; B=0.618 A; **C=1.0/1.618 A**. Бывает в в2/в4 импульса.
- **Двойной зигзаг W-X-Y**: X не за основание W, Y за конец W; X=0.618 W; Y=1.0/1.618 W.
- **Треугольник A-B-C-D-E**: сужение, C не за A, D не за B, E не за C; каждая ≈0.618 пред.; **обычно волна 4**.
- **Плоскость A-B-C**: B откат ≥90% A; B=1.236/1.382 A; **C=1.618 A**.
- **Комбинация W-X-Y**: X откат ≥90% W. Редкая.

## КЛЮЧ для детектора
OTE-вход 0.618 = **конец зигзага-волны-2** → ловим **волну 3** (цель 1.618×в1 = measured move = большой R). Вход в треугольник/плоскость/середину коррекции = слабый ход (MFE 1R). Конец коррекции (C вышел за A) = старт нового импульса. Эллиотт СУБЪЕКТИВЕН → движок даёт вероятностную разметку+confidence, не истину; чистые тренды лучше боковиков.
