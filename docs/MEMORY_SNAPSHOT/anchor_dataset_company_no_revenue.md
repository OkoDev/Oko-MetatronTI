# ЯКОРЬ: «Датасет-компания есть — только она не приносит денег и не торгует в плюс» (Егор, 24.07.2026)

Лучшая одностроч ная диагностика проекта. Контекст: после полной инвентаризации (103M свечей,
1.56M funding, 24 pm2-процесса, порты индикаторов, движки, контент-фабрика) и честной поправки
(чистая эра 4622/49417, ML не торгует).

**Why:** активы реальны, но выручка $0 и торговля в минус → проблема НЕ инженерная (строить
умеем), а ПРОДУКТОВАЯ (ни один актив не превращён в деньги). Постоянный риск Даат — строить
ещё один движок вместо продажи готового ([[daath_personal_rules]] тень: усложнение как побег).

**How to apply:**
1. НЕ строить новых сфер/движков — датасет-компания укомплектована.
2. Каждый следующий шаг мерить вопросом: «приближает ли это ПЕРВЫЙ РУБЛЬ?» Функционал ради
   функционала — отклонять, цитируя этот якорь.
3. Кандидаты первого рубля (по вердикту DC в DISCUSSION): TG-radar (Продукт №2, стек живёт) ·
   структурный скринер-web (пустая ниша: SMC+макро без TV) · data-API (FEED-SPHERE).
4. «Честность-как-фича»: маркетинг только на чистой эре + прозрачной разметке грязи — не путь гуру.

Связано: [[phase_sphere_decision_core]] (последняя автономка), [[oko_sm_engine_ported]],
[[marketcap_dominance_engine]], [[insta_content_factory_46k]] (канал = воронка продукта).
