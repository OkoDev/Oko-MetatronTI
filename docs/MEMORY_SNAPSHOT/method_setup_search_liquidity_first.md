**Егор 26.08.2026 (разбор GRT): «вот так надо потенциальные сетапы искать!»** — одобрен
конкретный порядок работы. Воспроизводить его, а не смотреть график на глаз.

## Порядок (именно в этой последовательности)

1. **Все ТФ через боевые движки, не на глаз.** 1w/1d/4h/1h/15m/5m → `run_structure` (OKO-SM
   len5/len50) + `current_leg` + `smc_engine` (FVG, OB, EQH/EQL). Плюс ATR/EMA/WT/RSI, режим
   рынка (BTC/ETH дрейф 7/30/90д), RS альта к BTC, фандинг, OI. См. [[method_egor_two_scale_entry]].
2. **Кластеризовать независимые уровни.** Пивоты (classic S1/S2/PP/R1) · фибо-ретрейс ноги ·
   FVG старшего ТФ · OB · трендовая · EQH/EQL. Сетап там, где ≥3 источника из РАЗНЫХ семей.
   См. [[project_confluence_principle]].
3. **🔑 Найти ЛИКВИДНОСТЬ — она объясняет ПОЧЕМУ.** Уровень говорит КУДА, ликвидность — ЗАЧЕМ
   цена туда пойдёт. Плита равных лоу/хаёв (не обязательно пара — искать коридор минимумов
   за несколько часов) = магнит. **Несобранная ликвидность ломает симметрию сценариев:**
   «пролив vs боковик» перестают быть равновероятными.
4. **Вход = зона + ВРЕМЯ, если в кластере есть наклонная.** Трендовая едет: посчитать наклон
   (%/сутки) и построить таблицу «время → уровень линии». Фиксированная лимитка на наклонной —
   ошибка. У GRT линия шла +3.77%/сутки и догоняла цену за 24ч.
5. **Стоп — в пустоте между кластерами**, не на уровне и не под плитой EQL: туда пойдёт прокол.
   См. [[stop_on_line_is_liquidity_sweep]].
6. **Отказ — тоже результат.** «С текущих» сетапа нет, если RR<1 к первой цели. Считать RR
   до КАЖДОЙ цели, а не до дальней.

## Что дало усиление на GRT

Вход, найденный по кластеру (0.016950), после уточнения местом снятия EQL сместился на 0.016915 —
**RR к цели вырос 3.3 → 5.1** при том же стопе. Точка снятия ликвидности лежала на 0.45% НИЖЕ дна
плиты равных лоу: S1 оказался ценой ПОСЛЕ свита, а не уровнем сам по себе.

## Про наклонные линии — говорить слабость вслух

Трендовая по ДВУМ точкам — гипотеза, не уровень. Наклон >3%/сутки требует ускоряющегося роста →
горизонт валидности 24-36ч. Называть число касаний и срок жизни, а не подавать линию как опору.

**Why:** без шага 3 сетап это «уровень, у которого может отскочить» — гадание. С ликвидностью
появляется механизм. **How to apply:** при вопросе «есть ли сетап по X» идти шагами 1→6; шаг 3
не пропускать даже когда кластер уже красивый.
