# 🔴🔴🔴 НОВЫЕ СЕТАПЫ ТЕРЯЛИСЬ МОЛЧА (найдено 06.10.2026)

Егор: «почему waves_long молчит?» — главное направление проекта не дало **ни одного
ордера на бирже за 14 дней**.

## Корень: одна ветка отступа

`scripts/wave5_shadow.py`, блок обработки найденного сетапа:

```python
if prev is None:                        # НОВЫЙ сетап
    prev = {...}                        # запись формируется
    if _w: prev.update(_w)
    # 🔴 и ВСЁ — в state не кладётся, выбрасывается
elif _w and prev.get("weight") is None: # старый сетап без веса
    prev.update(_w)
    state[k] = prev; transition(...)    # ← должно было быть у НОВЫХ
    print("  NEW  ...")                 # ← печать «NEW» для СТАРЫХ записей
```

Отступы уехали **22.09** при добавлении веса монеты (`coin_weight`).
`status.json` → `last_new: "2026-09-22 00:15"` — ровно эта дата.

## 🔑 ПОЧЕМУ Я СНАЧАЛА ОТВЕТИЛ НЕВЕРНО

Первый ответ Егору: «у лонга 0 полных ядер из 40, `depth5<0.5` режет 62%, а 7 шорт-ядер
отброшены по решению 16.09». **Неверно всё.** Эта разбивка печатается
**ПО ЖУРНАЛУ** (`df = pd.DataFrame(list(state.values()))`), а журнал замёрз на 58
сентябрьских записях со статусом `closed`. То есть я читал статистику сентября и выдавал
её за текущее состояние рынка.

Те «7 готовых шорт-ядер» — записи 09–21.09, **все закрыты, все в минус**
(сумма −32.77%, медиана −2.58%, плюсовых 0/7 — замер 29.09,
[[waves_sides_measured_both]]).

🔴 **Класс ошибки: прибор показывает своё прошлое, а читается как настоящее.**
Тот же класс, что [[radar_wave_gate_was_dead_column_not_selected]] (гейт без срабатываний)
и [[bug_watchdog_restarts_healthy_bot]] (прибор мерил не ту величину).

## Как доказал, что виноват не рынок

Прямой прогон детектора на СВЕЖИХ данных (`closed_bars` отдаёт бары до 06.10 12:00,
569 монет в работе): `mark_impulse` находит **ICP/USDT SHORT, вершина 05.10 20:00**.
На 55 монетах — 1 сетап, то есть на 569 ожидалось бы ~10 за это окно.
Сетапы были, их было некуда класть.

После фикса тот же прогон: `NEW ICP/USDT:USDT SHORT … активных: 1, журнал 1` вместо нуля.

## Что проверять в будущем

   статистика по журналу врёт. Это дешевле всех замеров.
