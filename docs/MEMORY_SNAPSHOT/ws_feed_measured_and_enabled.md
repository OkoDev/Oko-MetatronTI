**Почему был выключен (вопрос Егора «только из-за трафика?» — НЕТ).** Коммит `7433f33`, 30.05.2026,
DEV-230: пять ccxt.pro соединений душили ОБЩИЙ event loop → скан OHLCV 76–96 с, health 339×DEGRADED.
Kill-switch `performance.ws_enabled: false` вернул скан к 8 с. Трафик — отдельная история (29.09, VPN).

**Два РАЗНЫХ канала, путать нельзя:**
- `WsFeed` (`performance.ws_enabled`) — ccxt.pro: тикеры батчами по 100 + OHLCV приоритетных пар.
  Даёт `data_collector.get_current_price()` мгновенную цену и `tick_price` в шину (Сфера 2).
- `MarketWS-v2` (`performance.use_ws`) — свой клиент, свечи 3m/5m/15m, идёт МИМО VPN
  (`market_ws.bind_ip_prefix: "192.168.1."`). У WsFeed такой настройки НЕТ — он через туннель.

**Замер 04.10 (база против 25 мин работы):**

| | выкл | вкл |
|---|---|---|
| возраст цены в шине p50 / p75 / p90 | 116 / 291 / 398 с | **81 / 123 / 218 с** |
| пар свежее минуты | 159 из 571 | **207 из 573** |
| период скана, медиана по 8 парам | 358 с (n=45) | **255 с** (n=16) |
| slow callbacks · DEGRADED | 0 · 1 | 0 · **0** |
| VPN за минуту (парный замер) | rx 6752 КБ, tx 652 КБ | rx **5976** КБ, tx 5016 КБ |

🔑 **Цикл скана СОКРАТИЛСЯ**, а не вырос: WsFeed снимает REST-запросы цены, и экономия перевешивает
стоимость соединений. 🔑 **Трафик VPN не вырос**: без WsFeed входящий даже БОЛЬШЕ (REST тяжелее
подписки). Опасение мая не воспроизвелось — тогда не было отдельного свечного клиента.

🔴🔴 **УРОК О ВЫБОРКЕ (едва не стоил неверного отката).** Первая оценка цикла бралась по ДВУМ точкам
одной пары (BTC): 144 → 317 с, то есть «вдвое хуже», и критерий отката формально сработал.
На 8 парах и 61 интервале знак перевернулся: 358 → 255. **Две точки — не выборка**, даже в инфраструктурном
замере. Считать интервалы по нескольким парам и делить ДО/ПОСЛЕ по времени рестарта (`scratchpad/cycle_stat.py`).

**Чего замер НЕ покрыл:** трафик мерен минутными срезами (шумят по фазе скана) — для суточной цифры
нужен долгий замер; `tick_price` в шину публикуется не на каждый тик, поэтому в шине 81 с, а не секунда
(у `trade_tracker` цена мгновенная — dict lookup).

**How to apply:** откат — `performance.ws_enabled: false` + рестарт. Инструменты: `scratchpad/ws_bench.py`
(before/after), `scratchpad/cycle_stat.py`, `scratchpad/vpn_measure.ps1` (ТОЛЬКО латиница — PowerShell
падает на кириллице в .ps1 без BOM). Связано: [[law_sample_representativeness]], [[network_vpn_routing_happ]],
[[cube_selftest_sees_outside_spheres]].
