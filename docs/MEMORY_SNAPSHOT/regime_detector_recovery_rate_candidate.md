# 🧭 КАНДИДАТ В ПЕРЕКЛЮЧАТЕЛЬ: Recovery Rate (12.08.2026)

Задача: найти признак, ловящий переворот стороны фейда ПРИЧИННО
([[fade_side_flip_2026_period_not_survivorship]] — переворот 08.2025 реален,
инвариантен к 4 выходам, но детектировать в реальном времени было нечем).
Кандидаты и формулы предложил DS. Инструмент: `scripts/regime_detector_candidates.py`.

## Формулы (всё считается ТОЛЬКО по прошлым 200 барам 4h)
```
RR  = median( сумма доходностей за 12 баров ПОСЛЕ шока |r| > 2σ ) / σ     ← победитель
TAI = (P95(r) − median) / (median − P05(r))                              ← второй
VTR = mean(vol | r<P10) / mean(vol | r>P90)                              ← не работает
ACS = corr(r[t], r[t−6])                                                 ← не работает
```

## Разделяющая сила (36 окон 7 мес, шаг 1 мес)
| признак | LONG-окна | SHORT-окна | z |
|---|---|---|---|
| **RR** | **+0.340** | **−0.314** | **+7.87** |
| TAI | +1.036 | +0.941 | +5.71 |
| VTR | 1.075 | 1.117 | −0.83 ❌ |
| ACS | −0.010 | −0.006 | −0.70 ❌ |

**RR меняет ЗНАК ровно на переломе**, монотонно и заранее:
```
2025-05 LONG  RR +0.147
2025-06 LONG  RR +0.016
2025-07 LONG  RR −0.005   ← пересечение нуля, ещё до смены лидера
2025-08 SHORT RR −0.231   ← перелом стороны
2026-01 SHORT RR −0.520
```
**Физика прямая:** RR = восстанавливается ли цена после шока. Восстанавливается →
проливы выкупают → живёт LONG-фейд. Не восстанавливается → живёт SHORT-фейд.
Это ровно та физика, которую требовал DS («строить признак из физики, а не подбирать индикатор»).

## Правило и его точность
`RR > 0 → LONG, RR < 0 → SHORT` верно в **31 из 36 окон (86%)**.
Все 5 ошибок — в узкой зоне **|RR| < 0.12** (2023-02 +0.041 · 2023-03 −0.088 ·
2023-04 −0.114 · 2023-12 −0.035 · 2025-07 −0.005), то есть у самого порога.
→ лечится МЁРТВОЙ ЗОНОЙ: `|RR| < 0.15 → не переключаться, держать текущий режим`.

## 🔴 ПОЧЕМУ ЭТО ЕЩЁ НЕ РЕЗУЛЬТАТ
1. **Окна перекрываются на 86%** (7 мес / шаг 1 мес) → наблюдения НЕ независимы,
   z=+7.87 сильно завышен. Независимых окон всего **6** (4 LONG / 2 SHORT):
   RR LONG +0.395 против SHORT −0.240 — направление держится, но n=6 ничтожно.
2. **Перелом в выборке ОДИН** (08.2025) → ложные срабатывания оценить невозможно.
   Ранний перелом 2023-03 при выходе TTL48 исчезает, то есть он ненадёжен как вторая точка.
3. Проверено 4 признака на одной выборке → поправка на множественное тестирование не делалась.

**Статус: сильный кандидат с понятной физикой, НЕ подтверждён. В бой не ставить.**
