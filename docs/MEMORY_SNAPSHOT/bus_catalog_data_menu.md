16.06.2026, юзер сформулировал ключевую архитектурную идею (метафора «меню в ресторане»).

**ИДЕЯ — BUS-CATALOG (Каталог данных шины / «Меню»):** единое место (узел/реестр), где прописано ВСЁ что течёт в шине. Прихожу → вижу список доступных данных → выбираю что подключить («провод»). НЕ нужно шариться по всему проекту, выясняя какие данные есть. Проектирую новый дашборд/детектор → пришёл в каталог → подключился → не паришься. Точка входа в шину + контракт данных.

**Каждое «блюдо» каталога:** имя · тип · кто кладёт (источник: WsFeed/scan_loop/position_sync/EXEC-WS) · как подключить (`subscribe(SphereEvent.X)` ИЛИ `bus.get(sym).field` ИЛИ `bus.get_account().field`) · описание.

**Что уже есть (база, но РАЗРОЗНЕНО — надо знать код):**
- `SphereEvent` (события шины) — pair_context.
- `sphere_registry.py` (Сфера 12) — событие→сфера-источник (`_EVENT_TO_SPHERE`) + здоровье (OK/STALE/DEAD). НО про здоровье, не про данные.
- `PairState`/`AccountState` dataclass — поля (tick_price, regime, wt_snap, smc_snap, equity, positions[leverage/mark]).

**Чего НЕ хватает:** единого меню (события + поля состояния) с типом/источником/способом-подключения в ОДНОМ месте.

**Дизайн (вектор, не патч):**
- Самодокументируемый: строится из PairState/AccountState/SphereEvent + метаданные → один источник схемы, не дрейфует ([[principle_reuse_not_duplication]]).
- Два лица: (1) программный `bus.catalog()` для кода; (2) авто-markdown «меню» для человека/разработки.
- Расширяет `sphere_registry` (от «здоровья сфер» → к «каталогу данных»).

**Связь:** база под [[dashboard_oper_from_bus_analytics_sql]] (оперативка читает шину ЧЕРЕЗ каталог, не зная внутренностей), LISTENER-CANON (контракт подключения), часть BUS-эпика. Vision «всё из шины».

**Статус:** ✅ РЕАЛИЗОВАН 16.06. `core/context/bus_catalog.py` (самодокументируемый: поля из dataclass + метаданные источник/описание). Фасад в шине: `bus.catalog()` (программно) + `bus.catalog_markdown()`. Меню: `docs/BUS_CATALOG.md` (24 события + 56 L1 + 6 L2, у каждого тип/источник/как-подключить). `validate()` = синхрон (ловит поля без метаданных). Регенерация меню: `python core/context/bus_catalog.py > docs/BUS_CATALOG.md`. NEXT: дашборд-из-шины подключается ЧЕРЕЗ каталог.
