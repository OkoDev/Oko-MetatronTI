Правило: перед воспроизведением эталонного скрина TradingView — сверить **дату и символ** из шапки скрина («yogoru создал график … Июн 02, 2026 21:48 UTC», «GRT»). `fetch_ohlcv(limit=N)` без `since` отдаёт ПОСЛЕДНИЕ N баров = текущий день. Если эталон за вчера — данные разойдутся, разметка не сойдётся ни по цене, ни по времени.

**Why:** 02.06 сверял обратную фибо SHORT по live-данным за 03.06 → bear_ote.png не совпал с эталоном, пользователь: «нет слома структуры в шорт». Причина не в логике, а в дне. Взял `since=02.06 14:30 UTC` для GRT → OTE совпал до цента (0.705=0.02360, 0.79=0.02369) и по времени (high@18:01, low@19:33).

**How to apply:**
1. Прочитать шапку скрина: символ + дата + время (UTC) создания.
2. `since=int(datetime(Y,M,D,H,M,tzinfo=timezone.utc).timestamp()*1000)` — начало окна чуть раньше первой видимой свечи.
3. `ex.fetch_ohlcv(sym,'1m',since=since,limit=...)`, проверить печатью `df.index[0]→df.index[-1]` что окно покрывает скрин.
4. Только потом строить overlay и сверять. [[tmp-tmp-charts]] [[oko-sm-pine-ob-fvg]]
