**Цель OTE = fib 0.62-ретрейс (Егор 02.07.2026). Найдено визуал-сверкой XLM (TW-MCP) + walk-forward.**

## 🔴🔴 ОПРОВЕРГНУТО ЧЕСТНЫМ WALK-FORWARD (02.07 вечер, scripts/backtest_ote_matrix.py)
На РЕАЛЬНОМ walk-forward (структура structure_trend на прошлом, вход по тэгу 4h-OTE, 20 симв, costs 0.2%):
цель **−0.62 extension = WR 5% mean −2.94%/сделку (КАТАСТРОФА)**; ближний **TP=1R = WR 47% mean −0.092%**.
Дальний extension НЕ выживает вне идеализированного входа. Прежний вывод (−0.62 лучший, mean+4.159) был
на idealized mid-zone входе с ЛЕГОЙ ДЕТЕКТОРА → врал. **Правда: ближняя цель (1R/tp1) >> extension.**
Подтверждает [[ote_is_meanreversion_not_continuation]]. + naive тэг БЕЗ младшего триггера = брейк-ивен
(−0.092%) → корень слива = вход по сырому тэгу; ТРИГГЕР (младший CHoCH/реакция) = недостающий edge.
⚠️ В ote_signal_generator TP всё ещё _tp_fib=levels[-0.62] — ПЕРЕСМОТРЕТЬ на ближний после валидации триггера.

## 🔴 ИСПРАВЛЕНИЕ (02.07 вечер, визуал-сверка GRT): цель = fib −0.62 EXTENSION, НЕ 0.382
Первичное прочтение (levels[0.382]) БЫЛО НЕВЕРНО — сработало на XLM случайно (там импульс ВВЕРХ →
раскладка инвертировалась). Егор показал СВОЮ фибо на GRT: **цель = −0.62 extension = levels[-0.62]
ПРЯМОЕ соответствие** (не инверсия). Раскладка Егора: 1.0=начало импульса(high для short), 0=конец(low),
отрицательные = extension за конец = продолжение движения (ЦЕЛЬ). Проверено: Егор −0.62=0.01671 =
build_ote(0.01853,0.02147)[-0.62]=0.01671 ✅. Код исправлен: `levels[-0.62]` (было 0.382).
**⚠️ Но детектор берёт НЕ ТУ ногу (мельче размётки Егора) → цель считается от неверного импульса.**
Fib-фикс недостаточен без правильного выбора значимого импульса (select_significant_impulse). Это
объясняет walk-forward levels[-0.62] WR38% (усреднил крупные/локальные импульсы детектора, не Егоровы).

## 🔑 Маппинг фибо (инвертирован!) — источник путаницы (УСТАРЕЛО, см. исправление выше)
`build_ote(swing_a, swing_b)`: levels[f] = swing_a + f×(swing_b−swing_a). В ote_signal_generator
вызывается `build_ote(h["to"], h["from"])` → swing_a=to(конец импульса), swing_b=from(начало):
```
код fib +1.0 = from (начало, =SL)     fib +0.5/0.62/0.79 = OTE-зона
код fib +0.382 = ТВОЯ цель «0.62»      код fib 0.0 = to (конец импульса, =high)
код fib −1.0 = extension за конец (мой вчерашний АБСУРД)
```
**Формула: код_fib ≈ 1 − Егор_fib.** Цель Егора «0.62-ретрейс» (62% возврата импульса) = `levels[0.382]`.
Проверено XLM: Егор 0.62=0.2388 ≈ код levels[0.382]=0.23736. ✅
