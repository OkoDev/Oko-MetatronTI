18.09.2026. Егор: «коррекции a-b-c-d-e ведь тоже 5 волн, мы их можем определять! после таких коррекций бывают
хорошие движения!» + скрин XLM 1h (после дампа 16.09 — восходящий канал из пяти волн).

**Что мерилось** (`scratchpad/triangle_lab.py`, `figure5_lab.py`; данные `G:\oko_lab\out\triangle`, `figure5`, `figure5_q`):
детектор = `core/waves/wave_progress.py::triangle_ltf` (5 чередующихся свингов `_swings`), прогнан по истории каузально
(свинг известен с бара подтверждения, окна по сырым свингам; проверка `детектор(df[:n]) == детектор(df)[<n]` — 0 расхождений).
Формы по наклону границ: сходящийся · расширяющийся · восходящий/нисходящий канал · клин (границы сходятся) ·
**флаг = канал против ноги** (фигура Егора). Вход по закрытию за границей, стоп за последним свингом против хода,
цели — высота фигуры и «древко» (нога в фигуру), удержание max(24, 2·длина), кост 0.10%. Оба контроля
(та же монета ±30 дн ×8 · 5 чужих монет в тот же момент). ТФ 15m/1h/4h × два масштаба свинга.

**Результат.** Сырой прогон 1 828 715 сделок / 477 монет; «чистые» фигуры (3 точки стороны на линии ±15% высоты,
фигура ≤ 2/3 ноги, нога = экстремум окна 3·длины до фигуры — глазами подтверждено на 6 примерах) — 845 240.
На ВСЕХ формах, ТФ, сторонах, классах (по ноге / против) и обеих целях: среднее в коридоре −1…+1%, медианы ≤ 0,
Δ к случайному входу той же монеты в пределах ±1 (положительные Δr появляются только там, где случайный вход
ПРОТИВ тренда теряет), хрупкость (сумма без верхних 10%) отрицательна везде. XLM-тип (дамп → канал ↑ → пробой ↓)
на 4h: n=1972, WR 51%, +1.09% ср, медиана +0.70, Δr +0.84, Δt +1.40 — лучшая клетка из 144, не деньги.
Сходящийся треугольник отдельно (109 251 сделка): «thrust по точке e» vs «против e» — без разницы.
