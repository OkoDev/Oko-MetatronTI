## Механика (подтверждена Егором на живом графике BTC + оцифрована)
Индикатор: MTF-матрица WT (таблица Trend/WT/Zone × 7 ТФ) + стрелки = КРОСС WT-волн (wt1×wt2, wt2=SMA(wt1,4))
в экстремальной зоне ТФ + ATRTrend (SuperTrend) на цене + пивоты D/W/M. Связка Егора: «ATRTrend = режим
(рулит), WT-волна = фаза/тайминг (лидирует), пивот = уровень». Вход ПО тренду на ВЫЖАТОМ откате:
Trend▲ + WT-кросс↑ из OS = лонг; Trend▼ + WT-кросс↓ из OB = шорт.
