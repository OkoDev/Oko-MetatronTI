## ЗАКОН (симметричный, оба примера)
- Значимость импульса = **по СТЕПЕНИ ТФ (старший перебивает)**, НЕ по амплитуде на одном ряду. Идти СВЕРХУ ВНИЗ (1M→1W→1D→4h→1h→15m), найти самый старший значимый импульс.

## 🔴🔴🔴 ПОСЛЕДОВАТЕЛЬНОСТЬ (Егор 23.06) — вход СНАЧАЛА на младшем; HTF = ПОТЕНЦИАЛ, НЕ фильтр!
🔴 ИСПРАВЛЕНИЕ моей прошлой записи («вход ⇔ старший уже сломан» — НЕВЕРНО). HTF — не предусловие-фильтр ДО входа, а КАРТА потенциала/цели. Порядок во ВРЕМЕНИ снизу вверх и РАЗВОРАЧИВАЕТСЯ:
1. **ВХОД = разворотный слом МЛАДШЕГО (1h CHoCH) на ДНЕ большого движения.** Есть разворотный слом → БЕРЁМ СРАЗУ. НЕ ждём старших, НЕ предсказываем ракету («никто не знает что улетит»). Тесный SL под слом.
2. **HTF = ПОТЕНЦИАЛ/ЦЕЛЬ:** untested OTE старших вверх по иерархии = ревард + куда вести. Не предсказываем — ПОЗИЦИОНИРУЕМСЯ (тесный риск × большой untested-простор).
3. **РАЗВИТИЕ:** 1h-слом → (если разворот реален) импульс ломает 4h → цена идёт в untested OTE 1D. Мы в позиции С НИЗА, ведём каскадом младший→старший.
⚠️ В МОМЕНТ входа 4h/Daily ещё НЕ сломаны (цена на дне)! «4h уже сломан» (пред. сообщение) = взгляд ПОСТФАКТУМ.
- **РАЗЛИЧИТЕЛЬ XLM vs SYN = R:R ПО КАРТЕ untested-потенциала** (НЕ «сломан ли старший»):
  - SYN 1h-лонг ВВЕРХ из дна → огромный untested-простор (OTE 1D) → ревард велик → БРАТЬ.
  - XLM 15m-шорт ВНИЗ из discount/лонг-OTE 4h → вниз простора мало, untested ВВЕРХУ → плохой R:R → ПРОПУСК.
- **Закон:** бери разворотный слом младшего, направленный В СТОРОНУ большого untested-потенциала старшего. HTF=карта (ревард+цель), младший слом=вход, решение=R:R.
- = разгон [[user_wave_runner_strategy]] ($50→$7000): вход младший по слому → каскад → цель старший OTE. «Таких монет (дно большого down + локальный разворотный слом) сейчас БОЛЬШИНСТВО» = сканерный сетап.
