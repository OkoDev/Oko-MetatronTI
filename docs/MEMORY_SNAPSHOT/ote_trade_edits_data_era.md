## 🔬 ГИПОТЕЗА для пост-анализа: TSL-порог зависит от TF входа (юзер 04.06)
Сейчас `tsl_activation_r_per_strategy.ote_nested: 4.0` — ФИКС для всех ltf (компромисс).
**Механика:** TF входа определяет размер SL (за свечу) → notional → типичный RR:
- **5m вход** (SL крошечный, ×10 notional, runner огромный RR22) → порог ВЫШЕ (~6R, дать ракете развиться)
- **15m** → средний (~4R)
- **1h** (SL крупнее, RR меньше) → НИЖЕ (~2.5R, фиксировать раньше)
→ Калибровать `tsl_activation_r_per_ltf` (по аналогии с `ENTRY_TO_TSL_TF` для tsl_tf).
Пост-анализ: split avgR/captured_R% по (ltf × tsl_activation_r) на Эре-4 → оптимум per ltf.
Связанная гипотеза: `r_gradient_peak_min_r` 2.5→5.0 для OTE (иначе деэскалация сразу после активации 4R).
