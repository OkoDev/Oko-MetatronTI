**20.06 первый ЧЕСТНЫЙ замер edge ote_nested** (income/o.rp + MFE из реальных max/min цены, НЕ из вравшего DB-exit). Все прежние «ote_nested чемпион +0.748/+0.474» = DB-фикция.

**Реальность (income, 6д 06-14→19, n=817):** **NET −$510.80** (realized −$423 + ликвидации −$87). БД показывала **+$230** (инверсия знака $654). 6/6 дней в минус на правде.

**Диагностика (n=940, MFE честный):**
- **ВХОД ЖИВОЙ:** MFE медиана 0.98R / среднее 1.31R, **48% доходят до +1R, 22% до +2R, 10% до +3R.** Мёртвый вход = MFE≈0. → НЕ мёртвый.
- **🔴 ВЫХОД = КОРЕНЬ:** SL=66% сделок, из них **46% дошли до +1R MFE перед стопом** (медиана MFE у SL=0.89R; прямо в SL только 20%). TP=5%, TSL=1%. Цена шла в плюс → отдавала всё до −1R. Защита прибыли НЕ доносит.
- **SL НЕ тугой** (median 0.68%) — проблема не близость, а что **не трейлит/не в BE** за прибылью. BE фирит на +0.5R (`[DEV-40]`), но +1R всё равно отдаётся → BE/TSL медленные vs интрабар ИЛИ нужен частичный TP/трейл.
- **Плечо 50×** (55%≥30×) → ликвидации −$87 = исполнение, вторично (SL-safety кап).

**ВЕРДИКТ: ote_nested НЕ мёртв — живой вход сливается через выход + плечо. ФИКСИМО.** Грубо: 285 SL-сделок дошли +1R → захват хотя бы +0.5R вместо −1R = свинг ~+400R.

**How to apply (next):** EXIT-FIX = рычаг прибыли (BE/частичный TP/рабочий трейл после +1R, снизить плечо), НЕ трогать вход. Перемерить edge на income/o.rp многодневно ПОСЛЕ фикса выхода. Всё на бумаге VST (0 реальных потерь — полигон). Caveat: MFE=пик (полный захват нереален, но частичный спасает много). [[income_ledger_db_overstates_realized]] [[ote_nested_mtf_strategy]].
