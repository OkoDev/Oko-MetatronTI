# 📚 СЫРЫЕ ДАННЫЕ ИССЛЕДОВАНИЙ → obsidian/Research (Егор, 12.08.2026)

Вопрос Егора: «ты документируешь все данные, полученные при исследовании?»
Честный ответ был — **нет**. Выводы уходили в hot-memory, а сырые таблицы прогонов
(матрицы, роллинг-окна, распределения) оставались во временной папке сессии
и после неё исчезали. Вывод переставал быть проверяемым: число не поднять и не пересчитать.

**Why:** за одну сессию 12.08 было ~14 опровергнутых гипотез, и почти каждое
опровержение опиралось на конкретную таблицу. Без сырых данных следующая сессия
повторит те же прогоны заново — или, хуже, поверит хуку без возможности проверки.

**How to apply — трёхуровневая схема:**
1. **`obsidian/Research/<дата>-<тема>.md`** — ВСЕ таблицы целиком: числа, n, окна,
   охват монет, разрезы, оговорки, формулы, имена скриптов. Cold storage.
2. **hot-memory topic-файл** — хук, вывод, закон + ссылка на Research-файл.
3. **`whats-next.md`** — что это меняет для следующей сессии.
Индекс: `obsidian/Research/Research.md` (правило vault: имя индекса = имя папки),
подключён к `[[Project-MOC]]`.

Первый файл по схеме: `Research/2026-08-12-Fade-Side-Flip-Full-Data.md` —
матрица ТФ×сторона×фаза, роллинг 36 окон, разделяющий тест, инвариантность к выходам,
кандидаты в переключатель.
