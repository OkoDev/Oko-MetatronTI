# 🟡 ЛОНГ ОТ ГЛУБОКОЙ ПЕРЕПРОДАННОСТИ WT НА ЧАСОВИКЕ — кандидат

Нашлось перебором 72 политик выхода по просьбе Егора («пробуй все варианты»),
на его же конструкции: разрешение на часовике → вход на младшем. Из 72 положительна нетто
была ровно одна политика — выход в противоположной зоне на лонге.

## Правило

```
КОНТЕКСТ  1h:  кросс wt1×wt2 вверх при wt1 < −IZ (глубокая перепроданность)
ВХОД     15m:  ПЕРВЫЙ кросс wt1×wt2 вверх в окне 12 баров часовика, по OPEN следующего бара
ВЫХОД    15m:  wt1 дошёл до +EZ (touch, не кросс)
ТОЛЬКО LONG · одна позиция на монету · без дробления на кроссы
```
