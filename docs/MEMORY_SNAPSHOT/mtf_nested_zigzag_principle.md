**ФУНДАМЕНТАЛЬНЫЙ ПРИНЦИП структуры (Егор 02.07.2026, визуал-сверка GRT на живом графике TW-MCP).**

## Суть
**ZigZag на 4h ≠ ZZ на 1h ≠ ZZ на 15m.** Каждый ТФ имеет СВОЙ ZigZag → свои значимые импульсы/ноги.
Структура ВЛОЖЕНА: младший ZZ = под-волны внутри ноги старшего ZZ. Анализ ВСЕГДА старший→младший:
```
4h ZZ  → КРУПНЫЙ импульс = ГДЕ (контекст, направление, HTF-OTE-зона)
1h ZZ  → СРЕДНИЙ импульс ВНУТРИ 4h-ноги = уточнение
15m ZZ → МЕЛКИЙ импульс ВНУТРИ 1h = точка входа (триггер)
```

## Почему детектор ломается (доказано на GRT)
Детектор ИЗОЛИРОВАН по ТФ — `ote_retest_setups` + `setups[-1]` на КАЖДОМ ТФ отдельно, без вложенности:
- **1h**: взял мелкую локальную ногу 0.01872→0.01709 (последний слом, вне 4h-контекста).
- **4h**: взял ДРЕВНЮЮ майскую ногу 0.02526→0.03003 (24-26.05!), зона 0.026 — цена давно рухнула до
  0.0178. `setups[-1]` без привязки к актуальности/свежести.
- ZZ 4h правильно видит свежие ноги (0.02147→0.01853 июнь = размётка Егора), но детектор их не берёт.
Отсюда зона И цель −0.62 считаются от НЕВЕРНОЙ ноги (древней/мелкой).

## 🔑 МЕХАНИКА вложенности: ноги ВОЗВРАЩАЮТСЯ в OTE старших (Егор 02.07)
Зависимость между масштабами: младшая нога/откат валидны ТОЛЬКО когда ВОЗВРАЩАЮТСЯ в OTE-зону
старшей ноги. Цепочка (XLM пример):
```
4h LONG-импульс 0.135→0.298 → 4h-OTE-зона 0.17-0.22
   ↓ цена откатывает ВНИЗ в 4h-OTE
внутри 4h-OTE формируется 1h/15m под-импульс 0.188→0.169
   ↓ его откат ВВЕРХ = LTF-OTE (0.62=0.19944)
ВХОД = LTF-OTE попадает ВНУТРЬ HTF-OTE (нога вернулась в зону старшего) = КОНФЛЮЭНЦИЯ вложенности
```
Вход 0.19944 силён т.к. это 0.62 LTF-фибо И одновременно −0.27 HTF-зоны (совпадение масштабов).
**Изолированная LTF-нога вне HTF-OTE = ШУМ** (то что детектор берёт сейчас). Вложенная = когда
LTF-откат приходит обратно в зону старшего. Детектор ДОЛЖЕН проверять: LTF-вход ВНУТРИ HTF-OTE.

## Фикс (главный корень перестройки, важнее целей/гейтов)
1. **4h: выбрать СВЕЖИЙ ЗНАЧИМЫЙ ZZ-импульс** (prefer_recency, не древний/не крупнейший-span) → задаёт
   HTF-контекст. `select_significant_impulse(prefer_recency=True)` ARCH-128 создан для этого (был баг
   «мерцания зоны» от span-приоритета). ⚠️ у него look-ahead ([[bug_select_significant_impulse_full_dataset_lookahead]]) — нужен walk-forward.
2. **1h/15m: ноги ВНУТРИ окна старшей ноги** (вложенность), не изолированный последний слом.
3. **Сверху вниз**: 4h контекст → 1h внутри → 15m вход.
