# OTE-Retest вложенный (nested MTF) — каркас стратегии

Механика пользователя (03.06): 4h задаёт ЗОНУ+ЦЕЛЬ, 5m даёт ТРИГГЕР входа.
Бэктест 5 пар (BTC/ETH/SOL/GRT/DOGE, XLM нет 5m), tail 120K 5m (~400дн), синхрон окон.
Скрипты: `e:/tmp/ote_nested2.py`, `ote_mfe.py`.

## Доказано
- **Ужатие риска ×10.1** (5m-вход vs 4h-вход на ТОМ ЖЕ сетапе). risk 5m=49 vs 4h=495.
- **maxR=+16** (nested) против плоского 4h maxR=+1.8 — тот же TP, риск в 10 раз меньше.
- MFE-распределение n=346: 86%→0.5R, **66%→1R**, 39%→2R, 29%→3R, 18%→5R, 9%→8R.
- Исходы голого дальнего TP: 316 SL / 30 TP → только **9% доходят до 4h-target**, но 66% дают +1R по пути. Жадный TP сжигает прибыль.

## Каркас (рабочий)
```
ВХОД:   4h импульс+CHoCH → OTE(0.5-0.79) → на 5m первый слом того же направления В зоне → вход
SL:     за 5m-структуру, БЕЗ буфера (буфер 30% ВРЕДЕН: avgR +0.152→−0.085, WR не растёт)
TP1:    +1R фиксируем 50%  → WR 66%
RUNNER: 50% до 4h-target   → ловит хвост R=8-16 (9-18% случаев)
```
Частичный TP1=1R: **avgR +0.415, WR 66%, sumR +144** (грубая sim, runner=BE при недоходе).
Против голого дальнего TP: avgR +0.152, WR 12%.

## Каналы
- **SHORT nested = +0.858 avgR, maxR+16** (по HTF медвежьему тренду 2024-26) — работает.
- **LONG nested = −0.555** — ловит контр-тренд без фильтра. Нужен HTF-фильтр тренда (atr_up/HH-HL на 4h).

## 🥇 5m-ОТКАТ = ЗОЛОТО + масштаб входа зависит от дистанции цели (03.06)
Прогон 4h→5m двунаправленный, фильтр 5m RSI-дивергенции (скрипт `e:/tmp/ote_div5m.py`):
```
                n     avgR    WR    maxR
БЕЗ фильтра ПРОДОЛЖ  71  +0.385  68%   +8.5
БЕЗ фильтра ОТКАТ    96  +1.128  83%  +18.8  ← ЛУЧШАЯ ВЕТКА из всех прогонов
БЕЗ фильтра ОБЕ     167  +0.812  77%  +18.8
С 5m-div   ОБЕ       54  +0.083  72%   +0.5  ← дивергенция СРЕЗАЛА хвост
```
**ОТКРЫТИЕ 1: дивергенция-фильтр ВРЕДЕН для runner-механики.** Дивергенция = сигнал РАЗВОРОТА,
конфликтует с runner до далёкого target: после div-входа цена разворачивается, не доезжает →
maxR +18.8→+0.5, avgR +0.812→+0.083. Дивергенция для разворотных сделок с БЛИЗКОЙ целью, НЕ trend-фильтр.
**ОТКРЫТИЕ 2: масштаб входа зависит от ДИСТАНЦИИ цели (уточняет «5m шумит»):**
- ПРОДОЛЖЕНИЕ (далёкая цель=4h-target): **15m** лучше (+0.471 vs 5m +0.385). На дистанции 5m-шум выбивает.
- ОТКАТ (близкая цель=4h-OTE): **5m** лучше (+1.128 WR83% vs 15m +0.600). Точный вход, крошечный риск, цель рядом.
«5m шумит» верно ТОЛЬКО для далёких продолжений. Для откатов 5m = золото.
