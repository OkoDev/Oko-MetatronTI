## 🔄 Закон размера ИНВЕРТИРОВАН для trend-following
Внутри `atr_change`: <1% → PF **1.33** (+161) · 1–2% → 0.48 · 2–4% → **0.24** (−4116) ·
4–8% → **0.21** (−3806) · >8% → 0.45.
Чем БОЛЬШЕ стоп, тем хуже — зеркально фейду, где большой стоп даёт эдж.
Логика: в тренде большой стоп = большой убыток при развороте; в фейде большой стоп
переживает дислокацию. **Закон размера ТФ- и МЕХАНИКО-специфичен, не универсален.**

## 🔴🔴 ГЛАВНОЕ РАСХОЖДЕНИЕ: исследуем одно, торгуем другое

**НЕТ ВООБЩЕ**: топ по объёму — atr_change, ote_nested, arch104, wt_sideways.
