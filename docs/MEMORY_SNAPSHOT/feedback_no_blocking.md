Не предлагать `blocked_regimes`, `blocked_combos` и жёсткие запреты на вход как первое решение при плохом WR.

**Why:** Пользователь хочет чтобы бот торговал, а не молчал. Блокировки — крайняя мера, не инструмент настройки. "Хватит уже блокировать все подряд!" (10.04.2026).

**How to apply:**
- Сначала предлагать мягкие меры: изменить веса, поднять порог strength, скорректировать SL/TP
- Блокировку предлагать только если combo стабильно отрицательный на 100+ сделок в нейтральный рынок (не в crash-период)
- WR<10% в post-crash whipsaw — не повод для блокировок, рынок вернётся в норму
- Текущий подход: наблюдать, корректировать веса через adaptive weights, ждать нормализации
