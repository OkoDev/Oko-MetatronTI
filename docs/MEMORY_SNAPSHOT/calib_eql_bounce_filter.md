# КАЛИБРОВКА: EQL ловит флэт (нужен фильтр отскока)

**XLM 5m 04.06:** `detect_equal_levels` выдал EQL=0.20875 (лои 0.2088@23:05 / 0.2087@23:55,
Δ=0.048%). Пользователь визуально НЕ видит EQL. Проверка: между лоями цена БОЛТАЛАСЬ в
боковике 0.2091-0.2098 (~50 мин), макс-отскок только **1.01%** = КОНСОЛИДАЦИЯ, не двойной-лой.

## Корень
`detect_equal_levels(eq_len=3, threshold=0.1×ATR)` ловит ЛЮБЫЕ два близких лоя, включая края
флэта. EQL на консолидации = ложная «ликвидность». Настоящая EQL = два swing-лоя на уровне,
разделённых ИМПУЛЬСНЫМ отскоком (ушла вверх → вернулась = ликвидность собрана дважды).

## Решение (фильтр)
EQL/EQH валиден ТОЛЬКО если между равными пивотами был значимый отскок:
```python
bounce = (max(high между лоями) - eql_level) / eql_level
if bounce > THRESHOLD (~1.5% или N×ATR):  # импульс, не флэт
    valid EQL
```
Опц.: больший eq_len (значимые swing, не мелкие пивоты консолидации).

## Влияние
EQL = w=4 (сильнейший зональный триггер, liquidity sweep). Ложный EQL → движок ждёт
свип несуществующей ликвидности → пропуск/ложный вход. Фильтр критичен для collect_zone_triggers.
