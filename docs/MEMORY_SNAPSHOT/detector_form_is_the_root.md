# 🔑🔑 КОРЕНЬ — ФОРМА ДЕТЕКТОРА (обзор открытых реализаций, 20.08.2026)

Егор: «подключай рой и все возможные экспертные в торговле и разметке инструменты».
Проверены: ZigZag, Directional Change, LuxAlgo SMC, ICT, Bry–Boschan, CUSUM,
ElliottWaveAnalyzer, smc_quant, Pine-скрипты.

## ГЛАВНОЕ
**Ни одна открытая реализация НЕ сканирует окна.** Все — конечный автомат: держим
бегущий экстремум и его индекс, порог решает только КОГДА подтвердить разворот.
Origin по построению = индекс экстремума и физически не может попасть в тело
предыдущего движения.

Наш `find_impulses` (`for back in range(5, max_bars+1)`) — единственная конструкция с
перебором. **Захват чужого хвоста (случай KAIA) — следствие ФОРМЫ, а не порогов
3·ATR/35%.** Я чинил симптом: режим `origin_mode="extreme"` берёт САМЫЙ ДАЛЬНИЙ
экстремум, тогда как в ZigZag/DC/Bry–Boschan origin — ПОСЛЕДНИЙ подтверждённый
противоположный пивот. Второй независимый механизм захвата, мной же и воспроизведённый.

Канон (`neurotrader888/directional_change.py`):
```python
if up_zig:
    if high[i] > tmp_max: tmp_max, tmp_max_i = high[i], i    # экстремум по ФИТИЛЮ
    elif close[i] < tmp_max - tmp_max*sigma:                 # подтверждение по ЗАКРЫТИЮ
        tops.append([i, tmp_max_i, tmp_max])                 # conf_i И ext_i раздельно
```
🔴 У нас в `impulse_fib.py:99` якоря СМЕШАНЫ НАОБОРОТ: ход по close, откат по H/L.
Реализовано канонически: `core/smc/dc_legs.py` (20.08). Проверка на KAIA: DC нашёл дно
**0.02154 (19.08 01:00)** — то самое, что Егор показал стрелкой; перебор ставил origin
на 0.02225 сутками раньше. Лаг подтверждения **2-4 бара против 18** у swing50.

## ЧЕГО У НАС НЕТ (grep по core/ подтвердил)
1. **Ценового порога как класса** — вся структура бар-каунтовая (LuxAlgo swings).
   DC/ZigZag с порогом 2-3×ATR(14) не реализован.
2. **Альтернация и цензурирование Bry–Boschan**: из подряд идущих вершин остаётся
   высшая; фазы короче τ удаляются; развороты у краёв окна удаляются. Это ровно защита
   от «origin в хвосте чужого движения».
3. **CUSUM** (López de Prado): `S+=max(0,S+r)`, событие при |S|>h, сброс в 0 — цена,
   висящая у порога, не даёт серию ложных событий.
4. **Efficiency Ratio как критерий РАЗМЕТКИ** (у нас пробовался как гейт входа).
5. **Правила Эллиотта как ВАЛИДАТОРЫ НОГИ**: w2 ≥ 0.2·w1, w3 ≥ w1/3, w3 > w2,
   длительностные 9× и 7× — дешёвый фильтр «нога, а не каша», отдельный от порога отката.

## 🔴 ДЕВЯТЬ ПРОТИВОРЕЧИЙ МЕЖДУ ИСТОЧНИКАМИ (важнее согласия)
1. **Слом: close или фитиль.** LuxAlgo/joshyattridge — close_break. ICT — НАОБОРОТ:
   свип обязан быть фитилём, close за уровнем **аннулирует** сетап. Один бар = два
   противоположных смысла в двух фреймворках.
2. **Порог equal highs: 0.1×ATR (LuxAlgo) против 1% цены (joshyattridge)** — на 1h
   крипте расходятся в **7-14 раз**.
3. **Длина свинга: 50 / 5 / 10 / 2** — разброс 25×, обоснования нет ни у кого.
4. 🔴 **Популярнейший Python-пакет по SMC содержит look-ahead BY DESIGN**:
   `high.shift(-(swing_length//2)).rolling(...)` — центрированное окно, будущее прямо
   в колонке. Наш класс багов «флаг смещён на N баров» — в библиотеке-эталоне.
5. **Перекрытие волны 4**: Impulse требует `w4.low > w1.high`, LeadingDiagonal — `<`.
   Один знак меняет класс всей пятиволновки.
6. **Displacement нефальсифицируем**: LuxAlgo дословно «There is no fixed threshold»,
   при том что каждая ICT-стратегия ставит его жёстким гейтом.
7. **Геометрия стопа — три несовместимых**: 1.5×ATR / под фитиль свипа / граница OB.
   У нас 2.5×ATR — четвёртая.
8. **Якорь фибо**: фитили или тела свечей.
9. **MTF-согласие**: источники требуют согласия ТФ, наш замер даёт обратное.
   → Здесь источники СЛАБЕЕ наших данных: у них декларация, у нас измерение.

## Что это меняет в наших планах
- Детектор переписан в каноническую форму (`dc_legs.py`), сравнение с перебором — замер.
- Режим `origin_mode="extreme"`, добавленный 20.08, признан неверным (самый дальний
  вместо ближайшего структурного).
- Пороги чужих реализаций брать как ГИПОТЕЗЫ: ни один источник не даёт разреза
  сторона × год × режим × размер. Бэктест smc_quant — общая строка с WR 23% на train
  против 50% на test, по нашему протоколу это не вердикт.
