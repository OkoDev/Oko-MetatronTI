**Что сделано** (`053c41a`, `0ced18e`, `c874e0e`; репозиторий `oko-dashboard`, ветка main).
Экран рисовал СВОИ 13 узлов (BUS, DATA, SIGNALS, CONFIRM, OTE, PIVOT, DIAG…) из `lib/oko-data.ts`
и разошёлся с кодом: WAVE висела как «S14 · Elliott», хотя номер 14 отдан Execution, а волнам —
20. Теперь состав, статусы и детали приходят из `/api/cube/selftest` (13 сфер + 21 ребро + 4 цикла,
~0.35 с), а `lib/cube-skin.ts` держит только то, чего прибор не знает: цвет, подпись, роль, модули
суб-куба. Сфера, которой нет в кольцах и поясе, дописывается в пояс сама — новая появится без правки фронта.

**Инфраструктура:** `next.config.mjs` проксирует `/api/*` → :8001 (oko-api) и `/hub/*` → :8020
(cube-hub). `fetchCubeSelftest()` разбирает слои и сопоставляет узлы рёбер со сферами (`EDGE_ALIAS`,
где `BTCRegimeProvider` проверяется ДО `MarketRegime`, иначе «Regime» заберёт не ту сферу).
В панели — настоящие рёбра L14 с причиной тени вместо выдуманных «Event processed · 12ms»;
блок хаба и блок долгов считаются из ответа прибора.

🔴 **Два прокола, оба мои, оба в один вечер:**
1. Решётка брала цвет по индексу позиции, а позиций стало 16 (13 сфер + пояс) против 13 в списке →
   `undefined.color` уронил ВЕСЬ экран (белая страница у Егора). Чинить: `ALL[...]?.color ?? запас`,
   решётка строится только по 13 позициям Куба.
2. Пояс поставлен на углы −30 и 90, где уже стоят SIGNALS и EXIT, — подписи слиплись.
   Большие сферы стоят на −90, −30, 30, 90, 150, 210; пояс идёт МЕЖДУ ними: −60, 60, 180.

🔴🔴 **ЗАКОН ПРОВЕРКИ ФРОНТА: `next build` НЕ выполняет компонент** и промолчал про падение.
Проверять только настоящим браузером: `playwright` (установлен в Python312) + Chrome headless,
скрипт `scratchpad/check_cube.py` — кликает экран, собирает `pageerror`/console и снимает скриншот.
Сборка зелёная ≠ страница работает.

**How to apply:** правишь экран CUBE — гоняй check_cube.py перед докладом. Хочешь новую сферу
на экране — добавь её в селфтест бота, фронт подхватит. Связано: [[cube_selftest_sees_outside_spheres]],
[[state_lives_outside_the_code]], [[cube_hub_adr003]].
