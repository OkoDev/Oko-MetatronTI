## Три движка структуры и кто с кем согласен

Замер на 18 парах, 1h, 400 баров. Матч событий **по ЦЕНЕ уровня** (±0.05%),
не по индексу — см. «ловушка» ниже.

| сравнение | событий | матч по цене | тип BOS/CHoCH совпал |
|---|---|---|---|
| **OKO ↔ smc_engine** | 393 / 354 | **354 = 100% от A** | **349/354 = 99%** |
| smc_engine ↔ БОЙ | 354 / 455 | **57 = 16%** | 34/57 = 60% |
| OKO ↔ БОЙ | 393 / 455 | **64 = 16%** | 34/64 = 53% |

`oko_sm_engine.run_structure` и `smc_engine.detect_structure_breaks` — **фактически один
движок**: одни бары (сдвиг индекса 0 в 348 случаях из 354), одни цены, один тип.
Расходится только третий — тот, что стоит в бою.

## 🔑 Корень — НЕ масштаб, а `else` в классификации (исправлено 02.09)

🔴 Первая редакция этого файла называла корнем «разный масштаб». **Неверно**, поправил
Егор: «движок считает структуру сразу с двумя длинами, 5 и 50 — это детекция структуры
и микроструктуры ОДНОВРЕМЕННО». Зафиксировано ещё 28.08 в `docs/MATRIX_REGISTRY.md:146`.

`run_structure` ведёт **два слоя разом**, с раздельными трендами `trend` / `itrend`;
у каждого события есть флаг `internal`. Замер по слоям (18 пар, 1h/400):

| слой | событий | BOS / CHoCH |
|---|---|---|
| эталон, МИКРО (`internal_len=5`) | 353 | **54% / 46%** |
| эталон, СТРУКТУРА (`swing_len=50`) | 40 | **62% / 38%** |
| **БОЙ** (`swing_period=5`, ОДИН слой) | 455 | **29% / 71%** |

Микро/структура = 8.8:1 (сходится с зафиксированным 28.08: 1006/126).

**Масштаб ни при чём:** эталонный микро-слой работает на той же длине 5 и даёт
каноничные 54/46. Бой на длине 5 даёт 29/71. Различает их не длина, а логика.

### Настоящий корень — `structure.py:221-232`

```python
local_trend = _infer_local_trend(swings, swing.index)
if local_trend == StructureTrend.BULLISH:
    btype = BULLISH_BOS
else:                       # ← сюда падают NEUTRAL и None
    btype = BULLISH_CHOCH
```

`_infer_local_trend` возвращает `BULLISH`/`BEARISH` только при чистых HH+HL / LH+LL,
иначе `NEUTRAL`, а при <3 свингов — `None`. Замер на 250 пробоях (10 пар, 1h):

| что вернул тренд | доля | как метится |
|---|---|---|
| BULLISH / BEARISH | 55% | BOS либо CHoCH — верно |
| **NEUTRAL** | **34.4%** | **всегда CHoCH** |
| **None** (<3 свингов) | **10.8%** | **всегда CHoCH** |

🔴 **45% пробоев метятся CHoCH не потому, что рынок развернулся, а потому что движок
не смог определить тренд.** Класс «молчаливый отказ»: неизвестность оформлена как факт.

Бой ещё и пишет одно движение как несколько событий: один бар сносит два свинга —
две записи (1h: 80 записей на 66 барах, 18%). Формально верно, но ML/режим/TSL
получают двойной вес одного хода.

Бой не соответствует НИ ОДНОМУ слою эталона: с микро совпало 16% событий,
со структурой 20% (и тип там 0/8). **Старшего слоя у боя нет вовсе** — 40 структурных
событий на 1h, задающих контекст, в бою отсутствуют.

🔑 Двухслойность конструктивно необходима: при `swing_len=internal_len=5` микро-слой
выдаёт **0 событий** — слои схлопываются.
