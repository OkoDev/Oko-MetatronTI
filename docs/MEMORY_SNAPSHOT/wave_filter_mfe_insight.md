## ПОЧЕМУ (ответ в гайдах [[elliott_ikigai_guides]])
Детектор ловит «слом+откат0.618+вход», но НЕ различает КАКАЯ волна. Откат 0.618 бывает: (1) конец **волны 2** → впереди **волна 3** (1.618, большой R); (2) конец волны 4 → волна 5 ОГРАНИЧЕНА; (3) середина коррекции A-B-C → разворот, стоп. Вхожу во все → половина слабые → MFE 1R.
