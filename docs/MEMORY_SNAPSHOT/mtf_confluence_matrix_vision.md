## Архитектура: СКЕЛЕТ + КОНФЛЮЭНЦИЯ
```
СКЕЛЕТ (готов, core/smc/ote_matrix.py):
  structure_trend → сломы/ноги (BOS/CHoCH, защищённые уровни, правило Егора)
  ote_matrix     → OTE-зоны всех ТФ от ног (0.5-0.79 откат, SL за слом, цель −0.62)
  coherent_structure → связность: младшие наследуют слом+ногу старшего (боковик не ломает)
  matrix_playbook → bias / НЕтронутая старшая OTE = МАГНИТ / что ждём / скальп-к-зоне / флип
  reversal_state → переворот младший→старший (каскад снизу)

КОНФЛЮЭНЦИЯ (стекается на КАЖДУЮ зону скелета, MTF-вложенно):
  OTE  = сама зона отката (структурный вход)              [ЕСТЬ: ote_matrix]
  FIB  = уровни 0.5/0.62/0.705/0.79 + цели −0.62/−1/−1.618 [ЕСТЬ: build_ote]
  SMC  = OB/FVG/EQH/EQL ВНУТРИ зоны = магнит/подтверждение [ЕСТЬ: smc_engine, build_smc_snapshot]
  Pivot= недельный/дневной S/R совпал с зоной = сильнее    [ЕСТЬ: pivots, pivot_behavior_map]
  WT   = WaveTrend oversold в long-OTE / overbought в short= триггер-моментум [ЕСТЬ: WT indicator]
  DIV  = дивергенция RSI/WT на зоне = подтверждение разворота [ЕСТЬ: divergence detector]
```

## Как это «всё вместе» (правило)
1. **Матрица локализует** — где цена в стеке OTE-зон всех ТФ (скелет «где мы»).
2. **Значимость зоны = КОНФЛЮЭНЦИЯ** — сколько детекторов совпало на зоне (OTE+FVG+Pivot+WT+DIV = сильная;
   OTE-solo = слабая). Формула [[project_confluence_principle]] score=gravity/dist^1.5.
3. **MTF-вложенность усиливает** — младший сигнал ВНУТРИ старшей зоны = конфлюэнция масштабов
   (LTF-OTE в HTF-OTE, [[mtf_nested_zigzag_principle]]).
4. **Вход = высокая конфлюэнция + младший ТРИГГЕР** (CHoCH/WT-cross/DIV) в значимой (untouched) старшей зоне.
5. **Прайм-вход = НЕтронутая старшая OTE** (урок XLM: отскок от мелкой 1h OTE = слабый; 4h OTE untouched =
   магнит, там прайм). Путь к зоне торгуем младшим контр-leg (matrix_playbook даёт план).
