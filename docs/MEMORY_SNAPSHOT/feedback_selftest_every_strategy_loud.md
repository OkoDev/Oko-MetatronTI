# 🔴 SELF-TEST ДЛЯ КАЖДОЙ СТРАТЕГИИ, И ГРОМКИЙ

**Правило Егора, 25.08.2026:** «self-test'ы для всех стратегий должны быть и должны
работать не втихую».

**Why:** 25.08 на вопрос «как там сделки» выяснилось, что поток встал. Бот писал
`скан 250 пар · новых 0` — и всё. Чтобы понять, почему ноль, ушло несколько часов и
четыре отдельных замера: воронка детектора, тест лага сканирования, аудит журналов,
поиск всех фильтров по коду. Ответ должен был быть в ОДНОЙ строке лога.

В раннере нашлось **пять молчаливых отсевов** подряд (`impulse_fib_runner.py`:
кэп · сторона · сетап не live · три гейта механики · дедуп origin_ts) — ни один не
объясняет себя. Тот же класс, что уже ловили: [[bug_gate_lives_in_two_places]],
[[bug_source_policies_deadpath_router_off]], порог `min_bars` в харнессе,
[[zombie_open_without_pid_lifecycle_hole]] (WARNING в цикле 21 день, и никто не читал).

**How to apply:**
- у каждой боевой стратегии — self-test, который прогоняет СИНТЕТИЧЕСКИЙ сигнал через
  весь её путь (детектор → гейты механики → роутер → регистрация) и печатает, кто убил.
  Образец уже есть: `scripts/strategy_preflight.py` — расширить до всех источников;
- каждый проход лупа печатает ВОРОНКУ, а не только итог: сколько символов просмотрено,
  сколько сетапов найдено, сколько отсеял каждый гейт по имени. `новых 0` без разбивки —
  недопустимо;
- ни один `continue` в торговом пути не остаётся без причины в логе (хотя бы DEBUG);
- self-test обязан быть виден: результат в лог при старте и по расписанию, а не «есть
  скрипт, который можно запустить руками»;
- молчание = отказ. Если стратегия не дала сигналов за сутки — это событие, а не норма.

**Проверка правила:** если на вопрос «почему нет сделок» нельзя ответить, посмотрев
лог за минуту, — правило не выполнено.
