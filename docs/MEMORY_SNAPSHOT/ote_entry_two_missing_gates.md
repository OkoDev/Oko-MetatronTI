ICNT/USDT LONG-сетап на реальной OKO-SM разметке Егора (4h+15m), цена 0.182 в OTE-зоне 0.705-0.786.

## Разметка (OKO-SM, из pine_boxes/labels через MCP)
- Импульс: 0=0.2564 (high) → Weak Low 0.1554 (вниз) → откат вверх = LONG-сетап.
- OTE-зона: 0.705=0.1852, 0.786=0.1770. Цена 0.182 внутри → детектор даёт FIRE.
- FVG-боксы 4h: **0.16-0.17 под ценой**, у Weak Low. Пивоты: PPD 0.18, S1D 0.181, S1W 0.16.

## 🎯 Два недостающих гейта входа (обе находки Егора подтверждены)
1. **FVG-под-SL = магнит к стопу.** FVG 0.16-0.17 висит МЕЖДУ входом (0.182) и SL (за Weak Low 0.1554).
   Незакрытый FVG притягивает цену → она сходит его закрыть (вниз) = выбьет SL до движения к TP.
   Гейт: если между entry и SL есть незакрытый FVG ПРОТИВОПОЛОЖНОЙ стороны → skip/сдвинуть вход.
2. **LTF-CHoCH обязателен.** Детектор входит по «цена коснулась зоны», НЕ требует слома структуры
   на LTF в сторону сделки. ICNT 15m: справа только BOS ВНИЗ + CHoCH, разворотного bull-CHoCH НЕТ →
   структура ещё медвежья → LONG преждевременен. Гейт: вход только после LTF-слома В сторону сделки.
