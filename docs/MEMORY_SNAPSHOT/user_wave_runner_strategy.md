# Разгонная стратегия юзера (раскрыта 08.06.2026) — ядро WAVE-FLAGMAN

Юзер раскрыл СВОЙ торговый почерк, который хочет оцифровать (суть проекта «убрать себя как эмоцию»).

## Схема ($50 → макс $7000 руками)
1. **Разворот на МЛАДШЕМ ТФ** (минутки/5m).
2. **Вход на откате после волны-1** (предполагаемой) — самый идеальный вход.
3. **Вылет в волну-3** (по Эллиотту самая длинная) — основной профит.
4. После формирования **1-го импульса на СТАРШЕМ ТФ — выход**.
5. **Реинвест** (50 + профит) → откат СТАРШЕГО ТФ → опять заход в волну-3 старшего.
6. = **КАСКАД младший→старший ТФ** (это наш nested-MTF подход, OTE риск×10).

## Почему оцифровать (эмоция убивала)
- «Эмоционально подгорел»: большое плечо + право на ошибку мало.
- Страх упустить сделку → преждевременные входы → **потери** (сам признал).
- БОТ не боится, не торопится → берёт edge БЕЗ эмоции = **оцифрованный трейдер**.
- Это буквально изначальная идея проекта: «оцифровать себя, убрать эмоцию из торговли».

## 🔴 ГЛАВНЫЙ ВЫЗОВ WAVE-FLAGMAN: читать ХАРАКТЕР волны-2
**Самое сложное и затратное (по словам юзера) — НЕ найти 1-2-3, а распознать ЗАТЯЖНУЮ волну-2.**
- Учебник: волна-1 → коррекция-2 → погнали в 3 (легко, 100%). Рынок: волна-2 = изматывающая (накопление → ложный пробой → **вынос ликвидности** → ТОЛЬКО потом волна-3).
- Волна-2 создана чтобы ВЫБИТЬ зашедших правильно (собрать стопы перед волной-3).
- Различить: **накопление vs разворот? вынос ликвидности (выбьет и пойдёт) vs инвалидация (выбьет и упадёт)?**
- → движок учить читать характер коррекции-2: объёмы, время в коррекции, **sweep ликвидности под swing (EQL/EQH)**, накопление. Это превращает «бот по учебнику» в «почерк юзера».

## 💡 Философия (манифест проекта — почему оцифровка = edge)
- **Рынок работает ПРОТИВ человеческих эмоций** (дизайн, не баг): страх→продаёшь на дне (вынос-2), жадность→покупаешь на хае (конец-3).
- Вынос толпы, смена нарративов, переобувание инфлюенсеров (бык↔медведь) = машина конвертации эмоций толпы в деньги меньшинства.
- Психология человека НЕ заточена под рынок → теряют точку зрения в сложных волновых → теряют депозит.
- **Бот не имеет психики, которую рынок эксплуатирует:** не паникует (держит SL под инвалидацию), не читает твиттер (читает СТРУКТУРУ), не торопится, не переобувается. Этого ДОСТАТОЧНО для меньшинства, которое забирает.
- Юзер годами платил эмоциями+депозитом за знание контекста волны → теперь кодирует его в систему, которая платить эмоциями не умеет. Это и есть «оцифровать себя».
