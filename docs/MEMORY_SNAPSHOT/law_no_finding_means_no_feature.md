# 🔴🔴 «НАХОДОК НЕТ» = НЕТ ПРИЗНАКА, А НЕ НЕТ ЯВЛЕНИЯ (30.08.2026)

Я доложил: «связок в long нет, P(шум)=0.500, красивые PF 4-5 в списке — шум».
Егор: **«не может быть чтобы не нашлось ни одной связки в лонг! не может рынок давать
только одну сторону!»**

За час после возражения long нашёлся: [[long_relative_strength_axis]], ×1.49 при зеркале
short ×0.62, медиана месяца +1.8% против −60% у базы.

**Why:** перебор ищет только среди тех вопросов, которые ему заданы признаками. 753 колонки
матрицы описывали монету саму по себе и вселенную целиком — и ни одна не отвечала «сильнее
ли эта монета рынка». Отсутствующий признак неотличим от отсутствующего явления: обе ситуации
выглядят как P(шум) высокий. Это уже ТРЕТИЙ такой случай подряд:

| «находок нет» | оказалось |
|---|---|
| [[basics_missing_volume_candle_profile]] | объём — 1 признак из 565, анатомия свечи — 0 |
| [[matrix_covers_six_percent]] | 216 решающих признаков вне матрицы |
| [[long_relative_strength_axis]] | относительной силы монеты не было НИКОГДА |

Второй дефект того же доклада: **я объявил шире, чем померил.** Замер был — одна механика
(`impulse_fib`), один ТФ (15m), поверх гейта, откалиброванного под SHORT. Объявлено —
«связок в long нет». И окно оказалось односторонним: 3 медвежьих года из 4, а в единственном
бычьем зеркало идеальное (long 1.53 против short 0.13). Ловушка протокола «"лонг мёртв"
на медвежьем окне — тавтология» сработала при том, что я её знал.

**How to apply:** перед докладом «находок нет» выполнить три шага, и только потом формулировать.

1. **Инвентаризация базы.** Прибыльна ли база сама по себе? Фильтр НЕ создаёт эдж — он его
   отбирает. Над убыточной базой (long PF 0.89) перебор обязан вернуть шум, и это верный
   ответ на неверный вопрос. Печатать: база по годам · режим каждого года · есть ли в окне
   противоположный режим вообще.
2. **Грепнуть матрицу на семью, отвечающую вопросу задачи.** Ищешь long — есть ли хоть один
   признак про относительную силу? Ищешь исполнение — есть ли про спред? Отсутствие семьи
   даёт ровно ту же картину, что отсутствие эджа.
3. **Формулировать РОВНО по замеру.** «На 15m в механике impulse_fib поверх short-гейта
   связок не нашлось» — можно. «Связок в long нет» — нельзя.

И отдельно: **возражение Егора «этого не может быть» — рабочий сигнал, а не спор.** Он мыслит
рынком; когда результат противоречит устройству рынка, дефект почти всегда в моём приборе.
Проверять прибор, а не защищать вывод.
