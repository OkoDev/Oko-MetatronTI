**⚠️ РИСКИ/НЮАНСЫ:**
1. **Бумажная иллюзия (моё возражение, не снято — отложено в данные):** на неликвиде VST даёт красивый R, но реал slippage съест → метрики раздуются. При анализе ОБЯЗАТЕЛЬНО поправка slippage (slip ∝ 1/volume) — иначе самообман (= «разрыв бумага↔реальность» из аудита DS).
2. **Нагрузка scan/event loop:** 240→500+ пар (DS отметил event loop saturation). Следить за SLOW await / scan loop time.
3. **Требует РЕСТАРТ** (config + load_markets при старте).

**🎯 КРИТЕРИЙ РЕШЕНИЯ (через ~неделю, min 30+ неликвид-сделок):**
- split сделок по `volume_24h`: бакеты <1M / 1-5M / >5M
- сравнить avgR + WR + **median** (не только avg — раннеры искажают) ПО бакетам
