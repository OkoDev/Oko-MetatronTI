## 🔴🔴 РИСК КОНТЕКСТА В БОЮ ЗАКРЫТ ЗАМЕРОМ (04.10): шина слепа ~75 минут после каждого рестарта

Егор: «закрыть риск точно необходимо». Замер `scratchpad/risk7_bus_vs_causal.py` — сверка живой
шины с каузальным расчётом ПРЯМО СЕЙЧАС.

**Результат: контекста в шине НЕТ у 0 из 100 случайных пар** через 25 минут после рестарта,
при том что каузальный расчёт в тот же момент находит сетапы (FARTCOIN SHORT, PIXEL SHORT).
До рестарта в шине было накоплено 497 пар — всё обнулилось.

**Почему:** `wave5_setup` живёт только в памяти процесса. После старта луп берёт 120 пар за
проход (проход 519 с, интервал 900 с), значит полное покрытие 569 пар = **5 проходов ≈ 75 минут**.
А бот 04.10 перезапускался **11 раз за день** (restarts 30 → 41) — причина названа Егором:
над проектом параллельно работали НЕСКОЛЬКО СЕССИЙ, каждая со своим рестартом. Это не дефект
бота, но для контекста последствие то же: заметную часть суток его нет, и это не видно никому —
потребитель получает пусто и считает «нет импульса». 🔑 Значит персист нужен ТЕМ БОЛЕЕ: частые
рестарты здесь норма рабочего процесса, а не аварии, и ждать их прекращения бессмысленно.

🔑 **Следствие для веса механик: строить его на контексте ИЗ ШИНЫ нельзя.** Часть сделок получит
