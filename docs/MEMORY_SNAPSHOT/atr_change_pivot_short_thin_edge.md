## 🎯 ИТОГ всего исследования (3 направленных подхода)
atr_change-флип · LONG-зеркало · pivot-bounce — КАЖДЫЙ: (1) standalone минусовой, (2) плюсует только
«в свой режим» (SHORT медвежьи / LONG бычьи), (3) тугие стопы за линию/уровень = свит. **Направленной
pivot-ставки со standalone edge НЕТ — всё упирается в РЕЖИМ (доказано 3×).** Единственный непроверенный
путь = режимный гейт (LONG-в-BULL+SHORT-в-BEAR через weekly-P-slope/weekly-bias). Иначе — назад к
живому ote_nested (mean-reversion, работает).

## Выводы
1. **Чистый Supertrend-flip edge НЕ несёт** (пила). Подтверждает: «4h золото +0.692R n=94» был R-иллюзией на малом отборе ([[principle_measure_pct_not_r_LAW]]).
2. **WT-крайность как механический фильтр ВРЕДИТ** (концепция «от перекупленности» в лоб не работает).
3. **Недельный central-pivot bias (Егор-приоритет) РЕАЛЕН для SHORT** — переворачивает направленность. LONG не работает (крипто bull-bias: шорт-тренды от pivot несут, лонг нет). Бьётся с [[ote_all_setups_honest_map]] «SHORT≫LONG».
4. **Edge на грани costs** — нужен рычаг, НЕ ещё фильтры вслепую:
   - **LIMIT-вход (maker)** → costs 0.2→~0.05% → mean ~+0.25%. Решает хрупкость (тот же LIMIT-вектор что для ote slippage).
   - **FVG@pivot / вход у S1-R1** → median из минуса, отсечь пилу (Егор: «FVG в районе пивотов очень сильный знак»).
5. **Урок исполнения:** стоп НЕ на линию Supertrend (свит) → [[stop_on_line_is_liquidity_sweep]]. Выход = close-за-линией.
