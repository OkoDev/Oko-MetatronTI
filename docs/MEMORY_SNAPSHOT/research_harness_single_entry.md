| `scripts/ds_mining_features.py`, `pattern_sets_claimed_vs_live.py` | майнинг признаков | живут отдельно от харнесса |

## ✅ `scripts/research_harness.py` — ЧТО ЗАШИТО НА ВХОДЕ
```python
R = collect(mechanic, tf="15m", n_symbols=25)   # механика + ВСЯ матрица
report(R)                                        # обязательные срезы, ВСЕГДА
blind_select(R)                                  # IS → OOS, один раз
```
- **вся матрица подтягивается сама** → забыть семью технически невозможно;
- **чёрный список не-причинных**: `*_fvg_overlap_held` (проверено префиксом: 150/151 чисты);
- **флаги берутся на баре ВХОДА**, не импульса;
- **косты вычитаются в харнессе** (закон №1: % net, не R);
- **хрупкость (безтоп10%) и охват монет — в КАЖДОЙ строке**, не по желанию;
- **слепой отбор**: кандидаты только на IS, OOS открывается ОДИН раз.

## 🔴 ФОРМАТЫ — ТРИ ТИХИХ НУЛЯ ЗА ОДИН ДЕНЬ
Все три дали пустой результат, а не ошибку:
1. `compute_flags` требует **DatetimeIndex** (ресемплит пивоты);
2. SMC-детекторы требуют **RangeIndex + колонку `time`** — иначе 0 детекций;
3. символы в кэше **без суффикса**: `0G/USDT`, не `0G/USDT:USDT`.
Плюс: в матрице есть **текстовые колонки** (имя ближайшего пивота `'PP'`/`'R1'`) —
`.astype(float)` падает, нужен `select_dtypes(include=["number","bool"])`.

## АУДИТ ПРИЧИННОСТИ МАТРИЦЫ (21.08)
