**Расширение choch_wavec по «своим» осям НЕ дало ничего** (29 156 сделок, 470 монет):
- **LONG-зеркало минусит** во всех конфигурациях: Δr −0.11…−0.42, медиана −2.4. Правило одностороннее.
- **Окно фила 12 баров — лучшее**: 12 → Δr +1.19, 24 → +0.93, 48 → +0.73. В отличие от impulse_fib,
  где расширение окна удвоило деньги: лечение НЕ универсально, каждую механику мерить отдельно.
- **Диапазон стопа 8-15% — лучший**: шире = хуже и хрупче (5-20% → +0.96, без границ → +0.68
  при безтоп10% −7 064). Подтверждает закон размера стопа с другой стороны.
