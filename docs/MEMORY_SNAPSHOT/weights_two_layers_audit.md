Разбор 05.10 по вопросу Егора «на чём основываются веса и какие признаки используют».

## СЛОЙ 1 — `signal_weights` (веса ТИПОВ сигналов)

`core/trading_intelligence.py:106` база · `update_signal_weights()` там же:246 ·
применение `core/intelligence/signal_aggregator.py:15`.

**Основание:** `avg_R` по типу сигнала, EMA half-life 50, `data_era='post_fix'`, минимум
20 закрытых сделок. `factor = clamp(1.0 + avg_R*0.4, 0.5, 2.0)`, `вес = база × factor`.
Ключа `trading.adaptive_weights` в конфиге **нет** → работают дефолты кода.

🔴 **Веса стоят на R, а [[principle_measure_pct_not_r_LAW]] запрещает мерить эдж в R.**
Соседний слой (ниже) это уже исправил, этот — нет.

🔴 **Влияет на ~3% боевых сделок.** За сен–окт 1660 из 1660 сделок имеют `source_router`
(стратегии: `ote_nested` 575, `impulse_fib_15m` 545, `wl_breach` 246, `radar` 95…), и силу
задаёт роутер: `router_final_strength == strength` в 1640 из 1660. Типы, которые реально
участвуют в весах, — только 48 сделок (`mtf_bias` 41 + `pivot_reversal` 7).

🔴 **21 из 28 типов в БД получают дефолт 0.1 МОЛЧА** (`signal_weights.get(type, 0.1)`).
Так `radar_pump` (n=249, avg_R −0.10), `liquidity_sweep` (n=202), `rangefade4h` (n=42,
avg_R −0.58) весят 0.1 — больше, чем проверенные `wt_signal` 0.078, `trend_signal` 0.05,
`anomaly` 0.03. Непроверенное стоит выше проверенного слабого.

⚖️ **Сила — СРЕДНЕВЗВЕШЕННОЕ**, не сумма: `Σ(strength×w)/Σ(w)`. При ОДНОМ сигнале вес не
влияет вообще. Веса работают только на конфликте/множестве.

⚖️ Фактические факторы почти единица: pivot 0.89 · wt 0.97 · divergence 1.04 · wt_b 0.99 ·
mtf_bias 0.88. Кламп [0.5, 2.0] не используется — адаптация сдвигает вес на 3–12%.

⚠️ `docs/INDICATORS_GUIDE.md:364` **устарел**: там MTF_ALERT 0.30 / MTF_SIGNAL 0.25 /
PIVOT 0.24. В коде: MTF_BIAS 0.50 · WT_B 0.35 · PIVOT 0.20 · CONFLUENCE 0.15 ·
SMC_STRUCTURE 0.12 · DIVERGENCE 0.10 · MTF_ALERT 0.10 · WT 0.08 · TREND 0.05 · ANOMALY 0.03.

## ЗНАЧИМОСТЬ ПРИЗНАКОВ МОДЕЛИ SMC (108 = 4 ТФ × 27)

Permutation importance на отложенном по времени куске (учили март–июль, тест авг–окт,
AUC 0.542), а не MDI — MDI смещён в пользу высокой кардинальности:

- 🔴 **выше двух своих сигм только 5 признаков из 108.** Топ — `15m:fib_pos` +0.0071 ± 0.0053,
  то есть сам топ в пределах шума. Пережили порог: `1h:brk_dist_atr`, `4h:ob_bull_age`,
  `1h:brk_strength` и ещё два.
- Сумма положительных вкладов 0.047 при AUC−0.5 = 0.042 → весь «эдж» сидит в этих крохах.
- **булевы признаки 3.9%, непрерывные 96.1%** — и перестановка подтвердила MDI (95.5/4.5),
  значит это НЕ артефакт метода. Прямое подтверждение [[sphere4_features_are_binary_not_source]].
- по ТФ перестановка даёт **15m 55.4%** (MDI 32.8%) против 4h 16.4 · 1d 14.7 · 1h 13.4.
  Вся значимость в слое, записанном как [[ltf_is_execution_layer_not_signal_source]] —
  похоже, модель цепляется за 15m-шум, который не переносится (ср. [[smc_ml_edge_long_only_week_block]]).

**Что из этого следует для пересмотра:** чинить надо слой 1 (основание R → % net; типы
роутеров вне `_map`; дефолт 0.1 для непроверенного), а слой 2 — просто пересчитать, инструмент
готов. Сокращать 108 признаков модели до 5 переживших смысла нет: эдж там на уровне шума.
