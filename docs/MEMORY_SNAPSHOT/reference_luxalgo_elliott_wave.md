## Что даёт (один-в-один наша модель [[htf_significant_context_over_local]])
- **3 ZigZag-степени сразу** (`len 4/8/16`, pivot-based `ta.pivothigh(hi,len,1)`) = ФРАКТАЛ вложенности на ОДНОМ ТФ (len16=крупные импульсы, len4=мелкие). → «все импульсы на 45m».
- **`isWave` = кардинальные правила Эллиотта** (bull): `_W3 != min(W1,W3,W5)` (волна3 не самая короткая) + `_6y>_4y` + `_3y>_1y` + `_5y>_2y` (нет перекрытия 4↔1, верная вложенность). = ОБЪЕКТИВНАЯ значимость полного счёта 1-2-3-4-5, чего НЕТ в find_setups_zz (он метит одну ногу).
- **Фибо 0.5/0.618/0.764/0.854** от волны = НАША OTE-зона входа (0.764≈наш 0.705).
- **`_break_`** при пробое 0.854 → red/dot vs lime/sol = НАША валидность/untested (зона жива пока 0.854 цела). = «структура не сломана».
- **ABC** + «possible new (1)» (circle) = конец коррекции → новый импульс.
