Постановка задачи кому-то (DS/DEV) — **ТЗ целиком в TASKS.md** (критерии, acceptance, файлы, статус, роль). В DISCUSSION.md — максимум короткий пинг «→ DS: поставил задачу X, детали в TASKS» ИЛИ вообще ничего. **НЕ писать развёрнутые многопунктовые ТЗ в DISCUSSION.**

**Why:** юзер раздражён 14.06 («почему ты задачи в дискуссиях ставишь?!»). Длинные ТЗ (бэктест Э3 пункты 1-5, OTE-RBUG, DEV-226) в DISCUSSION засорили живой диалог — его не прочитать как ленту обсуждения. DISCUSSION = диалог агентов (вопросы/ответы/находки/решения), TASKS = задачи.

**How to apply:** при постановке задачи → писать полное ТЗ в TASKS.md (таблица задач). В DISCUSSION только если нужно ОБСУДИТЬ (вопрос к роли, находка, вердикт) — коротко. Уточняет/переопределяет старое [[feedback_tasks_vs_discussion]] («детали в DISCUSSION» — на практике плохо, детали тоже в TASKS). Новые записи в обоих файлах — сверху ([[feedback_discussion_newest_top]]).
