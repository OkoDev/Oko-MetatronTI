После выполнения каждой задачи или подзадачи — немедленно обновить статус в TASKS.md.

**Why:** Несколько раз задачи были реализованы (код написан, бот рестартован) но в TASKS.md оставались со статусом 🔴/🔄. Это создаёт путаницу при /tasks и в командном обсуждении.

**How to apply:**
- Как только задача закрыта → сразу меняй статус в TASKS.md: 🔴/🔄/🟡 → ✅
- После /enrich — если досье показывает done/закрыто → спросить пользователя и закрыть в TASKS.md
- Если задача частично выполнена (под-задачи ✅, основная ещё нет) — обновить описание с отметкой прогресса
- После каждого коммита с feat/fix — проверять связанные задачи и обновлять статусы
