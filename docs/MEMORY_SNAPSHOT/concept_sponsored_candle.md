# SC — Sponsored Candle (определение пользователя/ICT, 04.06)

**SC = свеча с ДВУМЯ условиями:**
1. **Снимает ликвидность:** длинный фитиль обновляет пред. важный экстремум (снимает стопы ритейла).
2. **Импульс-разворот:** сразу после свипа цена резко в ОБРАТНУЮ сторону (close против фитиля),
   часто оставляя имбаланс (FVG).

⚠️ НЕ «длинная свеча без теней» (это была моя ошибка — ловил импульсы, не развороты).
⚠️ НЕ Selling Climax (тоже ошибся сначала). SC = **Sponsored Candle**.

## Разметка box (зависит от направления)
- **Bull SC** (свип МИНИМУМА → разворот вверх, поиск ПОКУПОК):
  - верх box = max(open, close) [верх тела]
  - низ box = Low [фитиль, снявший ликвидность]
- **Bear SC** (свип МАКСИМУМА → разворот вниз, поиск ПРОДАЖ):
  - верх box = High [фитиль]
  - низ box = min(open, close) [низ тела]
- Проекция box вправо по времени = зона поддержки/сопротивления.

## Уровни внутри SC
- **MT (Mean Threshold) = 0.5 box** — середина (от кончика фитиля до противоположной стороны тела).
  Крупный капитал тестит именно середину перед продолжением.
- **Open** — уровень открытия SC (первичная поддержка/сопротивление).

## OB vs SC
- **OB** = последняя ПРОТИВОПОЛОЖНАЯ свеча ПЕРЕД импульсом (зона набора ММ).
- **SC** = САМА свеча со свип-фитилём + разворотом (снятие ликвидности + импульс).
  SC сильнее как разворотный сигнал (умные деньги собрали стопы и развернули).

## 🔴 КРИТЕРИИ ИСТИННОСТИ (истинный SC, как истинный OB) — 4 условия
1. **Свип ликвидности** (фитиль пробил пред. экстремум).
2. **Разворот** (close против фитиля).
3. **CHoCH** — импульс после = слом ПРОТИВ тренда = смена характера. **НЕ BOS!**
   - **CHoCH + FVG = РАЗВОРОТ** (наш SC, разворотный).
   - **BOS + FVG = ПРОДОЛЖЕНИЕ тренда** (другой случай, не SC-разворот).
4. **FVG** (имбаланс сразу после свечи).
→ поле `confirmed=True` только при всех 4. Кандидаты без CHoCH/FVG отброшены.
Проверено XLM 15m: из 11 SC-кандидатов 1 ИСТИННЫЙ (05:00, после CHoCH 0.198→0.2208 + FVG).
Поля: `broke_structure`(CHoCH), `has_imbalance`(FVG), `confirmed`. Коммит 4701b85.

## Реализация
`smc_engine.detect_sponsored_candle(df, lookback=10, min_body_atr=0.5, min_wick_frac=0.3)`
→ `SponsoredCandle(ts, idx, top, bottom, direction, mt, open_level, swept)`.
Проверено XLM 15m 05:00 МСК: BULL SC box[0.1981..0.2041] MT=0.2011 свип=0.2004.

## Вход по SC
Цена возвращается к box SC (особенно MT 0.5) → реакция → вход в сторону разворота.
SL за фитиль (свип-уровень). Часть зонального арсенала OTE: OB + FVG + EQL + SC.
