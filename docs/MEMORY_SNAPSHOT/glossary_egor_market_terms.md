# 🗣️ Словарь рыночных терминов (редакция Егора 24.08.2026)

**ОБЫЧНАЯ форма движения — РОСТ / ПАДЕНИЕ.
ЭКСТРЕМАЛЬНАЯ — ПАМП / ДАМП.**

Слова «залив» и «пролив» из проекта УБРАНЫ. Причина: они разошлись в ТРИ разных смысла
и читались задом наперёд.

**Why:** 18.08 Егор уже поправлял («пролив = вниз, залив = вверх»), но проверка 24.08
показала, что термин всё равно расползся:
- в `rangefade_loop` «залившаяся монета» означало УПАВШУЮ — прямо против той поправки;
- в `structure_terminal` кокпит переименовали в «ширина пролива», а докстринг API
  остался «ширина залива» — экран и код говорили разное;
- в `radar_armed_loop` и `analyze_bleeders` «залив ≥4» означало вовсе не направление,
  а МАССОВОСТЬ (сколько монет разом).

Термин, который надо каждый раз расшифровывать, — плохой термин. Цена ошибки прежняя:
неверно прочитанный экран → неверная сторона сделки.

**How to apply:**
- движение вниз → **падение**; резкое движение вниз → **дамп**;
- движение вверх → **рост**; резкое движение вверх → **памп**;
- много монет одновременно → **кластер** (это про количество, НЕ про сторону);
- метрика ширины (`/api/breadth`, WT<−60) = **ШИРИНА ПАДЕНИЯ** — и в UI, и в коде;
- «фейд падения» = покупка после падения (работает, PF 1.79); «фейд пампа» = продажа
  после роста (не работает, 0.82) — см. [[regime_map_four_setups_downdrift]];
- при любом новом термине в UI — сверять с этим файлом ДО того, как он попадёт на экран.

`rangefade_loop.py` (6), `radar_armed_loop.py` (1). Бэкапы `*.bak.terms`.
