🔑 **ГЛАВНОЕ — не вердикт, а вклад:** геометрия дала **PF ×2.4** (0.37 → 0.88),
перебор `n_down` (фаза Эллиотта, вокруг которой построена ВСЯ спека) — **ноль**.
Ещё одно подтверждение [[stop_zone_survived_blind_test]].

**Корень провала — кост больше стопа.** Стоп по спеке (за верх OTE +0.15%) даёт
медиану **0.36%** при костах круга **0.35%**; средний убыток −0.333% совпадает с
костами до сотой. Тот же класс, что [[live_root_cause_costs_eat_tight_stops]].

## Две ошибки САМОЙ спеки (внесены в документ)

1. **BearBOS + AbovePP несовместимы** при чтении «слом прямо сейчас»: цена не может
   одновременно ставить новый минимум и стоять выше дневного пивота — 720 → 15
   сетапов. Слом должен быть НЕДАВНИМ, вход — на откате.
2. **OTE [0.618–0.786] расходится с эталоном:** `build_ote` знает только
   0.5 / 0.62 / 0.705 / 0.79 (канон Егора 02.06). Ключей 0.618/0.786 в движке НЕТ.

**НЕ проверено:** ТФ входа кроме 15m (метод говорит «4h >> 1h >> 15m, 15m = микрошум» —
вход на 15m может сам быть корнем) · сигнал-специфичность (спека уточнялась на
`divergence`) · TSL после TP1 · лестница TP долями.
