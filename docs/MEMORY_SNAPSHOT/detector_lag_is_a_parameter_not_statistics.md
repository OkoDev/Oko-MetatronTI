# 🔑 ЛАГ ДЕТЕКТОРА — ЭТО ЕГО ПАРАМЕТР, А НЕ СТАТИСТИКА (29.08.2026)

Повод: находка «не входить 24 ч после импульса» оказалась раздутой look-ahead — импульс
Эллиотта виден только через 6 баров после экстремума, а правило мерило с допуском 1 ч.
Тогда же выяснилось, что грубая проверка усечением (шаг 1500 баров) такой лаг НЕ ловит.

## Таблица лагов (замер: 15m, 3 символа, 10 событий на детектор, все совпали до бара)

Шкала: сколько баров должно ЗАКРЫТЬСЯ ПОСЛЕ бара события. `0` = видно на закрытии
самого бара события.

| детектор (бар события) | лаг | в часах на 15m |
|---|---|---|
| `detect_structure_breaks(L)` → `.idx` | **0** при любом L | 0 |
| `detect_order_blocks` → `.break_idx` | **0** | 0 |
| `detect_sponsored_candle` → `.idx` (появление) | **0** | 0 |
| `detect_fvg` → `ts_i` | **0** | 0 |
| `detect_equal_levels(eq_len)` | **ровно `eq_len`** (3 по умолчанию) | 0.75 |
| SC-флаги `confirmed` / `broke_structure` / `has_imbalance` | **5** (`confirm_bars`) | 1.25 |
| **`classify_structure(L)` и `detect_swings`** | **ровно `L`** | **12.5 ч при L=50** |
| `detect_elliott_mtf` (контроль) | 5 | 1.25 |

🔑 **Главный вывод: лаг — АЛГОРИТМИЧЕСКАЯ КОНСТАНТА, равная параметру детектора.**
Проверено параметрически: `classify_structure` при L=5/20/50 даёт лаг 5/20/50;
`detect_equal_levels` при eq_len=2/3/5/10 даёт 2/3/5/10. Корень — `_swings_luxalgo`:
свинг помечается на баре `i − length`, а появляется в списке на итерации `i`.

Следствие: лаг **одинаков в БАРАХ на любом ТФ**, но в календарном времени масштабируется —
50 баров на 1h это 50 часов, на 4h — 8 суток.

## 🔴 Главная ловушка: свинги

`detect_swings(major_len=50)` → лаг **50 баров = 12.5 часа** на 15m. Любой признак вида
«свинг/HH/LH появился N баров назад» с N < 50 **читает будущее**. Это тот же механизм,
который дал невозможный PF 0.04 в истории с Эллиоттом.

## 🔴 Отдельный канал непричинности, НЕ связанный с лагом

`detect_fvg(threshold=None)` считает порог значимости как средний |gap%| × 2 **по всему
переданному ряду** — то есть зависит от будущего распределения. На 9000 барах ни один из
30 гэпов не «мигал», но на коротком окне пограничный FVG может появляться и исчезать.
В `matrix_full.smc_state_features` вылечено: порог берётся по первым 2000 барам и дальше
фиксирован (до лечения усечение давало расхождения в 8 признаках, до 1590 баров).

## Ещё одна оговорка (важная при работе с зонами)

Поля `mitigated_idx` / `is_breaker` у `OrderBlock` и `mitigated` у FVG **смотрят вперёд
по построению** — это «бар, где зону позже пробили». Использовать их можно только так:
зона ЖИВЁТ до `mitigated_idx` (это причинно), а признак «это breaker» известен с бара
митигации, а НЕ с бара слома.

Инструменты: `scripts/detector_confirmation_lag.py` (замер бар за баром) ·
`scripts/smc_confirmation_lags.py` (таблица по всем SMC-детекторам).
