# 🔑 ФОРМУЛА ЦИКЛА СКАНА И ИСТОЧНИК СКАЧКОВ (02.09.2026)

**Вопрос Егора:** «количество пар не меняется — откуда скачки и как ускорять?»

## Формула

```
цикл ≈ (число REST-запросов × latency биржи) / параллелизм(семафор)
```

Проверена на шести реальных циклах (семафор 8):

| REST | latency | расчёт | факт |
|---|---|---|---|
| 2288 | 2.6 с | 744 с | 902 с |
| 2748 | 2.6 с | 893 с | 961 с |
| **1999** | **8.7 с** | **2174 с** | **1890 с** |
| **3416** | **1.3 с** | **555 с** | **446 с** |
| 1301 | 2.6 с | 423 с | 509 с |
| 2711 | 2.6 с | 881 с | 946 с |

Отклонение ±20%, знак и порядок совпадают всегда.

## 🔴 Источник скачков — latency, а не наша нагрузка

- пар всегда **573**, не меняется;
- REST **не объясняет**: цикл 446 с при 3416 запросах против 1890 с при 1999;
- **latency BingX гуляет 2.0 → 8.7 с (×4.3)** — и цикл гуляет 365 → 4548 с (×12.5).

🔴 **Все 69 замеров health_loop — DEGRADED** (порог `LATENCY_DEGRADED_MS = 2000`,
медиана 2594 мс, максимум 8688 мс). Это не эпизод, это постоянное состояние.
Плюс за 2 часа: 502 — 60 раз, 503 — 38, timeout — 68.

🔑 Прямой замер одного запроса через ccxt дал 1265 мс. В бою при восьми параллельных —
2594 мс. Разница и есть цена конкуренции за один IP.

## Как ускорять — три множителя, два из них наши

| рычаг | что делает | оценка |
|---|---|---|
| **WS на 3m/5m** | убирает 63% запросов из числителя | цикл ÷2.7 |
| **прокси** (3 IP в `.env`, флаг off) | семафор 8→15 + свой rps-бюджет на IP | цикл ÷2-4 |
| latency | не наша, снизить нельзя | — |

**Рычаги умножаются:** WS + прокси вместе дают потенциально ÷5.

## Почему проба WS 02.09 не показала ускорения

Она убрала только **31%** запросов (2711→1869: 15m остался на REST), а в те же минуты
latency выросла с 2.1 до 8.7 с. Эффект утонул в шуме внешнего фактора —
поэтому по двум циклам вывода и не получилось ([[market_ws_kline_proven]]).

**Как мерить правильно:** сравнивать не длительность цикла, а **число REST на цикл**
(наша величина, не зависит от биржи) и медиану `ohlcv=` на пару, усреднённые
по ≥6 циклам. Длительность цикла как метрика непригодна: её дисперсия задана биржей.
