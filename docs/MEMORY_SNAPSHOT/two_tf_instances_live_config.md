**LONG на 15m исключён:** с тем же гейтом даёт 0.68, OOS **0.08**. Эффект строго short.

## ПОЧЕМУ ОТДЕЛЬНЫЙ ФАЙЛ, А НЕ ПАРАМЕТР
`bot/loops/impulse_fib_15m_loop.py` — копия с заменами (SRC, TF, таблица, конфиг-ключ).
Причина: боевой `impulse_fib_loop` торгует ПРЯМО СЕЙЧАС, а кэп открытых и `_resolve`
в нём считают по ВСЕЙ таблице без различения ТФ → два инстанса на общей таблице
конфликтовали бы. Своя таблица `impulse_shadow_15m` снимает конфликт.
Дублирование = осознанный техдолг, схлопывание в общий раннер — фаза 3 реестра.
