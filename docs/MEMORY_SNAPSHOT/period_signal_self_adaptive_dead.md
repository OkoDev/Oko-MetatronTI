# 🚫⏱️ ПРИЗНАК ПЕРИОДА ИЗНУТРИ МЕХАНИКИ — КЛАСС ЗАКРЫТ (13.08.2026)

Главный вывод ревизии реестра [[edge_registry_revision_two_axes]]: все уцелевшие фильтры
отвечают «хорош ли сигнал», и ни один — «работает ли механика СЕЙЧАС».
Проверен единственный признак периода, доступный в бою без новых данных:
**собственная недавняя доходность механики**.

`scripts/fade_regime_self_adaptive.py` · причинно (решение по сделке k только по сделкам,
ЗАКРЫТЫМ до её открытия, с учётом TTL=24 бара) · окна K=10/20/40.

## 🔴 Знак НЕ ПЕРЕНОСИТСЯ между ТФ — значит это не признак

| | 4h | 15m |
|---|---|---|
| после хороших окон | PF 2.06 | 3.85 |
| после плохих окон | 1.45 | **37.50** |
| p (после хороших лучше) | **0.00000** ✅ | **0.971 / 0.999** ❌ |
| Spearman(прошлая медиана, результат) | +0.114 | **−0.323** (p=0.0000) |

На 4h связь положительная, на 15m — **отрицательная и сильнее**. Противоположный знак
на двух независимых выборках = артефакт, а не свойство рынка.

## 🎣 Ловушка, ради которой стоит помнить этот замер
`p=0.00000` при бинарном разделении и `Spearman=−0.012 (p=0.68)` при K=10 —
**в одном и том же замере**. Противоречие объясняется тем, что сделки НЕ независимы:
они приходят залпами (64–96% сигналов года в топ-3 месяцах), и внутри залпа результаты
скоррелированы. Бинарный тест меряет кластеризацию, а не предсказуемость.

**ЗАКОН: перед тем как радоваться p<0.001 на серии сделок — проверить, независимы ли
наблюдения. При кластеризации считать по событиям/дням, а не по сделкам.**
Тот же капкан ловился в этот день дважды: у RR (перекрытые окна) и здесь.

## ⚖️ ИТОГ ДНЯ: признак периода НЕ НАЙДЕН, проверено три класса
| класс признака | результат |
|---|---|
| изнутри механики (своя доходность) | знак не переносится между ТФ |
| состояние рынка (корреляция) | не разделяет 2024 и 2026 |
| состояние рынка (объём) | усиливает хорошее, не спасает плохое |

Плюс ранее отвергнуты: режим года по дрейфу, глубина просадки, волатильность,
возраст монет, ликвидность, сессия, RR. **Общий паттерн у ВСЕХ: улучшают 2024–25
и не помогают в 2022/2026.**

**Следствие для стратегии:** перестать искать предсказатель периода и строить
РИСК-МЕНЕДЖМЕНТ — лимит просадки и быстрое отключение по факту убытка,
а не по прогнозу. Предсказание периода доступными данными не решается.

## Что остаётся для поиска признака периода
Изнутри механики — закрыто. Снаружи проверены и отвергнуты: режим года по дрейфу,
глубина просадки, волатильность, возраст монет, ликвидность, сессия, RR.
Не проверено: макро-структура (доминация USDT.D/BTC.D), объём/OI рынка целиком,
дисперсия между монетами (корреляционный режим).
