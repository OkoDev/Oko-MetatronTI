# 🔧 ТРИ ДЕТЕКТОРА ПОЧИНЕНЫ: пороги переведены в масштаб ТФ (10.09.2026)

Диагностика через гиперкуб показала частотный дрейф — признак срабатывает на младших
ТФ и умирает на старших. Причина у всех одна: **порог задан абсолютно, а не в масштабе слоя.**

## Что исправлено

| файл | было | стало | дрейф 240m/3m |
|---|---|---|---|
| `swing_bridge.py` | `_LIQ_NEAR_PCT = 0.5` (% цены) | `0.81·ATR(14)` | 0.006 → **0.49** |
| `swing_bridge.py` | окно OB `−0.5%…+3%` | `−0.81·ATR … +4.84·ATR` | 0.000 → **1.19** |
| `combinator_core.py` | `_wtx_divergences`: сравнение с ОДНИМ предыдущим фракталом | история `WTX_MAX_PP=10` в пределах `WTX_MAX_BARS=100` | частота 0.3-0.9% → **ровно 3% на всех ТФ** |

Множитель 0.81 откалиброван так, чтобы на 15m порог остался прежним (ATR(15m)≈0.62%
⇒ 0.81·ATR ≈ 0.5%) — поведение на боевом ТФ не изменилось, ожили старшие окна.

🔑 **Проверка по эталону Егора** (HYPE 1h, 02.08.2026, минимум 51.107): починенная
дивергенция ставит `bull_reg` за **2 бара до дна**. Старый детектор эту точку не видел.
