# 🌊 КОРРЕКЦИЯ ПОСЛЕ ПЯТОЙ ВОЛНЫ — ИЗМЕРЕНО (12.09.2026)

Егор: «если 5 волн импульса прошло — всегда есть коррекция, на любом ТФ; экстремум 5-й волны
у зоны OB/OS, на нём ВОЗМОЖНА дивергенция, вход по кроссу, выход по фибо».
🔴 Раньше НЕ проверялась в этой геометрии: фейд импульса выходил по 3×ATR и времени.

Скрипты: `scratchpad/wave5_correction.py` (база) · `wave5_wt_entry.py` (правило целиком) ·
`wave5_charts.py` (картинки). Страница с графиками — артефакт «Коррекция после пятой волны».

## Правило как измерено
Префиксный проход (импульс в момент ПЕРВОГО появления — иначе перерисовка зигзага даёт PF 15
из воздуха) → вершина w5 в зоне |WT|>Z → дивергенция ФЛАГОМ → первый кросс wt1×wt2 против
импульса → open следующего бара. Стоп за экстремум w5 (×1/1.5/2). Цели: зона w4 · 0.382 · 0.5 ·
0.618 · выход по времени 7/14 сут. Контроль: случайный вход ±30 дн, та же геометрия в %.
Счёт по ЭПИЗОДАМ. Кост 0.10%.

## 🔑 Два дефекта, найденные ГЛАЗАМИ на картинках (в таблицах их не было)
1. **Гигантские импульсы**: dev=3 ловит 50-65% хода, «зона w4» оказывается в +127% от входа.
2. **Опоздание входа**: вход по подтверждению импульса — цена уже на 13% от вершины, стоп 15% при
   цели 6%. ⇒ вход по КРОССУ WT сократил опоздание с 25% до 14% импульса — идея Егора работает.

- **Фильтр RR≥1.5**: отсекает плохие (17% сделок с целью ближе стопа), но эдж не создаёт (53-й перц.).
- **Шорт-ветка 14 сут z45**: +1.336% при контроле −1.22%, n=179 — случайный отбор **92-й перц.**,

## Вердикт (протокол)
**Подтверждено как ЯВЛЕНИЕ**: разворот после w5 приходит чаще случайного — +2…+3 п.п. на 4h,
значим при любом стопе, любой цели и при выходе по времени (три независимых способа).
**Не подтверждено как СИСТЕМА**: абсолют ~0, медиана <0 везде, WR 23-41%, плюс в правом хвосте,
на 1h/15m перевеса нет. Причина — РАМКА ([[frame_map_no_positive_median_for_long]]): случайный
вход в ней теряет 1.3-2.8%/сд, перевеса хватает ровно на ноль.
🔑 **«Лучше контроля» и «прибыльно» — ДВА РАЗНЫХ вопроса.** Весь день мерили первое, принимая за второе.
