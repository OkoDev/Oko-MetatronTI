## Почему пережил (в отличие от всех прочих)
1. Сигнальный ТФ = торговый (вход по close 4h флип-бара) — нет HTF-intrabar-проблемы.
2. Уровни статичны (пивоты прошлой недели) — нет пере-подгонки.
3. SHORT-механика в крипте систематична (4-й независимый сигнал: wave_smc, наш рецепт, ote pull, этот).
4. Тонкий но многолетний — то что рынок реально отдаёт после costs.
