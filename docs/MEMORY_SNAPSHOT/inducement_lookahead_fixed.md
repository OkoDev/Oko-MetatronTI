# 🔴 LOOK-AHEAD В `detect_inducement` — найден при внесении в матрицу (04.09)

`core/smc/smc_extensions.py:18`. Было:

```python
if low[i] < sweep_target:
    future_closes = close[i:i + reverse_bars]   # ← бары i+1, i+2
    if (future_closes > min_low).any():
        bull_ind[i] = True                     # ← флаг НА БАРЕ i
```

Флаг на баре `i` зависел от закрытий баров `i+1`/`i+2`. Класс — «данные будущего в баре»,
первый из пяти видов ([[oko_suite_trend_wt_validated]]).

**Починено в источнике** (флаг встаёт на бар ПОДТВЕРЖДЁННОГО возврата):
```python
k = i + int(np.argmax(fwd > min_low))          # первый бар возврата
bull_ind[k] = True
```
Правка безопасна: боевых потребителей нет (grep дал только `scripts/detector_bench.py`
и внутренние функции того же файла). Префиксный тест после фикса: **0 расхождений**
на t=1500/2500/3400, обе стороны.

## Почему это важно за пределами одного детектора

Детектор лежал в `MATRIX_REGISTRY` как «❌ НЕТ В МАТРИЦЕ» с DEV-215. Всё это время он был
непригоден, но об этом никто не знал — потому что **не был внесён и потому не проверялся**.
Внесение в матрицу работает как аудит: префиксный тест ловит то, что глазами не видно.

⇒ Правило: любой детектор, который «есть в коде, но не в матрице», считать НЕПРОВЕРЕННЫМ
на причинность, пока префиксный тест не прогнан. Не «работает, просто не подключён».
