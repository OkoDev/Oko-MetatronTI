# 🟢 ПЕРЕМЕР arch104 НА ПОЧИНЕННОМ FVG — есть живое (13.08.2026)

До 13.08 все 200 паттернов мерились на флаге FVG, смещённом на 2 бара
([[bug_fvg_flag_shifted_two_bars]]), причём 179 из 200 содержат FVG-фактор.
Их настоящего результата не видел никто ни разу.

Скрипт: `scripts/arch104_remeasure_causal.py`. Метрика — **% net с костами 0.35%**
(не avgR), SL проверяется ПЕРВЫМ на баре, TP=2R, TTL 24ч, HTF только с закрытого бара.

## 🔴 ГЛАВНОЕ: полное окно ОПРОВЕРГЛО замер на 2025+

Прогон на 40 монетах, **2023–2026**, n≥50 → 54 паттерна: **плюсовых 3 из 54**
(против «11 из 43» на окне 2025+). `DS_S004`, объявленный лучшим, на полном окне:
**n=880, PF 0.85, −0.296%** вместо +0.815%. Учебный случай
[[feedback_verdict_protocol_egor]]: окно 2025+ = нейтраль+медведь, бычий год не покрыт.

## 🔑 СИГНАЛ В FVG ЕСТЬ, НО ОН МЕНЬШЕ КОСТОВ

```
база:     −0.416% + 0.35% = −0.066% брутто
паттерны: −0.290% + 0.35% = +0.060% брутто
```
FVG-конфлюэнция **выводит брутто из минуса в плюс** и улучшает PF 0.70 → 0.84
на выборках 34–46 тыс сделок — это не шум. Но выигрыш ~0.13 п.п. против костов 0.35 п.п.
Тот же диагноз, что [[crosssection_dead_at_our_costs]]: направление верное, масштаба нет.

**Единственный путь в деньги — размер стопа.** У `DS_S044`: стоп 1–2% → +0.02%,
2–4% → +0.51%, **>4% → +1.26%**. Закон размера в 4-й раз на новой механике.

`DS_S044` (`bear_fvg_1h + pivot_near_R1_1D + pivot_bounce_down_PP_1D`) плюсовой во ВСЕ
годы кроме 2026: 2023 +0.40% · 2024 +1.21% · 2025 +0.28% · 2026 −0.03%. Охват 19/34 (56%),
безтоп10% −23.0. n=102 и 3 из 54 попыток → КАНДИДАТ, не находка.

## Три вывода

1. **FVG сам по себе пуст, работает ТОЛЬКО в конфлюэнции.** Голый `bull_fvg_1h+1d`
   на причинном баре = PF 0.72 при базе 0.72 (ровно ничего). А `bear_fvg + wt_ob`
   даёт PF 1.39. Это прямой ответ на вопрос Егора «можем ли по SMC-признакам искать входы».
2. **Все живые — SHORT + bear_fvg.** Ни один LONG-паттерн в плюс не вышел.
   Сходится с [[regime_map_four_setups_downdrift]] (снос вниз) и
   [[method_shadow_forward_verdict_long_bleeds]] (LONG кровит).
3. **Закон размера подтверждён в 3-й раз на новой механике:** у `DS_S004`
   стоп >4% даёт **+1.49%**, а зона 1–4% МИНУСОВАЯ (−0.51%, −0.55%).
   Сходится с [[bigflush_edge_size_not_timeframe]] и [[stop_tightening_by_structure_dead]].

## ⚠️ Чему НЕ верить

- **Хрупкость отрицательная у ВСЕХ**: безтоп10% от −25 до −1509. Плюс держится
  на верхних 10% сделок. По [[golden_keys_matrix_verdict]] это признак хвоста, не эджа.
- Заявленные `test_WR` 88–94% → причинно **36–54%**. Ранг паттернов частично сохранился
  (bear_fvg-семейство наверху), уровень — нет.
- Окно с 2025 = нейтраль+2026; **бычий год не покрыт**. Прогон с 2023 считается.
- 43 паттерна проверено из 200 → множественное тестирование: 11 плюсовых при 43 попытках
  ожидаемо и без эджа. Нужен OOS на независимом окне.
- Охват монет 52–67% — не подавляющий.
