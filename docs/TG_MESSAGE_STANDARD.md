## 🔝 ШАПКА (обязательна для всех типов)

```
{эмодзи} <b>{ТИП СОБЫТИЯ}:</b>          ← только тип, БЕЗ тикера
                                        ← пустая строка
{🟢|🔴|⚪} <code>{ТИКЕР}</code> {ключевая метрика}
```

- **Цвет = направление сетапа:** 🟢 лонг · 🔴 шорт · ⚪ нейтрально/сетапа нет.
  Отдельная строка «сетап LONG» не нужна — цвет говорит сам.
- **Тикер всегда `<code>`** — копируется одним тапом.
- Ключевая метрика типа: BUILD → `+ΔOI%/5м`, PUMP → `±Δцена%`, ПРУЖИНА → `OI +X%/15м · флэт`,
  СКВИЗ → `Δцена%/3м`, КАСКАД → `$Xk за 90с`.

## 🔚 ПОДВАЛ (обязателен для всех типов)

```
                                        ← пустая строка
- <a href="https://ru.tradingview.com/chart/?symbol=BINGX%3A{SYM}USDT.P&interval=5">TW</a>
- <a href="https://bingx.com/ru/perpetual/{SYM}-USDT">BINGX</a>
                                        ← пустая строка
#{ТИКЕР} #{ТИП}
```

- Две ссылки: график TradingView + страница биржи BingX. Всегда в подвале, НЕ в шапке.
- Хештеги последней строкой — фильтрация канала.

## 📄 ТЕЛО (правила, не жёсткий шаблон)

- **Все цены в `<code>`** — копируемые (вход, стоп, TP, текущая цена).
- **Блоки разделяются пустой строкой** (funding/суть → уровни → цели → подвал).
- Уровни построчно: `Вход: ~<code>X</code>` / `Стоп: <code>Y</code> (обоснование, риск Z%)`.
- Цели: заголовок `🧲 TP`, каждая строка `✅ <code>цена</code> (+X%) [★] · источник`
  (★ = конфлюэнция 2+ слоёв из карты целей 2.0).
- Напоминание-якорь при R:R: «у магнита ФИКСИРУЮТ, не входят».
