## Концепция

Входить SHORT в момент когда:
- Рынок **в Волне 3 вниз** (n_down=2 — начало сильнейшего движения)
- Цена сделала **откат Волны 2 вверх** и зашла в **OTE [0.618–0.786]**
- **AbovePP** — есть пространство вниз к S1, S2

Три концепции сходятся в одной точке входа: **Elliott (фаза) + OTE (зона) + Pivot (пространство) = Triple Confluence**.

```
Волна 1 ↓ → Волна 2 ↑ (OTE зона) → ВХОД SHORT → Волна 3 ↓ к S1/S2
                          ↑
                    точка входа
```

## Логика по таймфреймам

### HTF 4h — ФАЗА РЫНКА

Определяем что мы в начале Волны 3 вниз:

| Условие | Значение |
|---|---|
| `n_down = 2` | Две consecutive снижающихся swing high → начало Волны 3 |
| BearBOS подтверждён | Структура указывает вниз |
| WT 4h нейтральный | НЕ OS (OS = конец волны, не начало) |
| `htf_price_dir = down` | Последние 5 баров 4h идут вниз |

> ⚠️ **Критично:** `n_down` должен быть именно **2**, не 3+. При n_down=3 риск что рынок уже в Волне 5 → STOP SHORT.

### MTF 1h — ПРОСТРАНСТВО

Проверяем что у цены есть куда падать:

| Условие | Значение |
|---|---|
| Цена AbovePP дневного | Пространство вниз к S1 (≈0.382), S2 (≈0.618) |
| `pvt_nearest_level ≠ S2/S3` | Не входить если цена уже у глубокой поддержки |
| WT 1h нейтральный или OB | Подтверждение перекупленности на 1h |

### LTF 15m — ТОЧКА ВХОДА

Ждём откат Волны 2 вверх в OTE зону:

| Условие | Значение |
|---|---|
| Цена в OTE `[0.618–0.786]` | Откат 61.8–78.6% от последнего 15m импульса вниз |
| WT 15m OB `> +60` | Перекупленность в зоне отката = истощение покупателей |
| ATRTrend 15m = trenddown | Локальный тренд подтверждает SHORT |
| bear_div 15m | WT не делает новый OB, цена делает новый High = слабость *(опционально, усиливает)* |

## Расчёт OTE зоны для SHORT

```python
# Последний импульс ВНИЗ на 15m:
High_impulse = последний Swing High до импульса вниз
Low_impulse  = Swing Low после импульса (новый локальный лой)

diff = High_impulse - Low_impulse

# Откат Волны 2 вверх попадёт в:
OTE_bottom = Low_impulse + diff * 0.618  # нижняя граница OTE
OTE_top    = Low_impulse + diff * 0.786  # верхняя граница OTE

# Вход SHORT: когда текущая цена в [OTE_bottom, OTE_top]
```

**Пример:**
```
High_impulse = 100.00
Low_impulse  = 95.00   (импульс вниз 5 пунктов)
diff = 5.00

OTE_bottom = 95.00 + 5.00 × 0.618 = 98.09
OTE_top    = 95.00 + 5.00 × 0.786 = 98.93

→ Вход SHORT когда цена в [98.09, 98.93]
```

## SL / TP / TSL

```
SL:  выше OTE_top + 0.15% буфер
     (если цена пробила OTE_top = откат слишком глубокий, Волна 2 > 78.6% → пересмотр)

TP1: Дневной S1 = pp*2.003 - high  (≈0.382 Fib ниже PP)
TP2: Дневной S2 = pp - (H-L)       (≈0.618 Fib = OTE вниз = Волна 3 цель)
TP3: Дневной S3 = S1 - (H-L)       (расширение, если Волна 3 экстремальная)

TSL: активировать после TP1 (после +1R)
     следить за trenddown 15m
```

**Соотношение R:R:**
```
SL расстояние  ≈ OTE зона (14.4% от импульса = разница 78.6-61.8% + буфер)
TP1 расстояние ≈ PP до S1 (обычно 0.5-1.0% дневного диапазона)
→ R:R ≈ 1:2-3 (зависит от дневного диапазона)
```

## Чек-лист перед входом

### 🔴 Обязательные (все должны быть ✅)

- [ ] `n_down = 2` на 4h (не 1, не 3+)
- [ ] BearBOS на 4h подтверждён (Close за уровнем)
- [ ] WT 4h НЕ в OS (WT 4h > -60)
- [ ] `htf_price_dir = down` на 4h
- [ ] Цена AbovePP дневного
- [ ] `pvt_nearest_level` ≠ S2 и ≠ S3
- [ ] Цена в OTE [0.618–0.786] на 15m
- [ ] WT 15m > +60 (OB) ИЛИ нейтральный при bear_div

### 🟡 Желательные (повышают WR)

- [ ] WT 1h OB или нейтральный (не OS)
- [ ] bear_div на 15m
- [ ] OB (Order Block) совпадает с OTE зоной
- [ ] FVG медвежий в зоне OTE
- [ ] Дневная свеча красная (direction подтверждён)

### 🔴 Стоп-сигналы (если хоть один — не входить)

- [ ] `n_down ≥ 3` — STOP (возможно Волна 5)
- [ ] `n_down ≥ 3` + BullChoCH — СТОП STOP (конец 5 волн: WR=0%, avgR=-2.181)
- [ ] Цена BelowPP — нет пространства для SHORT
- [ ] `pvt_nearest_level = S2` или `S3` — у глубокой поддержки
- [ ] WT 4h OS < -60 — истощение продавцов, не начало Волны 3
- [ ] Reversal Mode active — ABC коррекция вверх идёт

## Управление рисками

- **Размер позиции:** фиксированный % от капитала (не менять под "уверенность")
- **Максимум одновременных позиций по стратегии:** 2
- **Не торговать:** за 1h до/после выхода макро-данных (FOMC, CPI)
- **Недельный стоп:** если 3 подряд SL → пауза, пересмотр n_down фильтра
- **После TP1:** перевести SL в безубыток, дать TSL работать к TP2
