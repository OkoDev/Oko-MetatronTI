# Стратегия: BearBOS Counter-LONG

> Статус: 📊 ПОДТВЕРЖДЕНА ДАННЫМИ | arch104 avgR=+2.001 WR=56%, watch_list_breach avgR=+1.556 WR=61%
> Создано: 28.05.2026 | TF: 4h → 1h → 15m | Направление: LONG (контр-тренд)

---

## Концепция

Покупать когда HTF тренд **ещё медвежий** (BearBOS активен), но цена находится у поддержки BelowPP с **истощением продавцов**. Это не разворотная стратегия — это покупка у дна до того, как рынок официально развернётся.

**Парадокс:** BearBOS лучше для LONG чем BullChoCH. Механика:
```
BullChoCH появился → ты уже опоздал (цена развернулась, ты покупаешь на пике)
BearBOS активен    → ты покупаешь у дна пока все ещё шортят → лучшая цена
```

**Данные подтверждают:**
- arch104 LONG: **BelowPP + BearBOS = avgR=+2.001 WR=56%**
- arch104 LONG: BelowPP + BullChoCH = avgR=-0.235 WR=35% (хуже!)
- watch_list_breach LONG: **BelowPP + BearBOS = avgR=+1.556 WR=61%**

## Логика по таймфреймам

### HTF 4h — КОНТЕКСТ (медвежий, но истощающийся)

| Условие | Значение |
|---|---|
| BearBOS на 4h активен | HTF тренд ещё вниз → контр-тренд LONG с поддержкой |
| `n_down < 3` на 4h | НЕ конец 5 волн (иначе BullChoCH = ловушка) |
| WT 4h OS `< -60` | Продавцы истощены на старшем TF → разворот вероятен |
| WT 4h разворачивается вверх | Первые признаки бычьего WT cross в OS зоне |

> ⚠️ **Критично:** если на 4h появился **BullChoCH** — это сигнал что ты уже опоздал. Стратегия работает именно при **BearBOS** — до официального разворота.

### MTF 1h — ПОЗИЦИЯ (у поддержки, есть пространство)

| Условие | Значение |
|---|---|
| Цена BelowPP дневного | Есть пространство вверх: BelowPP → PP → R1 |
| `pvt_nearest_level = S1` или `PP` | Цена у первой поддержки, не в глубине (не S2/S3) |
| WT 1h OS или нейтральный после OS | Локальное истощение продавцов |

### LTF 15m — ТОЧКА ВХОДА (истощение + подтверждение)

| Условие | Значение |
|---|---|
| WT 15m OS `< -60` | Локальная перепроданность — продавцы устали |
| bull_div на 15m | WT делает новый OS, цена НЕ делает новый Low = скрытая бычья сила *(основной триггер)* |
| ATRTrend 15m → trendup | Локальный тренд начинает разворачиваться |
| Цена в OTE [0.618–0.786] *(опционально)* | Откат вниз после локального импульса вверх = точка откупа |

## Расчёт OTE зоны для LONG

```python
# Последний локальный импульс ВВЕРХ на 15m (если есть):
Low_impulse  = локальный Swing Low (начало импульса вверх)
High_impulse = Swing High после импульса

diff = High_impulse - Low_impulse

# Откат вниз попадёт в OTE:
OTE_top    = High_impulse - diff * 0.618  # верхняя граница OTE
OTE_bottom = High_impulse - diff * 0.786  # нижняя граница OTE

# Вход LONG: когда цена откатилась в [OTE_bottom, OTE_top]
```

**Пример:**
```
Low_impulse  = 95.00
High_impulse = 100.00  (импульс вверх 5 пунктов)
diff = 5.00

OTE_top    = 100.00 - 5.00 × 0.618 = 96.91
OTE_bottom = 100.00 - 5.00 × 0.786 = 96.07

→ Вход LONG когда цена откатилась в [96.07, 96.91]
```

## SL / TP / TSL

```
SL:  ниже последнего Swing Low на 15m - 0.15% буфер
     (если пробился последний Low = структура сломана, BearBOS продолжается)

TP1: Дневной PP = (H+L+C)/3            (первая цель — центр равновесия)
TP2: Дневной R1 = pp*1.997 - Low       (≈0.382 Fib выше PP)
TP3: Дневной R2 = pp + (H-L)           (≈0.618 Fib = OTE вверх = Волна 3 LONG цель)

TSL: активировать после TP1 (после +1R)
     следить за trenddown 15m (если ATRTrend перевернулся вниз → выход)
```

**Соотношение R:R:**
```
SL расстояние  ≈ расстояние от цены до последнего Low + буфер
TP1 расстояние ≈ расстояние от цены до PP (BelowPP → цена ниже PP)
→ R:R зависит от глубины: чем ближе к PP — тем хуже R:R, чем глубже BelowPP — тем лучше
```

## Чек-лист перед входом

### 🔴 Обязательные (все должны быть ✅)

- [ ] BearBOS на 4h активен (HTF тренд медвежий)
- [ ] `n_down < 3` на 4h (не конец 5 волн)
- [ ] WT 4h OS `< -60` (продавцы истощены на HTF)
- [ ] Цена BelowPP дневного
- [ ] `pvt_nearest_level` ≠ S2 и ≠ S3 (не в глубокой зоне)
- [ ] WT 15m OS `< -60` (локальная перепроданность)
- [ ] bull_div на 15m ИЛИ WT bull cross в OS

### 🟡 Желательные (повышают WR)

- [ ] `htf_price_dir = down` (продавцы ещё активны — контр-тренд с наилучшей ценой)
- [ ] OTE [0.618–0.786] на 15m совпадает с зоной входа
- [ ] EQL (Equal Lows) на 1h — ликвидность снята
- [ ] Liquidity sweep произошёл (цена провалилась ниже и восстановилась)
- [ ] Bull Order Block на 15m или 1h в зоне входа
- [ ] ATRTrend 15m начинает trendup

### 🔴 Стоп-сигналы (если хоть один — не входить)

- [ ] BullChoCH на 4h уже появился — СТОП (опоздали, покупаете на пике разворота)
- [ ] `n_down ≥ 3` + BullChoCH — СТОП (конец 5 волн, ABC идёт вверх без нас)
- [ ] Цена AbovePP — нет пространства для LONG *(кроме liquidity_sweep!)*
- [ ] `pvt_nearest_level = R1` или `R2` — цена уже высоко, LONG невыгоден
- [ ] WT 4h нейтральный и не OS — продавцы ещё не истощены
- [ ] `n_up ≥ 4` — если уже считали n_up, волна 5 LONG = ловушка

## Варианты исполнения (sub-типы стратегии)

### Вариант A: "Ранний вход" (агрессивный)

Входить при первом WT bull cross в OS на 15m.
```
Плюс:  лучшая цена (ниже)
Минус: больше ложных входов (WT может снова упасть в OS)
R:R:   лучше (SL меньше)
```

### Вариант B: "Подтверждённый вход" (консервативный)

Ждать ATRTrend 15m разворота на trendup + закрытие бара выше OTE bottom.
```
Плюс:  меньше ложных входов, выше WR
Минус: хуже цена входа, меньший R:R
R:R:   умеренный
```

### Вариант C: "Divergence trigger" (стандартный, рекомендуемый)

Входить при появлении bull_div на 15m (не ждать разворота тренда).
```
Плюс:  bull_div — независимый сигнал (+0.922 WR=56.5%), хорошая цена
Минус: нужно следить за формированием div в реальном времени
R:R:   хорошее (до разворота тренда)
```

## Управление рисками

- **Размер позиции:** фиксированный % от капитала (не увеличивать "потому что уверен")
- **Максимум одновременных позиций:** 2 (разные пары)
- **Не торговать:** BTC/USDT 4h TREND_DOWN — блокирует LONG для всех альт
- **Корреляция:** не открывать 2 LONG позиции на сильно коррелированных парах одновременно
- **После TP1:** SL в безубыток, TSL по trenddown 15m
- **Недельный стоп:** если 3 подряд SL → пересмотр BearBOS фильтра (возможно рынок изменился)
