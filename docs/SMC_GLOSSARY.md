## 🔬 IFVG — проверено 26.08.2026, гипотеза НЕ подтвердилась

Детектор написан со списком активных зон (v1 держала одну зону и находила 1 инверсию
на 8311 сетапов — негодна). Бычий FVG на 1h: `low[i] > high[i-2]`, зона `(high[i-2], low[i])`;
инверсия — закрытие ниже низа зоны. Причинно: `shift(1)`, только закрытые часовые бары.

База long: 8311 сетапов · 60 монет · 2022-2026.

| зона входа | охват | %/сд | PF | OOS PF | лет+ |
|---|---|---|---|---|---|
| **на баре ФИЛЛА** | | | | | |
| вне FVG | 64.3% | +0.06 | **1.02** | 1.00 | 2/4 |
| живой бычий FVG | 29.7% | −0.87 | **0.64** | 0.66 | 1/4 |
| инвертированный | 6.0% | −0.37 | 0.82 | 0.57 | 2/4 |
| **на баре СИГНАЛА** | | | | | |
| вне FVG | 76.0% | −0.24 | 0.90 | 0.85 | 2/4 |
| живой бычий FVG | 17.5% | −0.27 | 0.88 | 1.04 | 2/4 |
| инвертированный | 6.5% | −0.18 | 0.91 | 0.67 | 2/4 |

**Выводы:**
1. Инвертированный гэп НЕ хуже живого — он ЛУЧШЕ (0.82 против 0.64). Объяснение
   анти-FVG эффекта через смену роли зоны не работает.
2. 🔴 **Живой бычий FVG — худшая зона для long** (PF 0.64 / OOS 0.66 против 1.02 вне гэпов).
   Это прямое опровержение канона SMC на наших данных: свежий бычий гэп должен быть
   поддержкой, а на деле вход в него — худший из возможных.
3. Применить нельзя: на баре СИГНАЛА разброс исчезает (0.88 / 0.90 / 0.91). Эффект живёт
   только в момент филла → это свойство исполнения, а не признак отбора.
   Четвёртый случай того же класса за два дня, см. [[bug_fill_toxicity_lookahead]].
4. Связка `bull_bos + инвертированный`: PF 1.40, 4 года из 4 — но **OOS 0.46** на n=110. Шум.

## 🔑 Приоритеты проверки (что осталось из ненайденного)

1. **IRL / ERL** — формализация «где вход внутри диапазона»; нижний терциль уже дал сигнал,
   но в версии на баре филла (см. [[long_capitulation_bounce_candidate]]).
2. **C.E.** — середина зоны дисбаланса; смыкается с [[fvg_htf_priority_midline]].
3. **BSL / SSL** — явная разметка стопов над/под экстремумами; сейчас только косвенно
   через EQH/EQL, а свип как признак слабый (PF 0.94).
4. **RB** (реджекшн-блок) и **PO3** — не трогали вовсе.

⚠️ Общее правило по итогам 25-26.08: любой новый признак сразу мерить в ДВУХ версиях —
на баре сигнала и на баре филла. Если работает только на филле — он не гейт.

Не приоритет: KZ (проверено, инверсия), OB (слабый), BB (эдж не подтверждён),
PDH/PDL (OOS не прошёл).
