# OTE METHOD ENTRY V2 — вход по методу Егора (двухмасштабный цикл)

> 04.07.2026. Источник: живой разбор ZEC с Егором на TW (метод в обе стороны).
> Память: `method_egor_two_scale_entry.md` (auto-memory). Заменяет логику входа ote_nested.
> Статус: ТЗ утверждено разбором; реализация — свежая сессия; валидация ДО боя.

## Почему V2 (диагноз V1 одной строкой)

ote_nested берёт широкую зону [0.5-0.79] ОДНОГО импульса как коридор («цена ∈ зоне» + любой
15m-слом) → входит без позиции в большой структуре, без отката, у исчерпания хода
(#41729 ZEC: LONG @463 у пика, в OTE большого НИСХОДЯЩЕГО, на −1 локальной сетки).
Июль: −1.31%/сд WR19% n=289. WT/MTF-фильтры поверх таких входов НЕ работают (ретро 1464
сделок: все бакеты минус) — чинить надо ВХОД, не фильтры.

## Формула метода (полный цикл сделки)

```
1. СТОРОНА    позиция в БОЛЬШОЙ структуре: у пика → готовим SHORT, у дна → LONG.
              + слой толпы: long/short ratio (толпа против хода у края = топливо → сначала
              возможен свип экстремума, потом слом).
2. ТРИГГЕР    len5 CHoCH в сторону ожидания (внутренняя структура ломается первой).
3. ВХОД       откат после len5-слома: ретест сломанного уровня / OTE малой сетки.
              СТОП тугой за локальный экстремум (~3%).
4. ПОДТВЕРЖД  len50 CHoCH по ходу (+~6% форы к этому моменту):
              → SL в БУ → ДОБОР на ретесте len50-уровня (полный размер на оплаченном риске).
5. ЦЕЛИ       OTE СЛОМАННОГО большого импульса: 0.5 → 0.62 → 0.705 (имбаланс/FVG чаще там).
              Частички по целям (лестница), остаток на трейле.
```

Асимметрия: вход по len5 платит ~3% стопа за ~6% форы; ждать len50 = платить 6% хода и
входить дороже. len50 = точка ДОБОРА и сопровождения, НЕ входа.

**🔴 СУТЬ ЭКОНОМИКИ (Егор): «стоп короткий — цель огромная — и на пути открываем на откатах
сделки в одном направлении».** Метод = СЕРИЯ входов на откатах вдоль импульса (не одна
сделка): пока структура импульса жива (нет len5-слома против), каждый откат внутри =
точка входа ПО направлению с тугим стопом; цель у всех одна — OTE большого. Промах
одного отката = −3%, пойманный импульс = серия × (6-15%). Требование к боту: state
«в каком я импульсе» (направление + жив/сломан) → на откатах входить/добирать, НЕ
трактовать откат как контр-сигнал (сегодня бот делает ровно наоборот — #41729).

## Принципы сеток (терминология Егора — обязательна в коде)

- Фибо-сетка ЕДИНАЯ непрерывная шкала: …−2, −1.5, −1, −0.62, −0.27, 0, 0.5, 0.62, 0.705, 1…
  НЕ «retracement + extension» — одна разметка одного импульса, продолженная в минус.
- Сетки вложены каскадом: −1/−2 одной ноги ложится на 0.5/0.618 другой = КОНФЛЮЭНЦИЯ.
  Вход/цель значимы только в совпадении уровней РАЗНЫХ сеток.
- «Первая фибо после слома — цель отката в OTE предыдущего импульса (−2), откуда разворот».

## Порядок реализации

1. **Детектор V2 (чистая функция, без боя):** по df ТФ → большая структура (пик/дно, последний
   значимый импульс) → ожидание стороны → len5-слом → откат → точка входа + стоп + цели из
   OTE большого. Выход: dict сетапа (как ote_retest_setups, совместимый с register-путём).
2. **Валидация НА ПРАВИЛЬНЫХ ВХОДАХ:** бэктест детектора на ohlcv_cache (2022-26, интрабар-
   стандарт, % net, walk-forward) — меряем МЕТОД, не БД-сделки. Порог: net>0 стабильно по эрам.
3. **SHADOW:** детектор в observer-луп параллельно старому (лог would-enter, без сделок).
4. **Бой за флагом** (vst, лестница TP из radar-обвязки). Добор len50 — v2.1 после форварда.

`scripts/test_method_v2.py` (интрабар, лестница 40/30/30 + BE после t1, % net).
**Smoke ZEC = урок 1:1:** LONG @388(SL 369)+@404 → series @411/418 → continuation @428
(на len50-CHoCH↑429); у пика 457-463 входа НЕТ, раннего SHORT нет. Детектор = метод структурно.

**Числа (полный прогон 490 симв, 1h, 2022-26, 139 346 сделок):**
- ALL −0.515%/сд — лобовая механизация «каждый сетап = сделка» эджа НЕ даёт (как все
  лобовые оцифровки: Егор отбирает, механика берёт всё).
- **reversal SHORT = единственный живой: +0.067%/сд WR41% n=32k (3/5 лет плюс: 2022 +0.64,
  2024 +0.41, 2025 +0.25); на 30 ликвидных +0.248%/сд WR42%** — ZEC-паттерн подтверждён.
- reversal LONG −0.31% (лонг-развороты хуже — вселенная альтов 22-26 бэровая по структуре).
- continuation −3.2% = ДЕФЕКТ РЕАЛИЗАЦИИ (цели серии тащат старую сетку момента разворота —
  поздние входы целятся в пройденные уровни: t1 мгновенно 63-80%, остаток выбивается широким
  стопом). Чинить: пересчёт целей от актуального импульса.
- Конфлюэнция v1 (уровень предыдущей ноги ±0.3%) НЕ улучшила (conf=ДА ≈ conf=нет) — повтор
  урока «жёсткий гейт конфлюэнции в лоб не работает»; глаз видит ВСЕ сетки+пивоты+FVG.

## 📈 Итерации 1-3 (04.07, тот же день) — эдж проявился

**Ит.1 — цели серии = ПРОДОЛЖЕНИЕ актуального импульса** (extension за экстремум, не старая
сетка разворота): continuation LONG −2.5%→−0.25%, SHORT −4.3%→−0.13%. Дефект был в целях,
не в методе.

**Ит.2 — ликвидная вселенная** (`--liquid top-N` по $-обороту): КОНФЛЮЭНЦИЯ ЗАРАБОТАЛА —
series/continuation conf=ДА в ПЛЮС (+0.5/+0.3%) vs conf=нет минус. Первое подтверждение
сердцевины метода Егора «вход только в пересечении сеток» числами.

**Ит.3 — крупная структура** (`--lenbig 100` ≈ 4h на 1h, ликвидные top-60) = ЛУЧШИЙ срез:
- **reversal SHORT: 4/5 лет плюс** (2022 +0.65, 2024 +0.35, 2025 +0.47, 2026 +0.68;
  минус только 2023 медвежий), n=6575 — ОБЪЁМНЫЙ ФЛАГМАН.
- **continuation conf=ДА: LONG +0.937% / SHORT +1.343%** (n 70/43 — редкий, мощный, копить).
- series слабое (t1=5% — цели-extension слишком далеко; нужна БЛИЖНЯЯ лестница для доборов).

**Боевые кандидаты (к валидации walk-forward):**
1. reversal SHORT @ len_big=100 на ликвиде — объёмный, устойчивый.
2. continuation + conf=ДА — редкий сильный эдж.

**Ит.4 — series ближняя лестница = НЕ спасла** (WR 14-19% при любых целях/conf). ВЕРДИКТ:
series (доборы ДО len50-подтверждения) — структурно шумная фаза «разведки», механика не
тянет. **Выкинуть из торговли** (в детекторе оставить для наблюдения, флагом не торговать).

## 🔬 МАТРИЦА ТФ (04.07, запрос Егора «идентичное в лонг + разные ТФ») — 4h = РОДНОЙ ТФ

`scripts/test_v2_matrix.py --tfs 15m,1h,4h`. Ликвид top-50, len_big адаптивный (4h=30, 1h=100,
15m=200 — крупная структура ≈4-5 дней).

**ГЛАВНОЕ: чем крупнее ТФ, тем чище метод. 4h живёт, 15m = шум.**

| ТФ | reversal SHORT | reversal LONG | лучший conf=ДА |
|---|---|---|---|
| **4h** | +0.16% (conf **+1.75%** WR59) | −0.43% (conf **+0.67%** WR43) | continuation SHORT conf **+3.48%** |
| 1h | +0.03% (conf −0.34) | −0.26% (conf −0.38) | continuation SHORT conf +2.07% |
| 15m | −0.12% (шум) | −0.19% (шум) | continuation LONG conf +0.62% |

**reversal LONG-ЭДЖ НАЙДЕН (ответ Егору):** на 4h без conf −0.43%, а **conf=ДА +0.665% WR43%**
(n=119) — конфлюэнция оживляет ЛОНГ. Метод симметричен, LONG-эдж = 4h + пересечение сеток.

**КОНФЛЮЭНЦИЯ = ЯДРО (не усилитель):** на 4h везде минус→плюс, ОБЕ стороны. На 1h/15m слабее.
Значит `conf` (совпадение entry с уровнем сетки соседнего импульса ±0.3%) — не опциональный
фильтр, а ОБЯЗАТЕЛЬНОЕ условие входа. Строить конфлюэнцию v2 (полный стек) на 4h.

## Правила

- Валидация ЧЕСТНАЯ: интрабар HTF-имитация, никаких full-df сканов (3 класса look-ahead в memory).
- Мера — % net (LAW №1), никаких R.
- Старый ote_nested НЕ трогать до готовности V2 (пусть копит статистику с cascade_gate).
