# OTE METHOD ENTRY V2 — вход по методу Егора (двухмасштабный цикл)

> 04.07.2026. Источник: живой разбор ZEC с Егором на TW (метод в обе стороны).
> Память: `method_egor_two_scale_entry.md` (auto-memory). Заменяет логику входа ote_nested.
> Статус: ТЗ утверждено разбором; реализация — свежая сессия; валидация ДО боя.

## Почему V2 (диагноз V1 одной строкой)

ote_nested берёт широкую зону [0.5-0.79] ОДНОГО импульса как коридор («цена ∈ зоне» + любой
15m-слом) → входит без позиции в большой структуре, без отката, у исчерпания хода
(#41729 ZEC: LONG @463 у пика, в OTE большого НИСХОДЯЩЕГО, на −1 локальной сетки).
Июль: −1.31%/сд WR19% n=289. WT/MTF-фильтры поверх таких входов НЕ работают (ретро 1464
сделок: все бакеты минус) — чинить надо ВХОД, не фильтры.

## Формула метода (полный цикл сделки)

```
1. СТОРОНА    позиция в БОЛЬШОЙ структуре: у пика → готовим SHORT, у дна → LONG.
              + слой толпы: long/short ratio (толпа против хода у края = топливо → сначала
              возможен свип экстремума, потом слом).
2. ТРИГГЕР    len5 CHoCH в сторону ожидания (внутренняя структура ломается первой).
3. ВХОД       откат после len5-слома: ретест сломанного уровня / OTE малой сетки.
              СТОП тугой за локальный экстремум (~3%).
4. ПОДТВЕРЖД  len50 CHoCH по ходу (+~6% форы к этому моменту):
              → SL в БУ → ДОБОР на ретесте len50-уровня (полный размер на оплаченном риске).
5. ЦЕЛИ       OTE СЛОМАННОГО большого импульса: 0.5 → 0.62 → 0.705 (имбаланс/FVG чаще там).
              Частички по целям (лестница), остаток на трейле.
```

Асимметрия: вход по len5 платит ~3% стопа за ~6% форы; ждать len50 = платить 6% хода и
входить дороже. len50 = точка ДОБОРА и сопровождения, НЕ входа.

**🔴 СУТЬ ЭКОНОМИКИ (Егор): «стоп короткий — цель огромная — и на пути открываем на откатах
сделки в одном направлении».** Метод = СЕРИЯ входов на откатах вдоль импульса (не одна
сделка): пока структура импульса жива (нет len5-слома против), каждый откат внутри =
точка входа ПО направлению с тугим стопом; цель у всех одна — OTE большого. Промах
одного отката = −3%, пойманный импульс = серия × (6-15%). Требование к боту: state
«в каком я импульсе» (направление + жив/сломан) → на откатах входить/добирать, НЕ
трактовать откат как контр-сигнал (сегодня бот делает ровно наоборот — #41729).

## Принципы сеток (терминология Егора — обязательна в коде)

- Фибо-сетка ЕДИНАЯ непрерывная шкала: …−2, −1.5, −1, −0.62, −0.27, 0, 0.5, 0.62, 0.705, 1…
  НЕ «retracement + extension» — одна разметка одного импульса, продолженная в минус.
- Сетки вложены каскадом: −1/−2 одной ноги ложится на 0.5/0.618 другой = КОНФЛЮЭНЦИЯ.
  Вход/цель значимы только в совпадении уровней РАЗНЫХ сеток.
- «Первая фибо после слома — цель отката в OTE предыдущего импульса (−2), откуда разворот».

## Порядок реализации

1. **Детектор V2 (чистая функция, без боя):** по df ТФ → большая структура (пик/дно, последний
   значимый импульс) → ожидание стороны → len5-слом → откат → точка входа + стоп + цели из
   OTE большого. Выход: dict сетапа (как ote_retest_setups, совместимый с register-путём).
2. **Валидация НА ПРАВИЛЬНЫХ ВХОДАХ:** бэктест детектора на ohlcv_cache (2022-26, интрабар-
   стандарт, % net, walk-forward) — меряем МЕТОД, не БД-сделки. Порог: net>0 стабильно по эрам.
3. **SHADOW:** детектор в observer-луп параллельно старому (лог would-enter, без сделок).
4. **Бой за флагом** (vst, лестница TP из radar-обвязки). Добор len50 — v2.1 после форварда.
