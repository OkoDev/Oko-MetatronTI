# 📋 PLAN C-01 — фикс слепоты CHoCH/SMC (length=50→5) + ре-майнинг

> **Статус:** запланировано 11.06.2026 · **Тип:** калибровочный фикс ядра + ре-майнинг
> **Реестр:** `docs/DUPLICATES_REGISTRY.md` → C-01 · **Память:** [[bug_ote_impulse_period5]], [[calib_choch_length5]]

## 🎯 Цель
Привести структурный SMC-слой паттернов к эталону OKO-SM (`length=5`), убрав слепоту
`detect_structure_breaks(length=50)` в `swing_bridge`, **без потери edge** (раннеры/WR).

## 🔴 Проблема (замерено 11.06)
- `swing_bridge` (×3: `etl_order_blocks`, `etl_bos_choch`, `etl_ote_premium`) зовёт
  `detect_structure_breaks(df)` → дефолт **length=50** → СЛЕПОЙ (5m/15m = 0 CHoCH, 1h лаг 202).
- Отравляет: **OB · BOS · CHoCH · OTE-premium/discount** → `compute_flags` → **69/200 паттернов (34%)**, ML-фичи, arch104.
- Чарты/`ote_signal_generator` уже на `length=5` (эталон). Рассогласование внутри «единого калькулятора».

## ⚠️ Главный риск: train ↔ live
69 паттернов **намайнены на length=50**. Резкая смена на `5` → их `ob`/`discount` факторы
сдвинутся → live-паттерн ≠ майненный → edge может разъехаться. **Поэтому фикс + ре-майнинг неразделимы.**

## Критерии успеха
1. CHoCH/OB/discount на length=5 (совпадают с OKO-SM визуально)
2. arch104 edge (avgR) **не упал**, раннеры целы
3. train=live (паттерны майнены и торгуются на одной структуре)

## Риски
| Риск | Митигация |
|---|---|
| Ре-майнинг роняет edge | A/B бэктест ПЕРЕД катом, флаг отката |
| 69 паттернов перестают матчиться | изолировать деградировавшие (DEV-236 метод) |
| length=50 «случайно» работал | бэктест покажет; если так — per-домен length |
| ML-фичи разъезжаются (train на 50, live на 5) | переобучить после стабилизации фичей |
