## Понятия

**Опорная точка** — экстремум бара, который не превзойдён следующими `window` барами.
- Вершина на баре `j`: `high[j]` строго выше каждого `high[j+1 … j+window]`.
- Впадина на баре `j`: `low[j]` строго ниже каждого `low[j+1 … j+window]`.
- Точка подтверждается на баре `j + window` — раньше её знать нельзя.
- **Чередование:** фиксируется только смена вида. Вершина, пришедшая после вершины, не фиксируется,
  пока не будет зафиксирована впадина, и наоборот.
- **Приоритет:** если на одном баре выполнены оба условия, считается вершина.
- **Начальное соглашение:** до первой точки считается, что последней была вершина. Поэтому первой
  зафиксированной точкой ряда всегда будет впадина.

**Масштабы.** Структура ведётся на двух масштабах одновременно: старший (`major`, по умолчанию окно 50)
и младший (`minor`, окно 5). Масштабы независимы: у каждого своё направление и свои уровни.

**Уровень** — цена последней зафиксированной точки масштаба. Уровень «взведён», пока его не сломали;
новый уровень того же вида заменяет старый и взводится заново.

**Слом** — закрытие бара за взведённым уровнем, пересечение по закрытию:
- вверх: `close[t-1] ≤ уровень < close[t]` для последней вершины;
- вниз: `close[t-1] ≥ уровень > close[t]` для последней впадины.

После слома уровень разряжается и повторно не срабатывает.

Вид слома:
- **разворот (CHoCH)** — слом против текущего направления масштаба;
- **продолжение (BOS)** — слом по направлению или при ещё не определённом направлении.

После слома направление масштаба становится направлением слома.

**Один слом — один масштаб.** Если уровень младшего масштаба совпадает по цене с уровнем старшего того
же вида, младший слом не фиксируется: событие принадлежит старшему масштабу.

**Экстремумы ноги** (старший масштаб): верх и низ, бегущие по `high`/`low` от начала ряда. Фиксация
вершины старшего масштаба сбрасывает верх на её цену и бар, впадины — низ. После сброса экстремум
продолжает обновляться текущим баром.

**Нога** — импульс для OTE, как её размечает Егор:
- направление вверх: начало = последняя впадина старшего масштаба (если её ещё нет — низ ноги),
  конец = верх ноги; нога существует, если начало ниже конца;
- направление вниз — зеркально; нет направления — ноги нет.

## Порядок внутри бара

1. Зафиксировать точки, подтверждённые на этом баре (оба масштаба), обновить уровни и сбросить
   экстремумы ноги.
2. Обновить экстремумы ноги текущим `high`/`low`.
3. На первом баре ряда сломов нет.
4. Проверить сломы: младший масштаб (вверх, затем вниз), затем старший (вверх, затем вниз).
5. Записать ногу после бара, если запрошено: решение на баре `t+1` принимается по ноге бара `t`.

## Причинность

Любая величина на баре `t` зависит только от баров `≤ t`. Проверка префиксом:
`trace(df[:k])` совпадает с `trace(df)` на всех событиях с баром `< k` и на ногах `< k`.

## Паритет (фаза 1)

Критерий: на выборке кэша (15m, 1h, 4h; масштабы 50/5, 15/4, 60/15) сломы (бар, вид, сторона, уровень,
масштаб, бар уровня), итоговое состояние и нога на каждом баре совпадают со старым каноном не менее
чем на 95% пар «символ × ТФ × масштаб». Цель — 100%. Расхождения разбираются по одному.

## Фаза 2 — зоны и уровни (`core/structure/levels.py`, `core/structure/zones.py`)

Заменяют функции `smc_engine`: `detect_structure_breaks`, `classify_structure`, `premium_discount`,
`detect_order_blocks`, `detect_equal_levels`, `detect_fvg` и `_swings_luxalgo`. Сверка —
`scripts/structure_parity_zones.py`. Определения общие для SMC/ICT, соглашения зафиксированы для паритета.

**Сломы одного масштаба с объёмом** (`level_breaks`). Одномасштабный вариант слома для зон и сетапов:
- уровень — последняя опорная точка окна `window`, действует с бара подтверждения;
- слом вверх — `close[t]` выше взведённой вершины (без условия на предыдущее закрытие), вниз — зеркально;
- за бар не больше одного слома, вверх проверяется первым;
- «тяжёлый объём» — объём бара больше среднего за `vol_len` баров, умноженного на `vol_mult`;
- ряд короче `2·window + 2` баров структуры не имеет.

**Подписи точек** (`label_swings`). Вершина выше предыдущей вершины — HH, иначе LH. Впадина ниже предыдущей
впадины — LL, иначе HL. Первая вершина ряда — HH, первая впадина — LL.

**Зоны диапазона** (`range_zones`). Для диапазона от `bottom` до `top`:
- верхняя полоса — верхние 5% диапазона;
- нижняя полоса — нижние 5%;
- равновесие — ±2.5% вокруг середины.

**Блок заявок** (`order_blocks`). Для каждого слома берём отрезок от бара уровня до бара слома включительно.
- Свечи с размахом не меньше 2·ATR (Уайлдер, 200) не рассматриваются.
- Для слома вверх блок — свеча с самым низким `low`, для слома вниз — с самым высоким `high`; при равенстве
  берётся первая.
- Границы блока — `high` и `low` этой свечи.
- Блок перестаёт действовать на первом баре после слома, где закрытие ушло за его дальнюю границу.
  С этого бара он меняет роль: поддержка становится сопротивлением и наоборот.

**Равные уровни** (`equal_levels`). Опорные точки с окном `k` с обеих сторон: слева значения строго
ниже (для вершин), справа — не выше. Две соседние точки одного вида «равны», если разница цен меньше
`tolerance · ATR(200)` на второй точке. Сначала перечисляются пары вершин, затем пары впадин.

**Разрыв справедливой цены** (`fair_value_gaps`). Три свечи:
- вверх — `low[t] > high[t-2]` и `close[t-1] > high[t-2]`;
- вниз — `high[t] < low[t-2]` и `close[t-1] < low[t-2]`.

Размер в процентах сравнивается с порогом: заданным явно или причинным. Причинный порог — удвоенное среднее
размера разрыва в процентах от закрытия по всем барам с 2-го по текущий; бары без разрыва дают ноль.
Разрыв закрыт на первом баре, где закрытие ушло за его дальнюю границу.
