## 0. Главный вывод (TL;DR)

**Интерфейс НЕ статичный — наоборот, он перенасыщен анимацией.** Просто движение всё ушло в **декор** (вращающийся фон, ~500 бесконечных SVG-анимаций в Cube, «дышащие» провода), а не в **данные**. Это **один корень обеих жалоб** юзера:

- декоративное движение **душит перформанс** → «тяжело/медленно»;
- функциональные поверхности (таблицы, карточки) **без микро-отклика** → «не живое».

**Решение = перераспределить бюджет движения:** срезать декор (чинит перф) + добавить функциональную анимацию (чинит живость). Не два проекта, а один.

Фундамент сильный (токены, шрифты, `tnum`, слой данных `useLive`+SSE) — его НЕ трогаем. Кровоточит «слой опыта»: иерархия, доступность, перформанс.

--c-loss:    oklch(0.62 0.24 18);    /* red */

--cat-blue:    oklch(0.62 0.22 260);

## 7. Референс-код

### 7.1. `MetatronBackground` — статичный, дешёвый, держит айдентику

```tsx
"use client"
// Дешёвый фон: НЕ вращается, НЕ блюрит SVG-фильтром.
// «Жизнь» — только медленная пульсация opacity (GPU-only, без перерисовки).
export function MetatronBackground() {
  const cx = 200, cy = 200, r1 = 55, r2 = 110
  const pts = [{ x: cx, y: cy }]
  for (const ring of [r1, r2])
    for (let i = 0; i < 6; i++) {
      const a = (Math.PI / 3) * i - Math.PI / 2
      pts.push({ x: cx + ring * Math.cos(a), y: cy + ring * Math.sin(a) })
    }
  const lines: [typeof pts[0], typeof pts[0]][] = []
  for (let i = 0; i < pts.length; i++)
    for (let j = i + 1; j < pts.length; j++) lines.push([pts[i], pts[j]])

  return (
    <div className="pointer-events-none fixed inset-0 z-0 overflow-hidden">
      <div className="absolute left-1/2 top-1/2 h-[120vmax] w-[120vmax]
                      -translate-x-1/2 -translate-y-1/2
                      motion-safe:animate-[bg-breath_14s_ease-in-out_infinite]"
           style={{ opacity: 0.10, willChange: "opacity" }}>
        <svg viewBox="0 0 400 400" className="h-full w-full" fill="none">
          {lines.map(([a, b], i) => (
            <line key={i} x1={a.x} y1={a.y} x2={b.x} y2={b.y}
                  stroke="var(--neon-gold)" strokeWidth={0.4} opacity={0.5} />
          ))}
          {pts.map((p, i) => (
            <circle key={i} cx={p.x} cy={p.y} r={i === 0 ? 56 : 55}
                    stroke="var(--neon-cyan)" strokeWidth={0.5} opacity={0.35} />
          ))}
        </svg>
      </div>
      {/* золотое сияние центра — статичный CSS-градиент, без блюр-фильтра */}
      <div className="absolute left-1/2 top-1/2 h-[55vmax] w-[55vmax]
                      -translate-x-1/2 -translate-y-1/2 rounded-full"
           style={{ background: "radial-gradient(circle, color-mix(in oklch, var(--neon-gold) 18%, transparent), transparent 60%)" }} />
      <div className="absolute inset-0
                      bg-[radial-gradient(ellipse_at_center,transparent_30%,var(--background)_85%)]" />
    </div>
  )
}
```
```css
/* globals.css — дыхание только opacity. motion-safe убирает при reduced-motion */
@keyframes bg-breath { 0%,100% { opacity:.07 } 50% { opacity:.13 } }
```
