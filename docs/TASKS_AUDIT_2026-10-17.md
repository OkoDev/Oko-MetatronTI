1. **Механический проход** — каждая строка привязана к разделу и дате раздела; по истории git для ID найден
   последний коммит и коммит-закрытие. Это **черновик, не вердикт**: ID в коммитах пишут не всегда, а блок
   «📊 Активные задачи» без даты смешивает свежие и старые строки.
2. **Ручная сверка** каждой сомнительной задачи — строка целиком, коммиты, код, конфиг, память, решения.
3. **Вердикты:** ✅ сделано · 🔀 поглощено другим эпиком · ⏸ пауза до первой оплаты (решение 13.10:
   исследования, ARCH-139/140, ML-сферы) · 🗑 устарело · 🟢 актуально · ❓ решить Егору.
4. **Применение** — после показа отчёта: ✅ и 🗑 → `TASKS-ARCHIVE.md` с основанием, ⏸ → отдельный блок,
   ❓ — решения Егора. Одним коммитом.
