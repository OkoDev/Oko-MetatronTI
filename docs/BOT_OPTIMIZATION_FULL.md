## 1. ДИАГНОЗ: ПОЧЕМУ БОТ ЗАДЫХАЕТСЯ

```
Market-data (526 пар × OHLCV × 5 TF) → 3 прокси IP ✅ НЕ банится

EventLoop lag                           → 0.609s 🟡
```

### Корень бана 100410

`get_open_orders(symbol)` вызывается **per-symbol**. При 200+ OPEN сделках на 100+ символах → ~10 прямых REST-вызовов в секунду на direct IP → BingX rate-limit. BingX API поддерживает вызов **БЕЗ symbol** — 1 запрос вместо 100.

### Очередь EventLoop: ДА, создаётся

```
Один цикл = SCAN (OHLCV + анализ) + CHECK_OPEN (слежение за позициями)

SCAN:        526 пар / 20 concurrent × ~1.75s = 47s
CHECK_OPEN:  ~200 позиций / 15 concurrent × ~1.5s = 21s
─────────────────────────────────────────────────────
ИТОГО цикл:  68 секунд
Интервал:    60 секунд (check_interval)
─────────────────────────────────────────────────────
ДЕФИЦИТ:     −8 секунд за цикл → лаг НАКАПЛИВАЕТСЯ
```

В пике (proxy latency 3141ms): **104 секунды на цикл — почти ×2 от интервала.** `await asyncio.sleep(60)` ждёт от конца цикла, не от начала → лаг аккумулируется.

## 2. РЕШЕНИЯ: ПРИОРИТЕТЫ

### 🔴 КРИТИЧНЫЕ — решают бан 100410 (немедленно)

| # | Что | Как | Эффект | Сложность |
|---|---|---|---|---|
| **P1** | Глобальный `get_open_orders` | 1 вызов без symbol вместо per-symbol | **-99% прямых вызовов** | Низкая |
| **P2** | TTL позиций 15→60s | `self._positions_ttl = 60` | -75% | 1 строка |
| **P3** | TTL баланса 30→120s | `self._balance_ttl = 120` | -75% | 1 строка |

```python
# P1 — ключевое: 1 вызов вместо 100+
# Было (100+ REST за цикл):
for symbol in symbols_with_open_trades:
    orders = await self._get_open_orders_cached(symbol)

# Стало (1 REST за цикл):
all_orders = await client.get_open_orders()  # БЕЗ symbol
# Разложить: self._open_orders_cache[symbol] = [o for o in all_orders if o['symbol'] == bx_sym]
```

### 🟠 ВАЖНЫЕ — ликвидируют очередь EventLoop

| # | Что | Как | Эффект |
|---|---|---|---|
| **P4** | `check_interval` 60→90s | Даёт +30s запаса | Цикл 68s входит в 90s |
| **P5** | `asyncio.sleep` от НАЧАЛА цикла | `sleep(max(0, interval - elapsed))` | Не копит лаг |
| **P6** | OHLCV кэш: не фетчить если свеча горит | Для 4h/1d свечей — кэш на часы | −30% запросов |
| **P7** | Троттлинг direct IP | `DirectRateLimiter(max_rps=1)` | Защита от будущих банов |

```python
# P5 — критично для очереди
cycle_start = time.monotonic()
# ... выполняем цикл ...
elapsed = time.monotonic() - cycle_start
sleep_time = max(0, check_interval - elapsed)  # от НАЧАЛА, не от конца
await asyncio.sleep(sleep_time)
```
