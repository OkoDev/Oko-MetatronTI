## 🔑 ПРИНЦИПЫ (новые знания)

1. **Вложенность = ядро.** HTF-зона = ГДЕ (контекст), LTF = КОГДА (триггер). Вход на LTF ужимает риск ×10 (15m SL → HTF target) → R до +16. 1h/4h = фильтры, 5m/15m = входы.
2. **Частичный TP1=1R лечит WR** (12%→72% по всей матрице). Корень низкого WR — далёкий TP (цена не доходит, разворачивается), НЕ выбивание SL.
3. **SL-буфер вреден.** Выход живёт в ATRTrend-линии + TSL (другой движок, ExitManager/tsl_updater), не в статичном стопе.
4. **Масштаб входа зависит от ДИСТАНЦИИ цели:** продолжение (далёкая=HTF target) → **15m** лучше; откат (близкая=OTE-зона) → **5m** лучше. «5m шумит» верно только для далёких целей.
5. **Глубина куба = качество.** Больше согласованных уровней (1d→4h→1h→15m) → выше WR/avgR, но экспоненциально реже n. Каждый уровень фильтрует ложь.
6. **Двунаправленность** (рекурсивно в обе стороны): на каждом уровне ДВЕ сделки — продолжение (по тренду, TP=target) + откат (контр-тренд, TP=OTE). Откаты ≥ продолжений. Откат родителя = импульс ребёнка.
7. **Дивергенция в ВОЗДУХЕ = шум.** Имеет смысл ТОЛЬКО в OTE-зоне (где цена на откате). Без якоря OTE — n=тысячи, avgR≈0.
8. **Типы дивергенции (семантика):** hidden = continuation (HTF контекст тренда), regular = разворот (триггер конца отката). Regular КАК ТОЧКА ВХОДА разбавляет continuation; правильно — regular как ВАЛИДАТОР, вход по continuation-timing.
9. **Правило неперекрытия Эллиотта = уровень инвалидации = SL.** Волна 2 не ниже старта в.1, волна 4 не в территорию в.1. Откат в OTE (не пробил 1.0) = валиден; пробил 1.0 (начало импульса) = смена тренда. `s['sl']=levels[1.0]` = эта граница.
10. **Сверка геометрии (моя матрица) = майнинг (DS-316) → 15m-вход.** Два независимых пути, один ответ. DS top: HTF-пивот-зона(1D R1/1W PP) + 15m FVG + RSI/WT OB, WR91-97%.
