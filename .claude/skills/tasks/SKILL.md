# Tasks

Прочитай `/workspace/TASKS.md` и выведи структурированное резюме:

**🔄 IN PROGRESS:**
- все задачи со статусом в работе, с указанием роли (DEV/ARCH/TRADER)

**⏳ PENDING (приоритет):**
- топ-5 задач ожидающих выполнения

**✅ DONE (последние):**
- последние 3-5 завершённых задачи

Если есть задачи с блокерами или зависимостями — отметь отдельно.
