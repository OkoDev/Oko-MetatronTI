## 3. Вычисление пивотов

### ✅ Проверено:

**Модуль:** `core/pivot_calculator_fixed.py`

#### Дневные пивоты (1D):
- Метод 1: Прямое получение из `1d` таймфрейма (если доступно)
- Метод 2: Агрегация из `1h` свечей (24 часа = 1 день)
- Формулы: Traditional Pivot Points (PP, S1-S5, R1-R5)

#### Недельные пивоты (1W):
- Метод 1: Агрегация из `1d` свечей (7 дней = 1 неделя)
- Метод 2: Агрегация из `4h` свечей (42 свечи = 7 дней)
- Кэширование: 1 час для недельных пивотов
- Формулы: Traditional Pivot Points

#### Мультитаймфрейм:
- `get_multi_timeframe_pivots()` - получает и 1W, и 1D пивоты
- `find_confluences()` - находит конфлюэнции между таймфреймами
- `is_near_level()` - проверяет близость цены к уровням
- `format_pivot_message()` - форматирует сообщение для Telegram
