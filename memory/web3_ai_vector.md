### Три зерна (остальное — шум)

**🔥 1. On-chain данные → новая Сфера данных Куба**
- Whale-движения, DEX-объёмы, stablecoin-потоки, smart-money
- Не замена TA — дополнительное измерение: «техника + поток капитала on-chain»
- Ляжет в Куб как расширение Сферы 5 (cross-market / data)
- Реальная альфа, не хайп

**🔵 2. DEX-исполнение → расширение Execution Layer**
- Уже покрыто: [[ote_nested_mtf_strategy]] → Condor DEX Gateway (ARCH-96-HUB)
- Другая микроструктура: gas, MEV, slippage пулов
- Вектор далёкого будущего, когда CEX-фундамент зрелый

**🟣 3. MCP-серверы для крипто (awesome-crypto-mcp-servers)**
- MCP = стандарт подключения on-chain данных к агенту
- Ровно архитектура [[arch125-metatron-kernel]] AdvisorPort: «подключение, не встраивание»
- On-chain данные подключаются к Кубу через порт, не встраиваются
- Связь с [[swarm-advisorport-decision]]

### Что НЕ твоё (мимо)
Smart-contract генерация, токенизированные DeAI-агенты, DAO-governance — чужой домен / незрело / мемкоин-шум.

### Куб-маппинг
- On-chain данные → новая Сфера данных (новое ребро)
- DEX-исполнение → расширение Execution Layer (Condor)
- MCP-crypto → AdvisorPort-порт (подключение)

Всё ложится в Куб органично — **когда придёт время.**
