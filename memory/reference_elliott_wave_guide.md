# Эталон волновых структур (PDF-гайды IKIGAI, 08.06.2026)

**Путь:** `docs/Гайд по структурам движения.pdf` + `docs/Гайд по структурам коррекции.pdf` (положил пользователь 08.06). Самый полный гайд — основа для [[WAVE-SERVICE]].

## Полная таксономия (для классификации фазы)

**ДВИЖЕНИЕ (тренд):**
- **Импульс** (5 волн 1-2-3-4-5) — ЕСТЬ в коде (`detect_elliott_impulse`, smc_engine). Правила: R1 (w2 не за начало w1), R2 (w3 не самая короткая из 1/3/5), R3 (w4 не в территорию w1).
- **Диагональ начальная** (волна 1 или A) — НЕТ. w4 заходит в территорию w1, состоит из зигзагов.
- **Диагональ КОНЕЧНАЯ** ⭐ (волна 5 или C) — НЕТ, но КРИТИЧНА: сигнал КОНЦА тренда → разворот неизбежен. Все волны зигзаги, сужающийся диапазон, w5 за конец w3.

**КОРРЕКЦИЯ (контр-тренд):**
- **Зигзаг (ABC)** — простая. B не за основание A, C за конец A. B=0.618·A, C=100%/162%·A.
- **Двойной зигзаг (W-X-Y)** — два зигзага через X. X не за основание W, Y за конец W.
- **Треугольник (ABCDE)** — сужающийся (обычный/бегущий, чаще бегущий). C не за A, D не за B, E не за C. Каждая однонаправленная волна 0.618 предыдущей.
- **Плоскость (ABC)** — B откатывает ≥90% A. B=1.236/1.382·A, C=162%·A.
- **Комбинация (W-X-Y)** — две коррекции через X. X≥90% W.

## КЛЮЧ к pivot-слепоте (PIVOT-CONTEXT)

```
pivot LONG НОЖ  = середина ИМПУЛЬСА вниз (волна 3) → тренд продолжается (W12 −0.94 WR2%)
pivot LONG ВАЛИД = конец КОРРЕКЦИИ (зигзаг C/плоскость C завершилась) → разворот (W16 +0.99)
⭐ Конечная диагональ (волна 5/C) = конец тренда → разворот скоро = GOLD для разворотных
```
→ WaveService классифицирует структуру (импульс=не входить против / коррекция-конец=можно разворот).

## Фибо-правила (цели + валидация)
- Импульс: w2=0.618·w1, w4=0.382·w3, w5=w1 (равенство) или 0.618·w3.
- Зигзаг: B=0.618·A, C=1.0 или 1.618·A.
- Плоскость: B=0.9-1.382·A, C=1.618·A.
- Треугольник: волны сужаются 0.618.
- **Чередование (alternation):** w2 острая → w4 боковая (и наоборот); w1 диагональ → w5 импульс.

## Локальная вложенность (фрактал — для nested MTF)
- Волна 1/5 = импульс или диагональ; волна 3 = только импульс.
- Волна 2 = любая коррекция кроме треугольника; волна 4 = любая.
→ объясняет nested 4h⟷1h: 4h-волна 4 содержит 1h-зигзаг ABC.
