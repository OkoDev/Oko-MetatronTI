ОПИСАНИЕ МЕТРИК ИСТОРИИ ПАРЫ:
──────────────────────────────

Pumps%
  Определение: % выигрышных LONG сделок по этой паре
  Вычисление: count(signal_type=OTE, direction=LONG, status=TP) /
              count(signal_type=OTE, direction=LONG, all_statuses)
  Интерпретация:
    > 50% = пара хорошо идёт вверх (бычья)
    30-50% = нормально
    < 30% = пара склонна к откатам (медвежья)
  Пример: "Pumps: 3.2%" = только 3.2% LONG сделок в прибыль (очень плохо!)

Reversed%
  Определение: % сделок закрытых по SL (переворот против входа)
  Вычисление: count(status=SL) / count(all_statuses) * 100%
  Интерпретация:
    < 20% = хороший SL (редко срабатывает)
    20-40% = нормально
    > 40% = SL слишком близко или пара волатильная
  Пример: "Reversed: 12%" = 12% сделок закрыты по SL (хорошо)

AvgDrop%
  Определение: средний % убытка на SL-закрытиях
  Вычисление: mean(|entry_price - stop_loss| / entry_price)
              для всех status=SL сделок
  Интерпретация:
    < 1% = очень тесный SL (хороший контроль)
    1-3% = нормальный SL
    > 3% = широкий SL (высокий риск на сделку)
  Пример: "Avg drop: -2.1%" = в среднем теряем 2.1% на SL

КОМБИНИРОВАННОЕ ПРОЧТЕНИЕ:
  "Pumps: 3.2% · Reversed: 12% · Avg drop: -2.1%"
  = BTC памп'ит редко (3.2%), но когда входим SHORT,
    редко срабатывает SL (12%), теряя в среднем 2.1% на убыток.
  = Пара требует твёрдой hand и хороших фильтров (не много памп'ов)
