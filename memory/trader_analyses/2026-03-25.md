## КРИТИЧЕСКОЕ НАБЛЮДЕНИЕ 1: RANGE режим — массовый SL

**Факты:**
- Из 68 OPEN позиций: 47 в RANGE режиме (69%)
- Сегодня закрытые: 100% SL, все в RANGE
- Confluence LONG RANGE: 7 SL. Confluence SHORT RANGE: 5 SL. WL breach RANGE: 6 SL

**Паттерн:** RANGE + любое направление + любой сигнал = SL.

**Почему:** RANGE — это боковик. Система открывает позиции в обоих направлениях одновременно (LONG и SHORT в RANGE), они взаимно уничтожаются через SL. Это не "плохой сигнал" — это системная проблема с открытием позиций в боковике.

**Дополнительно:** R:R в RANGE часто нереальные:
- ATH/USDT RANGE SHORT RR=49.8 → SL
- GALA/USDT RANGE LONG RR=27.0 (TREND_UP, но это RANGE TP)
- COOKIE/USDT RANGE LONG RR=69.5 → гарантированный SL
- NOT/USDT RANGE LONG RR=16.9
- UMA/USDT RANGE SHORT RR=18.6

Все эти позиции закроются по SL — TP на RR>10x недостижимо в RANGE.

**→ DEV/ARCH (важно):** требуется отдельный guard для RANGE режима:
```
RANGE + confluence → либо повысить min_strength до 85, либо cap max_rr=3.0 для RANGE
RANGE + WL breach → либо не регистрировать, либо только если TP = реалистичный (RR ≤ 4)
```
Иначе RANGE позиции будут продолжать доминировать в SL-статистике.
